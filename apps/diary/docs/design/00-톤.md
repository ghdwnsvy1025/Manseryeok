# 사주읽는밤 일기 — 디자인 톤 명세 (00)

> 디자인 작업은 `frontend-design` 스킬을 먼저 불러서 한다.
> 이 문서는 모든 화면에 공통이다. 화면별 명세(`01-…`, `02-…`)는 이 문서를 전제로 쓴다.
> 앱 코드: `apps/diary/` (Next 15 · React 19 · Tailwind 4). 색 토큰은 `src/app/globals.css`의 `@theme`에만 둔다.

## 한 문장

밤 11시 책상 위 스탠드 하나. 바탕은 거의 검은 남색, 빛은 등불 주황 하나뿐.

## 서명(signature) — 캡처만 봐도 이 앱인 것

**60갑자 격자(10×6).** 홈 상단, "나" 화면, 공유 카드에 같은 격자가 반복된다. 기록이 쌓일수록 칸이 하나씩 켜진다. 달력 대신 간지력을 쓰는 앱은 없다. 이것이 유니크의 전부이고, 다른 장식으로 유니크를 만들지 않는다.

## 유니크한 장치 — 하나만

**배경이 실제 시각을 따라간다.** 저녁 6시 짙은 남색 → 밤 11시 거의 검정 → 새벽 다시 옅어짐. 색은 한 계열인데 시간마다 달라 보여서 "밤에 쓰는 앱"이 설명 없이 전달된다. 구현은 `body` 배경색을 KST 시각으로 3~4단계만 바꾸는 정도면 된다. 이 장치 외의 "특별한 효과"는 넣지 않는다.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 색 | 바탕 남색 계열 + 강조 **등불색 하나**. 오행 다섯 색(청·적·황·백·흑)은 UI에 쓰지 않는다 (사주 앱이 전부 쓰는 요소라 빼는 게 유니크). 공유 카드에서만 바이럴 60갑자 카드 색을 그대로 쓴다 |
| 서체 | 한자·큰 제목은 명조(현재 Gowun Batang), 본문은 고딕(현재 Noto Sans KR). 서체는 두 개를 넘기지 않는다 |
| 모드 | **다크 전용.** 라이트 모드 없음. 시스템 설정과 무관하게 어둡게 고정 |
| 밀도 | 한 화면에 카드 2장 이하, 카드당 행동 버튼 1개. 스크롤 없이 끝나는 화면을 목표 |
| 아이콘·그림 | 아이콘은 하단 탭에도 쓰지 않고 글자만. 일러스트·이모지·마스코트 없음. 유일한 그림은 60갑자 카드 |
| 모션 | **운세가 열리는 순간**과 **저장이 끝나는 순간** 두 곳에만 300~600ms ease-out 전환 한 번. 반복 애니메이션·로딩 중 돌아가는 문구 없음 |
| 글 | 어미 "~어요" 통일. 금지어: 결·기운·흐름·두근. 숫자는 사실만("신해일 2번, 평균 8.0"), 기간 약속 금지("150일 더 쓰면") |
| 글자 크기 | 본문 16px 이상, 간지 한자 28px 이상. 침대에서 보는 화면이라 작게 만들지 않는다 |
| 산출물 | 피그마가 아니라 **코드로 바로**. 새 UI 라이브러리·애니메이션 패키지 설치 금지. CSS와 Tailwind 유틸리티로 해결 |

## 작업 경계 (기능 작업과 충돌 방지)

디자인 작업이 **고쳐도 되는 것**
- `src/app/globals.css` (토큰·전역 스타일)
- `src/components/**` 의 className·마크업 구조·모션
- `src/app/**/page.tsx`, `src/app/**/*Form.tsx` 의 **className과 JSX 구조**. 단 `props`, `name=` 속성, 서버 액션 호출, 데이터 읽는 코드는 그대로 둔다

디자인 작업이 **건드리지 않는 것**
- `src/lib/**`, `src/app/actions.ts`, `src/app/api/**`, `src/middleware.ts`, `supabase/**`, `test/**`, `package.json`
- 폼의 `name` 값과 `value` 값 (서버가 그 이름으로 읽는다)

끝나면 `apps/diary`에서 `npx tsc --noEmit`과 `npm test`가 통과해야 한다. 커밋은 하지 않고 작업 트리에 둔다 (기능 쪽에서 검토 뒤 커밋).
