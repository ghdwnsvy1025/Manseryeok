## v3.3 — 내 캐릭터 (2026-10-07, 이 절이 v3.2보다 우선)

사용자 피드백(2026-10-07): "사람마다 캐릭터가 있으니 자기 캐릭터를 띄우자 / 오늘 탭 네모칸은 빼자 / 입력창이 허접하다, 양식지·띠지 이상 / 격자엔 카드 말고 캐릭터만 + 테두리 색". 진단: 앱의 주인공은 '나'인데 화면에 나를 나타내는 것이 없었다. 그림은 매일 바뀌는 '그날 동물'뿐이라 애착이 생기지 않는다.

### 내 캐릭터 = 일주 캐릭터, 하나, 고정
- `pillars.day.ko`(예: 기축)의 바이럴 캐릭터 `characters/{일주}.webp`, 카드는 `cards/{일주}.webp`. 가입 때 정해지고 바뀌지 않는다(나중에 "모은 카드 중 고르기"는 보류).
- **화면의 그림은 내 캐릭터 하나.** 운세 카드의 '그날 동물'은 삭제. 그날 간지는 글자로만. "한 화면에 그림 하나" 규칙은 그대로 — 그 하나가 '나'로 바뀐 것.

### 어디에, 무엇을 하나
| 화면 | 캐릭터 |
|---|---|
| 오늘 | 제목 오른쪽 64px (운세 카드 안 동물 삭제) |
| 쓰기 → 팡 | 팡 카드 = **내 일주 카드**. 오른쪽 아래 인주 행복도 도장. 글자 "기축 카드에 오늘 도장을 찍었어요". 카드 아래 가장자리에 **지난 도장들**이 작게(최근 7개, 12px 인주 점, 번호 없음) 쌓여 매일 달라 보이게 |
| 나 | 맨 위 "나의 밤" 제목 대신 **내 카드 크게**(폭 56%) + 이름·"기축일 · 소" 한 줄. 그 아래 나무패 |
| 공유 카드 | 내 카드 + 오늘 한 줄 (기존 ShareCard의 카드 이미지를 일주 카드로) |
| 로딩 | 붓선 대신 **내 캐릭터 48px** + "오늘 글자를 읽고 있어요". 캐릭터를 아직 모르는 온보딩 전에는 붓선 유지 |
| 온보딩 직후 | **공개 화면 1회** `/welcome`: 팡 연출로 내 카드 등장 + "당신의 카드는 기축 · 소예요" + "오늘 운세 보기" 금색 버튼. 한 번만(프로필 생성 직후 redirect) |

### 오늘 화면 — 60칸 띠 삭제
띠·설명·첫 방문 힌트(BandHint) 전부 삭제. 제목 아래 한 줄 Pretendard 14px muted: **"60갑자 중 51번째 · 기록 12일째"** (링크 → /me). 기록 0이면 "60갑자 중 51번째 · 첫 기록을 기다려요".

### 생년월일 입력 — 양식지 제거, 깨끗하게
- `form-sheet` 배경 삭제(에셋 파일은 둠, 참조 제거). 한지 카드 한 장 안에 입력칸.
- 입력칸: 높이 56px, 녹갈 1px 테두리, 한지색 바탕(`paper-3`), 숫자 Song Myung 22px. **상태만 분명히**: 빈 칸 = 흐린 자리표시 / 입력 중 = 금색 2px / 채움 = 먹색 글자. 오류 = 먹색 1.5px + 아래 `danger` 한 줄.
- 양력·음력, 성별, 시간 모름: **두 칸 세그먼트**(띠지 그림 없음). 고른 쪽 = 먹색 면 + 한지색 글자, 안 고른 쪽 = 테두리만. 윤달은 음력일 때만 체크 한 줄.
- 도시 select는 같은 입력칸 모양.
- 금색 면 버튼 "내 카드 보기"(→ /welcome).

### "나" 격자 — 동물만, 금 테두리
- 모은 칸 = **캐릭터만**(`characters/{간지}.webp` contain, 카드 틀·썸네일 없음) + 테두리 금색, 농도 = 평균 행복도(옅음 1px → 진함 2px). 약속 지킨 날이 있는 칸은 **두 겹**(금 2px + 안쪽 한지 1px + 금 1px). 안 모은 칸 = 빈 도장 자리 + 지지 글자(지금대로).
- 오행 색은 여전히 나무패 안에서만. 격자에 쓰지 않는다.
- 선택 칸 상세: 그 간지 **카드** 크게(여기서만 카드 전체) + 숫자 줄 + 기록 목록 (v3.2 그대로).

## v3.2 — 인주, 양식지, 로딩, 오행 점, 작은 약속 (2026-10-06, 이 절이 v3.1보다 우선)

사용자 피드백(2026-10-06, 16항목)에서 디자인에 해당하는 결정. 기능 쪽 결정(익명 시작·스트리밍·설정)은 `docs/ANON_START.md`.

### 네 번째 색: 인주 빨강 `seal`
- 지금까지 한지·녹갈·금 셋이 모두 노란 기라 밋밋했다. **인주(朱) 색을 넷째 색으로 넣는다.** 토큰 `seal` = 키트 `stamp-inked-red` 측정값(목표 #b8322a 근처, 수채 번짐).
- 측정값(2026-10-07, `ui-kit/analysis.json`): `stamp-inked-red-clean` 지배색 #be281d(31%)·#c12c21(27%)·#bf2a1f(22%), `seal-collected-clean` 지배색 #be301d(27%)·#c13421(20%) → **`seal #bf2a1f`**. `fire`는 `seal`과 같은 값. 숫자는 `paper-2` 한지색(대비 5.6:1).
- **쓰는 곳은 도장·인장뿐**: 쓰기 화면 행복도 도장(찍힌 상태), 팡 카드의 행복도 도장, 모은 카드의 "모음" 인장, "저장했어요" 표시. 바이럴 톤의 "인주는 인장에만" 규칙과 같다.
- **쓰지 않는 곳**: 버튼, 글자, 경고, 화살표(↓는 여전히 먹색), 테두리, 밴드. 길흉을 색으로 말하지 않는 규칙 유지.
- 남색은 그대로 간지 글자·띠지·오늘 칸 테두리에만.

### 오행 색 — 네 기둥 패 안에서만 허용
- v2의 "오행 다섯 색을 UI에 쓰지 않는다"를 **"네 기둥 나무패 안의 작은 점에만 허용"**으로 고친다. 토큰 `wood #3f7a4a` `fire #b8322a`(=seal) `earth #b58a2e`(=gold-ink) `metal #9a9a92` `water #1c2b52`(=sky). 점 지름 8px, 패 아래 오행 글자 옆. 다른 곳(격자·운세·그래프)에서는 여전히 금지.

### 운세 카드 (피드백 7·8)
- 글에서 "윗글자·아랫글자"가 사라진다(기능 쪽 프롬프트). 카드 맨 아래 `<details>` "왜 이런 운세인가요?"에 `core.facts` 6~10줄(14px muted, 왼쪽 금색 세로선).
- **"내 기록으로 본 오늘" 블록**: 운세 본문과 영역 줄 사이, 한지보다 한 단계 어두운 네모(`paper-3`) 안에 "계축일에 3번 기록 · 평균 7.3 · 사주 점수는 4.0이지만 내 기록은 좋은 편". 기록 0이면 같은 자리에 "아직 기록이 없어 사주만으로 계산했어요". 맨 아래 흐린 한 줄은 삭제(이 블록으로 이동).
- 하면 좋아요 = **금색 띠지**(tag-strip gold-wash 면 + gold-ink 글자), 피해요 = **먹색 테두리 띠지**(한지 띠 + ink 테두리 1.5px). 라벨은 띠지 안에, 문장은 오른쪽.

### 팡 + 작은 약속 (피드백 11·12)
- 팡 카드 오른쪽 아래에 **행복도 도장**(`stamp-inked-red` + 숫자 Song Myung 28px 한지색)이 카드 팡 150ms 뒤 scale 1.4→1로 **꽝** 찍힌다(120ms). 글자 줄은 "계축일 카드를 모았어요"만.
- **오늘의 작은 약속**: 운세 "하면 좋아요" 한 줄이 그날의 약속. 쓰기 화면 맨 위(행복도 위)에 금색 띠지 "오늘 약속 · 저녁에 지출과 약속을 다시 확인해요" + 체크 "지켰어요 / 못 지켰어요 / 해당 없음"(세그먼트 3칸, `name="promise"`). 지켰으면 그날 카드가 **금테 카드**가 된다(격자·팡에서 테두리 금색 2px). 포인트·연속일·배지 없음.

### 나 화면 (피드백 13·14·15)
- 나무패: 위 천간 한자(28px) / 가운데 지지 한자(28px) / 아래 십신 한글 13px + 오행 글자 + 오행 점 8px. 일주 패에 "나" 12px 금색. 패 폭은 4개가 375px에 들어가게(각 ≤ 78px).
- 격자 = **카드 앨범**: 모은 칸은 바이럴 카드 전체 썸네일(`public/cards/{간지}.webp`를 칸에 맞춰 cover) + 평균 행복도 농도의 금색 테두리(1px 옅음 → 2px 진함), 약속 지킨 날이 있으면 금테 2px 고정. 안 모은 칸은 빈 도장 자리 + 지지 글자. 칸은 정사각 ≥ 30px, 10×6 유지.
- 칸을 누르면 격자 아래에 그 간지 **카드를 크게**(폭 60%) + "계축일 3번 · 평균 7.3 · 지킨 약속 1" + 그 날들의 기록 목록. 기존 `?cell=` 처리 유지.
- 천간별·지지별·오행별 `<details>`: 기록 1건 이상이면 **펼친 상태가 기본**. 0건이면 "첫 기록을 남기면 여기에 천간·지지·오행별 평균이 쌓여요".

## v3.1 — 밤을 지우고, 팡 (2026-10-05 저녁, 이 절이 v3보다 우선)

사용자 피드백: "운세 카드만 밤이라 이질적이다. 밤 콘셉트를 없애도 된다." / "기록을 저장하면 게임 보상처럼 '팡' 터지는 팝업이 있으면 좋겠다."

### 밤 제거
- **화면에서 남색 면을 전부 뺀다.** 운세 카드도 한지 카드(`card-paper` + `card-frame`)다. `sky-panel`·`sky-panel-warm` 클래스와 이미지는 쓰지 않는다(파일은 두되 참조 제거).
- **저녁 번짐(`data-sky`) 삭제.** `page.tsx`의 `data-sky` 속성과 `globals.css`의 `main[data-sky]` 규칙을 지운다. 시간대와 무관하게 같은 화면.
- 남색(`sky`, `ganji`)은 **글자·띠지·격자 오늘 칸 테두리 같은 작은 악센트로만** 남는다. 면으로 쓰지 않는다.
- 운세 카드의 구분은 **금색 이중 테두리(card-frame의 금색 변형 또는 금색 외곽선 2px) + 송명 큰 글자 + 그날 동물**로 한다. 이 화면에서 그림이 있는 카드는 운세 카드뿐이다(제목 옆 동물을 운세 카드 머리 오른쪽으로 옮긴다). 글자색은 `ink`, 보조는 `muted`, 눈금과 세로선은 `gold`.
- 앱 이름 "사주읽는밤 일기"는 그대로(브랜드·채널 통일). 이름 변경은 보류.
- 토큰 `sky-ink`·`sky-muted`는 쓰는 곳이 없어지면 삭제. `sky`·`sky-2`는 악센트용으로 유지.

### 팡 — 저장 완료 보상 (모션 예외 한 곳)
"저장 완료" 모션을 접힘 전환에서 **보상 팝업**으로 바꾼다. 매일 한 번, 0.6초 안에 끝난다.
1. 저장 버튼 → 서버 저장 성공 → 화면 가운데 오버레이(한지 반투명 `paper` 85%).
2. **그날 간지의 바이럴 카드**(`public/cards/{간지}.webp` — `에셋/바이럴/cards`에서 60장 복사)가 scale 0.6 → 1.08 → 1.0으로 **팡** (400ms, cubic-bezier(.2,.9,.3,1.2)). 카드 폭은 화면의 62%.
3. 터지는 순간 카드 뒤에서 **한지 조각 8개 + 금빛 가루 8개**가 바깥으로 흩어지며 사라진다(600ms, 각각 다른 방향·회전, opacity 1→0). 재료는 CSS로 그린 작은 사각·원이 아니라 키트 이미지 `ui-kit/pop-paper-bits`(투명, 조각 몇 개가 한 장에)와 `ui-kit/pop-gold-dust`를 잘라 쓴다. 두 장 생성.
4. 카드 아래 "임자일 카드를 모았어요" (Song Myung 22px) + "행복도 7" (Pretendard 16px muted). 글자는 카드 뒤 150ms 늦게.
5. 1.5초 뒤 자동으로 오버레이가 사라지며(200ms fade) `/?saved=날짜`로 이동. 오버레이를 탭해도 바로 닫힌다. `navigator.vibrate?.(30)` 한 번. 소리 없음.
6. `prefers-reduced-motion`이면 팡·흩날림 없이 카드가 바로 나타나고 1초 뒤 이동.
- 구현 위치: `EntryForm.tsx`의 저장 성공 분기(지금 접힘 전환 자리). 서버 액션·name/value는 그대로. 카드 파일명은 `day_ganji`의 한글(`임자`)로 만든다 — `characters/`와 같은 규칙.
  - **실제 구현(2026-10-05)**: 서버 액션이 성공 즉시 `/?saved=날짜`로 redirect하므로 폼은 성공 신호를 받지 못한다. `SaveBurst`는 오늘 화면 `page.tsx`에서 `saved === today && entry`일 때 마운트하고, 1.5초 뒤 걷히며 아래의 오늘 화면이 드러난다. 상세는 05 명세 끝의 구현 메모.
- "색종이·폭죽 없음" 규칙은 **이 한 곳만 예외**다. 다른 곳(운세 열림, 도장 눌림)에는 번지지 않는다.
- 오늘 화면의 "저장했어요" 150ms 지연 표시는 유지(팝업 뒤에 도착하므로 중복 느낌이 없다).

### 유지

## 뿌리 — 바이럴 60갑자 카드

이 앱의 색·질감·그림은 전부 바이럴 60갑자 카드(`사주 앱/에셋/바이럴/cards`, `characters`, `cards-bg`, 각 60장)에서 가져온다. 카드에 없는 재료는 쓰지 않는다. 카드의 재료는 넷뿐이다.

| 재료 | 카드에서 | UI에서 |
|---|---|---|
| 한지 크림 | 카드 바탕, 글 상자 | 화면 바탕, 카드 표면 |
| 녹갈색 선 | 카드 테두리 | 구조선, 테두리 |
| 별 금색 | 밤하늘의 별 | 행동 버튼 하나, 점수 눈금 |
| 밤하늘 남색 | 그림 창 | 운세 카드 패널, 간지 글자, 밤의 번짐 |

## 서명(signature) — 캡처만 봐도 이 앱인 것

**60갑자 격자(10×6).** 홈 상단, "나" 화면, 공유 카드에 같은 격자가 반복된다. 한지에 찍은 도장 격자처럼 그린다. 기록이 쌓일수록 칸이 하나씩 찍힌다. 격자 칸에 동물 그림을 넣지 않는다. 달력 대신 간지력을 쓰는 앱은 없다. 이것이 유니크의 전부이고, 다른 장식으로 유니크를 만들지 않는다.

## 유니크한 장치 — 하나만

**밤이 되면 한지 위로 남색이 번진다.** 낮(05~18시)은 한지 그대로. 저녁(18~21시)은 화면 위쪽 가장자리부터 옅은 남색 수채 번짐. 밤(21~05시)은 번짐이 가장 깊다. **한지는 끝까지 한지다.** 바탕 전체가 어두워지지 않고, 글자 대비는 시간과 무관하게 같다. 구현은 `page.tsx`의 `<main data-sky="day|dusk|night">`와 `globals.css`의 고정 위치 그라데이션 하나면 된다. 이 장치 외의 "특별한 효과"는 넣지 않는다.

| 글자 크기 | 본문 16px 이상, 간지 한자 28px 이상. 침대에서 보는 화면이라 작게 만들지 않는다 |
| 산출물 | 피그마가 아니라 **코드로 바로**. 새 UI 라이브러리·애니메이션 패키지 설치 금지. CSS와 Tailwind 유틸리티로 해결 |

## 에셋 키트 — 디자인은 재료에서 시작한다

순서가 중요하다. **코드를 먼저 짜고 그림을 끼우지 않는다.**

1. **납품**: 화면 명세의 "필요한 에셋" 절대로 `saju-assets`가 재료를 만든다 (`에셋/사주 일기/ui-kit/`). 바탕 한지(타일), 카드 테두리(투명, border-image용), 밤하늘 패널, 금색 버튼면, 괘선. 전부 60갑자 카드와 같은 손 그림 질감으로.
2. **분석**: `analyze_kit.py`로 납품물의 색·밝기·대비·선 밀도를 **측정**해 `analysis.json`에 남기고, 그 수치로 아래 토큰 표를 갱신한다. 눈대중 hex를 쓰지 않는다.
3. **조립**: 디자이너는 그 이미지를 `public/ui/`로 복사(webp)하고, `globals.css`의 재료 클래스(`.hanji`, `.card-frame`, `.sky-panel`, `.gold-plate`, `.rule`)로 화면을 조립한다. 글자·배치·동작만 코드다.

키트 목록과 측정값은 `에셋/사주 일기/ui-kit/analysis.json`과 `manifest.json`에 있다. 토큰 표의 색은 이 측정값에서 온 것이고, 키트가 바뀌면 토큰도 다시 측정한다.

## 작업 경계 (기능 작업과 충돌 방지)

디자인 작업이 **고쳐도 되는 것**
- `src/app/globals.css` (토큰·전역 스타일)
- `src/components/**` 의 className·마크업 구조·모션
- `src/app/**/page.tsx`, `src/app/**/*Form.tsx` 의 **className과 JSX 구조**. 단 `props`, `name=` 속성, 서버 액션 호출, 데이터 읽는 코드는 그대로 둔다
- `public/characters/**` (바이럴 세트에서 복사만. 수정·생성 금지)
- `public/ui/**` (에셋 키트에서 복사만. 원본은 `에셋/사주 일기/ui-kit/`)

디자인 작업이 **건드리지 않는 것**
- `src/lib/**`, `src/app/actions.ts`, `src/app/api/**`, `src/middleware.ts`, `supabase/**`, `test/**`, `package.json`
- 폼의 `name` 값과 `value` 값 (서버가 그 이름으로 읽는다)

끝나면 `apps/diary`에서 `npx tsc --noEmit`과 `npm test`가 통과해야 한다. 개발 서버(`.claude/launch.json`의 `dev-night-diary`)를 띄워 375px 폭 스크린샷을 찍고, 이 문서의 결정표와 대조한 결과를 보고에 넣는다. 커밋은 하지 않고 작업 트리에 둔다 (기능 쪽에서 검토 뒤 커밋).

## 개정 이유

v1은 "밤 11시 책상, 거의 검은 남색, 그림 없음"이었다. 바이럴 카드 60장(한지·수채·한복 입은 동물·남색 밤하늘 창)이 이미 완성돼 있고, 일기와 바이럴이 같은 세계여야 공유 카드가 자연스럽다. 또 v1은 사용자 취향(따뜻한 한지색, 수채, 귀엽고 가벼움)과 어긋났다. 그래서 바탕을 카드의 한지로 되돌리고, 남색은 "밤에 번지는 물감"으로만 남겼다. 60갑자 격자와 모션 두 곳, 글 규칙은 그대로다.

v3(2026-10-05): v2는 색과 바탕만 정하고 "물건"이 없어 화면이 문서처럼 보였다. 사용자가 스크린샷을 보고 서체·남색·버튼·카드 구분을 지적했다. 일기장의 물성(도장·띠지·손글씨·괘선)을 재료로 두면 버튼과 카드가 PPT 도형이 아니라 물건이 되고, "나" 화면 격자에 60갑자 카드 동물을 채우면 바이럴과의 연결이 눈에 보인다. 서체는 제목에 힘이 있는 송명, 본문은 바이럴과 같은 Pretendard, 사용자 글만 손글씨로 나눴다.
