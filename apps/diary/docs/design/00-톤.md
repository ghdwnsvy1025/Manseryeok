# 사주읽는밤 일기 — 디자인 톤 명세 (00) · v3 "밤의 일기장"

> 2026-10-05 v3 개정: v2 "한지 위의 밤"의 바탕(한지·녹갈 선·금색 버튼 하나)은 그대로 두고, **손에 잡히는 물건(일기장·도장·띠지·손글씨)**과 **임팩트 있는 서체**, **따뜻한 밤 남색**을 더한다. 아래 "v3 — 밤의 일기장" 절이 앞선 결정표보다 우선한다. 이유는 맨 아래 "개정 이유".
> 디자인 작업은 `frontend-design` 스킬을 먼저 불러서 한다. 다른 세션에서는 `saju-designer` 에이전트가 이 문서를 읽고 작업한다.
> 이 문서는 모든 화면에 공통이다. 화면별 명세(`01-…`, `02-…`)는 이 문서를 전제로 쓴다.
> 앱 코드: `apps/diary/` (Next 15 · React 19 · Tailwind 4). 색 토큰은 `src/app/globals.css`의 `@theme`에만 둔다.

## 한 문장

한지 위에 놓인 60갑자 카드 한 장. 바탕은 카드와 같은 한지 크림색이고, 밤이 되면 종이 위로 남색 물감이 번진다.

## v3 — 밤의 일기장 (2026-10-05, 이 절이 우선)

### 한 문장
**한지 일기장의 오늘 페이지.** 밤에 펼쳐서 도장 하나 찍고, 띠지 몇 개 붙이고, 손글씨 한 줄 쓰는 물건. 60갑자 카드는 그 일기장에 모이는 수집 카드다.

### 왜 바꾸나 (사용자 피드백 2026-10-05)
1. 글자가 문서 같고 임팩트가 없다 → 서체 교체
2. 운세 카드 남색이 차갑고 우울하다 → 따뜻한 밤
3. 운세 카드가 무엇인지 한눈에 안 들어온다 → 날짜·간지를 카드 안에, 밴드 단어를 주인공으로
4. "오늘도 한 줄 남겼어요" 카드가 무슨 칸인지 모르겠다 → "오늘의 기록" 일기장 페이지
5. 쓰기 화면 버튼이 PPT 같고 바탕과 겹쳐 안 보인다 → 도장·띠지 재료, 카드 대비 강화
6. "나" 화면도 같다 → 도장판 격자 + 카드 앨범

### 물건 (재료 → UI)
| 물건 | 어디에 | 상태 |
|---|---|---|
| **도장** (둥근 나무 도장, 1~10이 새겨짐) | 쓰기 · 행복도 | 안 고름 = 한지에 눌린 빈 도장 자리(흐린 테두리) / 고름 = **금빛 인주가 찍힌 자국**, 숫자는 한지색으로 빠짐 |
| **종이 띠지** (가장자리가 손으로 찢긴 짧은 한지 띠) | 쓰기 · 기분, 오늘의 기록 카드 | 안 고름 = 연한 한지 띠 + 녹갈 글자 / 고름 = **진한 남색 물들인 띠** + 한지색 글자 |
| **편지지 괘선** | 쓰기 · 한 줄 메모 입력칸, 오늘의 기록의 메모 | 가로 괘선 2~3줄 위에 손글씨 |
| **카드 종이** | 모든 한지 카드 | 바탕 한지보다 **한 단계 밝고**, 가장자리 그림자 대신 종이 두께감(키트 이미지). 바탕과 같은 색으로 묻히지 않게 |
| **도장판** | 나 · 60갑자 격자 | 칸마다 눌린 빈 자리. 기록한 간지 칸에는 **그 간지 동물(characters) 작게 + 평균 행복도 농도의 금빛 테두리** |
| **나무패** | 나 · 네 기둥 | 세로로 긴 나무 위패 4개에 한자 |
| **따뜻한 밤하늘** | 운세 카드 | 아래 "색" |

### 서체 (세 개, 역할 고정)
| 역할 | 서체 | 쓰는 곳 |
|---|---|---|
| 제목·숫자 (display) | **Song Myung (송명)** · `next/font/google`의 `Song_Myung`, 400 | 오늘 제목("오늘은 임자일"), 운세 밴드 단어("무난"), 큰 숫자(행복도·맞춤도), 섹션 제목 |
| 본문 (sans) | **Pretendard** · `globals.css`에서 `@import url("https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css")` (바이럴과 같은 CDN·버전). 실패 시 Noto Sans KR로 폴백 | 본문·라벨·버튼 |
| 내 글씨 (hand) | **Nanum Pen Script** · `Nanum_Pen_Script` | **사용자가 쓴 한 줄 메모만.** 앱 문구에 쓰지 않는다 |

- 송명에 없는 한자는 Gowun Batang으로 폴백(`--font-serif` 스택 뒤에 둔다). 한자 `壬子`는 지금처럼 명조.
- 서체 로딩은 `layout.tsx`가 기능 파일이라, **`next/font`를 쓰려면 기능 쪽 수정이 필요하다.** `globals.css`의 `@import url()`은 next/font의 @font-face 뒤에 번들돼 브라우저가 무시하므로(2026-10-05 확인), 지금은 Google Fonts CSS의 `@font-face`(woff2·unicode-range 슬라이스)와 Pretendard static 3단계를 `globals.css` 맨 아래에 그대로 옮겨 두었다. 기능 쪽이 `next/font/google`(`Song_Myung`, `Nanum_Pen_Script`)로 바꾸면 그 블록을 지운다.
- 손글씨는 크게(20px 이상). 작은 손글씨는 읽기 어렵다.

### 첫 화면 순서 (고정)
1. 날짜 · 제목 · 동물
2. **60칸 띠** — 제목 아래 얇게. 60갑자 중 오늘 위치에 금빛 점, 기록한 날은 흐린 점. 누르면 "나"로
3. **운세 카드** — 시간대와 무관하게 늘 위
4. **기록 카드** — 기록 전: 금색 "오늘 기록하기" / 기록 후: "오늘의 기록" 페이지
- v2의 "밤엔 기록 카드가 위" 규칙은 폐기. 밤에는 기록 카드의 금색 버튼만 조금 커진다(높이 56→60px).

### 모션
v2의 두 곳(운세 열림, 저장 완료) 그대로. 추가로 **도장을 고를 때 120ms 눌림(scale 0.94→1)** 한 번은 피드백으로 허용한다. 반복·로딩 애니메이션은 여전히 금지.

### v2에서 유지
한지 바탕, 녹갈색 테두리(이음새 수정판), 금색 행동 버튼 하나, 밤 번짐(`data-sky`), 그림은 60갑자 세트만(새 장면 그림 금지, 재료는 생성), 글 규칙, 16px 이상, 라이트 고정.

## 뿌리 — 바이럴 60갑자 카드

이 앱의 색·질감·그림은 전부 바이럴 60갑자 카드(`사주 앱/에셋/바이럴/cards`, `characters`, `cards-bg`, 각 60장)에서 가져온다. 카드에 없는 재료는 쓰지 않는다. 카드의 재료는 넷뿐이다.

| 재료 | 카드에서 | UI에서 |
|---|---|---|
| 한지 크림 | 카드 바탕, 글 상자 | 화면 바탕, 카드 표면 |
| 녹갈색 선 | 카드 테두리 | 구조선, 테두리 |
| 별 금색 | 밤하늘의 별 | 행동 버튼 하나, 점수 눈금 |
| 밤하늘 남색 | 그림 창 | 운세 카드 패널, 간지 글자, 밤의 번짐 |

## 서명(signature) — 캡처만 봐도 이 앱인 것

**60갑자 격자(10×6).** 홈 상단, "나" 화면, 공유 카드에 같은 격자가 반복된다. 한지에 찍은 도장 격자처럼 그린다. 기록이 쌓일수록 칸이 하나씩 찍힌다. 격자 칸에 동물 그림을 넣지 않는다. 달력 대신 간지력을 쓰는 앱은 없다. 이것이 유니크의 전부이고, 다른 장식으로 유니크를 만들지 않는다.

## 유니크한 장치 — 하나만

**밤이 되면 한지 위로 남색이 번진다.** 낮(05~18시)은 한지 그대로. 저녁(18~21시)은 화면 위쪽 가장자리부터 옅은 남색 수채 번짐. 밤(21~05시)은 번짐이 가장 깊다. **한지는 끝까지 한지다.** 바탕 전체가 어두워지지 않고, 글자 대비는 시간과 무관하게 같다. 구현은 `page.tsx`의 `<main data-sky="day|dusk|night">`와 `globals.css`의 고정 위치 그라데이션 하나면 된다. 이 장치 외의 "특별한 효과"는 넣지 않는다.

| 모드 | **라이트 고정(한지).** 다크 모드 없음. 시스템 설정과 무관하게 `color-scheme: light` |
| 질감·재료 | **UI의 재료는 납품된 에셋 키트다.** 바탕 한지, 카드 테두리, 밤하늘 패널, 금색 버튼면, 괘선은 CSS 색이 아니라 `public/ui/`의 이미지(`에셋/사주 일기/ui-kit/`에서 복사)를 쓴다. CSS는 배치·크기·동작만 맡는다. 키트에 없는 재료를 CSS로 흉내 내지 않는다. 필요하면 키트에 추가한다 |
| 밀도 | 한 화면에 카드 2장 이하, 카드당 행동 버튼 1개. 스크롤 없이 끝나는 화면을 목표 |
| 아이콘·그림 | 아이콘은 하단 탭에도 쓰지 않고 글자만. 이모지 없음. **장면 그림(일러스트·마스코트)은 60갑자 세트에서만**: 오늘 화면 제목 옆에 그날 일진의 동물(`characters/{간지}.webp`)을 작게 하나, 공유 카드는 바이럴 카드를 그대로. 장면 그림을 새로 그리지 않는다. **재료 에셋(질감·테두리·패널·버튼면·괘선)은 생성한다**: 화면 명세의 "필요한 에셋" 절에 적고 `saju-assets`로 만들어 `ui-kit/`에 둔다 |
| 모션 | **운세가 열리는 순간**과 **저장이 끝나는 순간** 두 곳에만 300~600ms ease-out 전환 한 번. 반복 애니메이션·로딩 중 돌아가는 문구 없음 |
| 글 | 어미 "~어요" 통일. 금지어: 결·기운·흐름·두근. 숫자는 사실만("신해일 2번, 평균 8.0"), 기간 약속 금지("150일 더 쓰면") |
| 글자 크기 | 본문 16px 이상, 간지 한자 28px 이상. 침대에서 보는 화면이라 작게 만들지 않는다 |
| 산출물 | 피그마가 아니라 **코드로 바로**. 새 UI 라이브러리·애니메이션 패키지 설치 금지. CSS와 Tailwind 유틸리티로 해결 |

## 에셋 키트 — 디자인은 재료에서 시작한다

순서가 중요하다. **코드를 먼저 짜고 그림을 끼우지 않는다.**

1. **납품**: 화면 명세의 "필요한 에셋" 절대로 `saju-assets`가 재료를 만든다 (`에셋/사주 일기/ui-kit/`). 바탕 한지(타일), 카드 테두리(투명, border-image용), 밤하늘 패널, 금색 버튼면, 괘선. 전부 60갑자 카드와 같은 손 그림 질감으로.
2. **분석**: `analyze_kit.py`로 납품물의 색·밝기·대비·선 밀도를 **측정**해 `analysis.json`에 남기고, 그 수치로 아래 토큰 표를 갱신한다. 눈대중 hex를 쓰지 않는다.
3. **조립**: 디자이너는 그 이미지를 `public/ui/`로 복사(webp)하고, `globals.css`의 재료 클래스(`.hanji`, `.card-frame`, `.sky-panel`, `.gold-plate`, `.rule`)로 화면을 조립한다. 글자·배치·동작만 코드다.

키트 목록과 측정값은 `에셋/사주 일기/ui-kit/analysis.json`과 `manifest.json`에 있다. 토큰 표의 색은 이 측정값에서 온 것이고, 키트가 바뀌면 토큰도 다시 측정한다.

## 작업 경계 (기능 작업과 충돌 방지)

디자인 작업이 **고쳐도 되는 것**
- `src/app/globals.css` (토큰·전역 스타일)
- `src/components/**` 의 className·마크업 구조·모션
- `src/app/**/page.tsx`, `src/app/**/*Form.tsx` 의 **className과 JSX 구조**. 단 `props`, `name=` 속성, 서버 액션 호출, 데이터 읽는 코드는 그대로 둔다
- `public/characters/**` (바이럴 세트에서 복사만. 수정·생성 금지)
- `public/ui/**` (에셋 키트에서 복사만. 원본은 `에셋/사주 일기/ui-kit/`)

디자인 작업이 **건드리지 않는 것**

- 폼의 `name` 값과 `value` 값 (서버가 그 이름으로 읽는다)

## 개정 이유

v1은 "밤 11시 책상, 거의 검은 남색, 그림 없음"이었다. 바이럴 카드 60장(한지·수채·한복 입은 동물·남색 밤하늘 창)이 이미 완성돼 있고, 일기와 바이럴이 같은 세계여야 공유 카드가 자연스럽다. 또 v1은 사용자 취향(따뜻한 한지색, 수채, 귀엽고 가벼움)과 어긋났다. 그래서 바탕을 카드의 한지로 되돌리고, 남색은 "밤에 번지는 물감"으로만 남겼다. 60갑자 격자와 모션 두 곳, 글 규칙은 그대로다.

v3(2026-10-05): v2는 색과 바탕만 정하고 "물건"이 없어 화면이 문서처럼 보였다. 사용자가 스크린샷을 보고 서체·남색·버튼·카드 구분을 지적했다. 일기장의 물성(도장·띠지·손글씨·괘선)을 재료로 두면 버튼과 카드가 PPT 도형이 아니라 물건이 되고, "나" 화면 격자에 60갑자 카드 동물을 채우면 바이럴과의 연결이 눈에 보인다. 서체는 제목에 힘이 있는 송명, 본문은 바이럴과 같은 Pretendard, 사용자 글만 손글씨로 나눴다.
