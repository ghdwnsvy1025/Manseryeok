# 02 — 오늘 화면 · 운세 카드 · 저장 완료 전환

> 먼저 `00-톤.md`를 읽는다. `frontend-design` 스킬을 불러서 작업한다.
> 기능은 끝나 있다. 이 문서는 **보이는 것과 움직임**만 다룬다.

## 수정 가능 파일

- `src/app/page.tsx` — className과 JSX 구조. 데이터 읽는 코드(`getTodayFortune`, `getEntry`…)와 조건 분기는 그대로
- `src/components/FortuneCard.tsx` — 전부. 단 `<form action={fortuneVoteAction}>`, `name="date"`, `name="vote"`, `value="1" / "-1"`은 유지
- `src/app/write/EntryForm.tsx` — 저장 뒤 전환 연출. `name` 값과 `onSubmit` 로직은 유지
- `src/app/globals.css`

건드리지 않는 것: `src/lib/**`, `src/app/actions.ts`, `src/app/onboarding/ProfileForm.tsx`의 props

## 오늘 화면 구조 (지금 그대로, 순서만 시간대로 바뀜)

```
[날짜 한 줄]  10월 4일 일요일
[제목]        오늘은 신해일 辛亥        ← 신문 1면 제목. 화면에서 가장 크다
[카드 A]      운세 카드 (낮엔 위, 밤엔 아래)
[카드 B]      기록 카드 (밤엔 위, 낮엔 아래)
```

- 제목의 한자 `辛亥`는 명조 28px 이상, 한글 간지 `신해일`은 등불색이 아니라 **연보라(moon)**. 등불색은 버튼 하나에만.
- 카드는 두 장뿐. 세 번째 카드를 만들지 않는다.

## 운세 카드 (`FortuneCard`)

**닫힌 상태** — 봉투. 윗줄 "오늘의 운세", 아랫줄 "열어 보기". 오른쪽에 작은 `+`. 점수는 **보이지 않는다**.

**여는 순간** — `<details>`가 열릴 때 내용이 위에서 아래로 종이 펼쳐지듯 한 번. 400ms, ease-out, `grid-template-rows: 0fr → 1fr` 또는 `max-height` 전환. 반복 없음. 이 앱에서 모션이 허용된 두 곳 중 하나다.

**열린 상태**
```
오늘의 운세                               ×
좋음 · 7.1 /10
──────────────────────────────
차근차근 쌓이는 날                 ← 명조 22px, 카드 안에서 가장 크다
본문 2~3문장 (고딕 16px, 줄간격 1.6)

하면 좋아요   작은 목표 하나를 정해요
피해요        큰 계획을 새로 세우지 않아요

아직 내 기록이 없어 사주만으로 계산했어요   ← 작은 회색 한 줄 (fitPercent 문구)
오늘과 맞았어요?  [맞아요] [아니에요]      ← 로그인 때만
```
- 점수는 숫자 하나 + 그 아래 **얇은 가로선 눈금** (0~10을 10칸 점선으로, 점수까지 등불색). 원형 게이지·별점·이모지 금지.
- 밴드 색: 좋음/무난/주의 **모두 같은 색**. 색으로 길흉을 말하지 않는다. 글자만 다르다.
- 헤드라인 왼쪽에 세로 괘선 하나(등불색 2px)로 인용처럼 보이게.
- "하면 좋아요 / 피해요"는 두 줄 표. 라벨 열 너비 5.5rem 고정, 아이콘 없음.
- 투표 버튼은 pill. 눌린 쪽만 테두리 등불색, 나머지 회색. 누르면 페이지가 다시 그려진다(서버 액션). 별도 토스트 없음.

## 게스트 생년월일 폼 (카드 A 자리에 나옴)

- 제목 "오늘 운세, 생년월일만 넣으면 바로 보여요", 부제 "이 기기에만 남고 서버에 저장하지 않아요".
- 폼은 `ProfileForm`을 그대로 쓴다. 입력칸 높이 48px 유지. 성별·양음력 선택은 지금처럼 두 칸 세그먼트.
- 제출 버튼 "오늘 운세 보기"는 등불색. 이 화면에서 등불색은 이 버튼과 "Google로 시작하기" 둘뿐이라, **기록 카드가 아래로 가는 낮 시간에는** Google 버튼을 테두리만 있는 버튼으로 낮춘다 (등불색 면 버튼은 화면에 하나).

## 기록 카드 (카드 B)

- 기록 전: 제목 "오늘 하루, 어땠어요?" 명조. 버튼 "오늘 기록하기".
- 기록 후: 윗줄 작은 등불색 "저장했어요"(또는 "오늘 기록, 고마워요"), 제목 "오늘도 한 줄 남겼어요", 행복도 숫자, 메모 인용, 구분선, **"내일은 임자일이에요"** 한 줄. 이 한 줄이 내일 다시 오게 하는 문장이라 본문보다 살짝 크게(17px).

## 저장 완료 전환 (`EntryForm`, 두 번째 모션)

- 지금은 저장 뒤 `/?saved=날짜`로 이동한다. 이동 자체는 유지.
- 떠나기 직전 600ms: 폼 카드가 아래로 접히며(scaleY 1 → 0.96, opacity 1 → 0) 사라진다. 이동 뒤 오늘 화면의 기록 카드 "저장했어요" 줄이 150ms 늦게 나타난다. 색종이·폭죽·레벨업·XP 없음.
- 저장 버튼은 눌린 뒤 "저장하는 중…"으로 글자만 바뀐다. 스피너 없음.

## 하지 않는 것 (이 화면 한정)

- 회전 티저 문구, "두근두근", 로딩 중 명언
- 점수에 색 입히기, 원형 게이지
- 카드 테두리 그라데이션, 글로우
- 운세 본문 안 이모지
- 3개 이상의 카드
