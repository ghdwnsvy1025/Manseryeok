## 시간 장치 (`data-sky`)

`page.tsx`가 KST 시각으로 `day`(05~18) · `dusk`(18~21) · `night`(21~05)를 `<main data-sky="…">`에 적는다. `globals.css`가 `main[data-sky="dusk"]`, `main[data-sky="night"]`에 화면 위쪽에서 내려오는 남색(`sky`) 그라데이션을 고정 위치로 깐다. dusk는 옅게(상단 30%, 불투명도 낮음), night는 깊게(상단 45%). 바탕 한지는 그대로 보이고 글자색은 바뀌지 않는다. 카드 순서는 지금처럼 `night`(18~05)일 때 기록 카드가 위다.

## 오늘 화면 구조 (지금 그대로, 순서만 시간대로 바뀜)

```
[날짜 한 줄]  10월 4일 일요일
[제목]        오늘은 신해일 辛亥   [동물]   ← 신문 1면 제목. 화면에서 가장 크다
[카드 A]      운세 카드 (낮엔 위, 밤엔 아래)
[카드 B]      기록 카드 (밤엔 위, 낮엔 아래)
```

- 제목의 한자 `辛亥`는 명조 28px 이상, 한글 간지 `신해일`은 **남색(ganji)**. 금색은 버튼 하나에만.
- 제목 오른쪽에 그날 일진의 동물 `characters/{ganji.ko}.webp`를 56~64px로 하나. 장식 테두리 없음. `alt`는 `"{간지} 동물"`. 이 화면의 유일한 그림이다.
- 카드는 두 장뿐. 세 번째 카드를 만들지 않는다.
- 카드 공통: 바탕 `paper-2` 위에 키트 테두리(`.card-frame`, `card-frame.png` border-image). CSS border·그림자 없음. 바탕 한지는 body의 `.hanji`(paper-bg 타일).

## 운세 카드 (`FortuneCard`) — 밤하늘 패널

운세 카드만 바탕이 **남색(`sky`)**, 글자는 `sky-ink`다. 바이럴 카드의 "밤하늘 창"이 한지 위에 놓인 것처럼 보여야 한다. 테두리는 `frame`.

**닫힌 상태** — 봉투. 윗줄 "오늘의 운세"(`sky-muted`), 아랫줄 "열어 보기"(`sky-ink`). 오른쪽에 작은 `+`(금색). 점수는 **보이지 않는다**.

**여는 순간** — `<details>`가 열릴 때 내용이 위에서 아래로 종이 펼쳐지듯 한 번. 400ms, ease-out, `grid-template-rows: 0fr → 1fr` 또는 `max-height` 전환. 반복 없음. 이 앱에서 모션이 허용된 두 곳 중 하나다.

**열린 상태**
```
오늘의 운세                               ×
좋음 · 7.1 /10
··········●─────────                      ← 10칸 눈금, 점수까지 금색
차근차근 쌓이는 날                 ← 명조 22px, 카드 안에서 가장 크다
본문 2~3문장 (고딕 16px, 줄간격 1.6)

하면 좋아요   작은 목표 하나를 정해요
피해요        큰 계획을 새로 세우지 않아요

아직 내 기록이 없어 사주만으로 계산했어요   ← 작은 흐린 한 줄 (fitPercent 문구)
오늘과 맞았어요?  [맞아요] [아니에요]      ← 로그인 때만
```
- 점수는 숫자 하나 + 그 아래 **얇은 가로선 눈금** (0~10을 10칸 점선으로, 점수까지 금색). 원형 게이지·별점·이모지 금지.
- 밴드 색: 좋음/무난/주의 **모두 같은 색**(`sky-ink`). 색으로 길흉을 말하지 않는다. 글자만 다르다.
- 헤드라인 왼쪽에 세로 괘선 하나(금색 2px)로 인용처럼 보이게.
- "하면 좋아요 / 피해요"는 두 줄 표. 라벨 열 너비 5.5rem 고정, 아이콘 없음. 라벨은 `sky-muted`.
- 투표 버튼은 pill. 눌린 쪽만 테두리 금색, 나머지 `sky-muted` 테두리. 누르면 페이지가 다시 그려진다(서버 액션). 별도 토스트 없음.

## 게스트 생년월일 폼 (카드 A 자리에 나옴)

- 한지 카드(`paper-2`). 제목 "오늘 운세, 생년월일만 넣으면 바로 보여요", 부제 "이 기기에만 남고 서버에 저장하지 않아요".
- 폼은 `ProfileForm`을 그대로 쓴다. 입력칸 높이 48px 유지. 성별·양음력 선택은 지금처럼 두 칸 세그먼트.
- 제출 버튼 "오늘 운세 보기"는 금색 면 버튼. 이 화면에서 금색 면 버튼은 하나뿐이라, 이 폼이 보이는 동안 "Google로 시작하기"는 **테두리만 있는 버튼**(`frame` 테두리, `ink` 글자)으로 둔다. 게스트가 생년월일을 넣어 운세 카드가 보이는 상태에서는 금색 버튼이 Google 버튼 하나가 된다.

## 기록 카드 (카드 B)

- 한지 카드(`paper-2`).
- 기록 전: 제목 "오늘 하루, 어땠어요?" 명조. 버튼 "오늘 기록하기" 금색 면 버튼. (게스트 화면에서는 운세 폼의 버튼이 금색이므로, 로그인 카드의 Google 버튼은 테두리형.)
- 기록 후: 윗줄 작은 금색 "저장했어요"(또는 "오늘 기록, 고마워요"), 제목 "오늘도 한 줄 남겼어요", 행복도 숫자, 메모 인용, 구분선(`line`), **"내일은 임자일이에요"** 한 줄. 이 한 줄이 내일 다시 오게 하는 문장이라 본문보다 살짝 크게(17px). 간지는 남색.

## 저장 완료 전환 (`EntryForm`, 두 번째 모션)

- 지금은 저장 뒤 `/?saved=날짜`로 이동한다. 이동 자체는 유지.
- 떠나기 직전 600ms: 폼 카드가 아래로 접히며(scaleY 1 → 0.96, opacity 1 → 0) 사라진다. 이동 뒤 오늘 화면의 기록 카드 "저장했어요" 줄이 150ms 늦게 나타난다. 색종이·폭죽·레벨업·XP 없음.
- 저장 버튼은 눌린 뒤 "저장하는 중…"으로 글자만 바뀐다. 스피너 없음.

## 2026-10-05 수정 — 스크린샷 검토 뒤 고칠 것

375px 스크린샷(게스트, 낮)에서 발견. 아래 두 가지만 고친다. 로그인 카드·문구·카드 순서는 그대로.

1. **카드 테두리 이음새.** `.card-frame`(`border-image: url(/ui/card-frame-clean.png) 30 / 12px / 0 round`)에서 가로·세로 변 **가운데에 모서리 장식이 한 번 더 찍혀** 선이 끊긴 것처럼 보인다. 원인은 원본 1024px 테두리 이미지의 변 중앙에도 장식이 있고 `round`가 그걸 반복하기 때문. 고친 뒤 모습: **모서리 장식은 네 귀퉁이에만, 네 변은 매끈한 이중선.** 방법은 디자이너가 고른다 — (a) slice 값을 키워 귀퉁이 장식 전체를 코너 조각에 넣고 변은 장식 없는 구간만 잘라 `repeat`/`stretch`, (b) 키트 테두리 이미지를 변이 매끈한 판으로 다시 납품(`saju-assets`, 투명 1024, 네 귀퉁이에만 장식)하고 `analyze_kit.py`로 측정. (a)가 되면 (a). 어느 쪽이든 카드 네 귀퉁이가 잘리거나 늘어나 보이면 안 된다.
2. **점수 아래 장식 겹침.** 열린 운세 카드에서 점수(`좋음 · 7.1/10`) 바로 아래에 금색 붓선(`.rule`, divider)과 10칸 점선 눈금이 **연달아 두 줄** 있어 과하다. 명세대로 **점선 눈금 하나만** 남긴다. 붓선 구분선은 본문과 "하면 좋아요/피해요" 표 사이, 또는 표와 맨 아래 흐린 한 줄 사이 중 **한 곳**에만 둔다. 카드 안에 `.rule`은 최대 1개.

오른쪽 위 금색 `×`는 `<details>` 열림 표시(닫힘 `+`)라 명세대로다. 건드리지 않는다.

확인: 375px에서 카드 네 변이 끊김 없이 이어지는지(한지 카드 2장 모두), 운세 카드에 눈금 1줄·붓선 최대 1줄인지, `npx tsc --noEmit`·`npm test` 통과.

> 2026-10-05 처리: 1은 (a)로 해결 — `public/ui/card-frame-clean.png`(512px 사본)의 귀퉁이 괘 장식이 x≈8~36px까지라 slice를 30→40으로 키우고, 변 조각은 장식 없는 이중선뿐이라 `round`→`stretch`, 테두리 폭 12→14px(귀퉁이 장식이 뭉개지지 않는 최소 폭). 재납품 없음. 2는 점수 아래 `.rule` 삭제, 표와 흐린 한 줄 사이에 하나만 둠.

### 첫 화면 순서
00 v3 "첫 화면 순서" 그대로. 제목 아래 **60칸 띠**: 높이 10~12px의 가로 한 줄 60칸(또는 30칸×2줄). 오늘 칸 금색, 기록한 간지 칸은 녹갈 흐린 점, 나머지는 괘선. 링크로 `/me`. 데이터가 page.tsx에 없으면(로그인 사용자의 간지별 기록) **오늘 칸만 표시하고 나머지 표시는 "남긴 것"으로 보고**한다.

### 운세 카드 머리
```
10월 5일 · 임자일의 운세          +/×   ← Pretendard 15px sky-muted. 날짜·간지가 카드 안에
무난                                     ← Song Myung 44px sky-ink, 카드의 주인공
━━━━━━━━━━░░░░░░░░░░  5.3               ← 눈금 굵게(4px), 점수 숫자는 오른쪽에 작게(17px)
책임감이 필요한 날                        ← Song Myung 24px, 왼쪽 금색 세로선
```
- **닫힌 상태**도 날짜·간지와 밴드 단어("무난")까지는 보인다. 열면 눈금·제목·본문·하면/피해요. (v2의 "점수는 닫힌 상태에서 보이지 않는다"는 폐기: 밴드 단어는 보이고, 숫자·눈금만 열어야 보인다.)
- 바탕은 `sky-panel-warm`. 아래쪽 금빛 번짐 위의 글자도 대비 4.5:1 이상.

### 오늘의 기록 카드 (기록 후)
```
오늘의 기록                         고치기   ← Pretendard 14px muted / 오른쪽 링크(→ /write?date=)
7                                           ← Song Myung 48px, 행복도. 옆에 작게 "/10"
[차분] [뿌듯]                               ← 고른 기분을 띠지(tag-strip 남색)로
 ───────────────────────────
  오늘은 산책을 오래 했다                    ← Nanum Pen Script 22px, ruled-paper 괘선 위
 ───────────────────────────
내일은 계축일이에요                          ← 17px, 간지 남색
```
- "오늘도 한 줄 남겼어요", "고마워요" 같은 앱 인사말 제목은 없앤다. 저장 직후(`?saved=`)에만 맨 위에 작은 금색 "저장했어요"가 150ms 늦게 나타난다(v2 모션 유지).
- 메모가 없으면 괘선 자리에 흐린 "한 줄은 안 남겼어요" 대신 **괘선 영역 자체를 생략**.
