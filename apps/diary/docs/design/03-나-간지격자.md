# 03 — "나" 화면 · 60갑자 격자 · 맞춤도

> 먼저 `00-톤.md`. `frontend-design` 스킬로 작업. 기능은 끝나 있고 이 문서는 보이는 것만 다룬다.

## 수정 가능 파일
- `src/components/GanjiGrid.tsx` — 전부. 단 `href`(`?cell=N` / basePath), `aria-label`, `aria-current`, `scroll={false}`는 유지
- `src/components/StatsSummary.tsx` — 전부. 숫자·문장 내용은 유지(기간 약속 문구 추가 금지)
- `src/app/me/page.tsx` — className과 JSX 구조. 데이터 읽는 코드와 `searchParams.cell` 처리는 그대로
- `src/app/globals.css`

건드리지 않는 것: `src/lib/**`

## 격자 (서명 요소)
- 10×6. 열 = 천간(甲…癸), 각 칸 글자는 지지 한 자. 위에 천간 10자가 열 제목으로 얇게.
- 기록 있는 칸: 평균 행복도에 따라 금색 농도 (1 → 옅게, 10 → 진하게). 없는 칸: 괘선만.
- 오늘 칸: 테두리만 다른 색(간지색). 선택 칸: 먹색 테두리. 두 상태가 겹치면 선택이 이긴다.
- 칸 사이 간격 4px, 모서리 작게. 칸 안에 숫자·점·이모지 넣지 않는다.
- 칸을 누르면 아래 한 줄 "신해일 2번 · 평균 행복도 8.5 · 신호 약함"이 바뀐다. 전환 효과 없음(모션 예산은 운세·저장 두 곳뿐).

## 맞춤도
- 숫자 % 명조 큰 글자 + 아래 얇은 선 하나. 선 옆에 "기록 10일 · 평균 행복도 6.4 · 아직 안 겪은 간지 52개". 원형 게이지 금지, "150일 더 쓰면" 류 금지.

## 사실 줄
- 왼쪽 금색 세로선 2px, 한 줄씩. 최대 4줄. 아이콘 없음.

## 천간별 · 지지별 · 오행별
- `<details>` 세 개, 접힌 상태가 기본. 펼치면 가로 막대(배경 괘선색, 채움 금색) + 오른쪽 "평균 / 횟수". 기록 없는 줄은 흐린 글자, 막대 0.

## 내 사주 네 기둥 / 내 기록 목록
- 지금 구조 유지. 한자 28px 이상. 기록 목록 왼쪽 숫자 칸은 행복도.

## 끝났을 때 확인
- `npx tsc --noEmit`, `npm test` 통과 · 375px에서 가로 스크롤 없음 · 격자 60칸, `?cell=47` 선택 표시

### 격자 = 도장판 + 카드 앨범
- 10×6 유지. 칸 안: **기록 없는 칸** = 빈 도장 자리 + 지지 한 글자(흐리게). **기록 있는 칸** = 그 간지 동물 작게(칸 폭의 70%) + 칸 테두리 금빛, 금빛 농도는 평균 행복도(1 옅게 → 10 진하게). 지지 글자는 칸 아래 작게.
- v2의 "칸 안에 그림 넣지 않는다"는 이 화면에서 폐기. 숫자·이모지는 여전히 넣지 않는다.
- 오늘 칸 = 남색 테두리, 선택 칸 = 먹색 두꺼운 테두리.
- 칸이 작아 동물이 뭉개지면 칸을 정사각 유지하고 격자 좌우 여백을 줄인다(375px에서 칸 ≥ 30px). 그래도 안 되면 동물 대신 금빛 도장 자국만 두고 "남긴 것"으로 보고.
- 이미지 60장은 `loading="lazy"`, 크기 고정(레이아웃 흔들림 없게).

### 네 기둥
- 나무패 4개를 가로로. 패 안에 천간·지지 한자 세로로(명조 28px 이상), 패 아래 "시·일·월·년" Pretendard 13px. 일주 패만 금빛 테두리.

### 맞춤도·숫자
- 큰 숫자는 Song Myung. 섹션 제목("간지별 내 행복도", "내 기록")도 Song Myung 22px.

### 내 기록 목록
- 한 줄 = 왼쪽 행복도 숫자(Song Myung 24px) · 날짜·간지 · 메모 한 줄(Nanum Pen Script 20px) · 기분은 작은 띠지.
- 카드 종이 `card-paper`, 카드 사이 대비가 바탕과 분명하게.

### 하지 않는 것
- 진행률 바·"N개 더 모으면" 문구·배지 (수집은 보이게만, 재촉하지 않는다)

## v3.2 — 나무패 정보 · 카드 앨범 · 통계 펼침 (2026-10-06, 위보다 우선)

> 00-톤.md v3.2 "오행 색"·"나 화면" 절이 명세다.
- 나무패: 천간/지지 한자 + 십신 한글 + 오행 글자 + 오행 점(토큰 wood/fire/earth/metal/water, 패 안에서만). 십신은 `@saju/core-rules`의 `tenGod` 또는 `@saju/engine`의 `getTenGod`로 일간 기준 계산(일주 천간은 "나"). 데이터 계산은 `me/page.tsx` 서버 쪽에서 한 번 하고 props로.
- 격자 칸: 모은 칸 = `public/cards/{간지}.webp` cover 썸네일 + 금 테두리(농도 = 평균 행복도, 약속 지킨 날 있으면 2px 고정) + 오른쪽 아래 `seal-collected` 10px. 안 모은 칸 = 빈 도장 자리 + 지지 글자.
- 선택 칸 상세: 카드 크게(폭 60%) + 숫자 줄 + 기록 목록. 기존 `?cell=` 유지.
- 천간·지지·오행별 details: 기록 ≥1이면 `open`. 0이면 안내 문장.
- 에셋: `seal-collected` 1장 생성. 썸네일은 `cards/` 60장 재사용(필요하면 `public/cards-thumb/` 160px로 줄여 복사).
- 확인: 375px 칸 ≥30px, 격자 60칸 이미지 lazy, 가로 스크롤 없음, 오행 점이 격자·운세에 번지지 않았는지.
