# 04 — 저녁 알림 · 앱으로 두기 · 공유 카드

> 먼저 `00-톤.md`. `frontend-design` 스킬로 작업. 기능은 끝나 있다.

## 수정 가능 파일
- `src/components/NotificationSettings.tsx`, `InstallHint.tsx`, `ShareCard.tsx` — className·마크업. 버튼의 onClick·form `name="hour"`·action은 유지
- `src/lib/shareCanvas.ts` — 카드 그림(색·배치·글꼴 크기). 1080×1350과 `drawShareCard(canvas, text, characterSrc)` 시그니처는 유지
- `src/app/me/page.tsx` — "내일도 오게" 섹션의 className
- `public/icons/*` — 앱 아이콘 교체 (지금은 레거시 벚꽃 아이콘). 192·512·maskable 192·512·apple-touch 180 모두 바꾼다. `manifest.webmanifest`의 파일명은 유지

## 알림 카드
- 한 줄 제목 "저녁 알림" + 상태 문장 + 오른쪽 pill 버튼 하나(켜기/끄기). 켜져 있으면 아래 "알림 시각 [21시 ▾] 바꾸기".
- 토글 스위치 그림 금지. 아이콘 금지. 켜진 상태도 색을 바꾸지 않고 글자("끄기")로만 구분.
- 카카오 채널 줄은 구분선 아래 작은 글 + 밑줄 링크.

## 앱으로 두기
- 설치돼 있으면 아예 안 보인다(컴포넌트가 처리). 안 돼 있으면 번호 매긴 3줄. 그림·화살표 없음.
- `beforeinstallprompt`가 오면 버튼 "앱으로 설치" 하나만.

## 공유 카드 (서명 요소를 밖으로 내보내는 유일한 그림)
- 한지 바탕, 녹갈색 테두리, 왼쪽 위 작은 설명 → 큰 한자(간지색 명조 150px) + 한글 간지 → 가운데 캐릭터(바이럴 60갑자 캐릭터 webp) → 한 줄 사실 → 아래 구분선 + 왼쪽 "기록 N일 · 60가지 날 중 M가지" + 오른쪽 금색 "사주읽는밤 일기".
- 배경 장식·별·그라데이션 없음. 글은 세 덩어리만.
- 캐릭터 그림을 바꾸고 싶으면 `public/characters/<간지>.webp` 60장을 같은 이름으로 교체한다.

## 끝났을 때 확인

- 로그인 → 나 탭에서 "카드 공유" 누르면 공유 시트(모바일) 또는 PNG 내려받기(데스크톱)가 뜬다
- 375px에서 가로 스크롤 없음
