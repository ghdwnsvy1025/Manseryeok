# 05 — 쓰기 화면 (v3 밤의 일기장)

> 먼저 `00-톤.md`(v3 절 우선)를 읽는다. `frontend-design` 스킬을 불러서 작업한다. 기능은 끝나 있다. 보이는 것만 다룬다.

## 수정 가능 파일
- `src/app/write/EntryForm.tsx` — className·JSX 구조·시각 상태. **`name="happiness"`·`name="moods"`·`name="note"` 등 name/value, `onSubmit` 로직, 저장 뒤 이동, 최대 기분 개수 처리는 그대로**
- `src/app/write/page.tsx` — className과 JSX 구조만
- `src/app/globals.css`
- `public/ui/**` (키트에서 복사)

건드리지 않는 것: `src/lib/**`, `src/app/actions.ts`, 폼 필드 이름

## 필요한 에셋
| 에셋 | 생성 | 쓰임 |
|---|---|---|
| `ui-kit/stamp-empty` (투명 256) | 생성 | 행복도 안 고름: 한지에 눌린 둥근 빈 도장 자리, 녹갈 흐린 테두리 |
| `ui-kit/stamp-inked` (투명 256) | 생성 | 행복도 고름: 금빛 인주로 찍힌 둥근 도장 자국(가장자리 번짐, 가운데는 비워 숫자를 얹음). 글자 없음 |
| `ui-kit/tag-strip` (투명 512×160, 2종: 한지 / 남색 물들임) | 생성 | 기분 띠지. 양 끝이 손으로 찢긴 짧은 한지 띠 |
| `ui-kit/ruled-paper` | 02와 공용 | 메모 입력칸 괘선 |
| `ui-kit/card-paper` | 02와 공용 | 폼 카드 |

숫자(1~10)와 기분 글자는 이미지에 넣지 않고 코드 글자로 얹는다.

## 화면 구조
```
[제목]  10월 5일 임자일, 오늘 하루         ← Song Myung 26px, 간지 남색
[카드 종이 한 장]
  행복도                                   ← Pretendard 17px bold
  ( 1 )( 2 )( 3 )( 4 )( 5 )                ← 도장 5×2. 지름 52px 이상
  ( 6 )( 7 )( 8 )( 9 )(10 )
  기분 · 3개까지                            
  [차분][뿌듯][지침][설렘] …                ← 띠지, 줄바꿈
  한 줄                                     
  ─────────────────────                    ← 괘선 위에 입력, 입력 글자는 Nanum Pen Script 22px
  ─────────────────────
[금색 면 버튼] 저장하기                      ← 화면에 금색 면은 이것 하나
```

## 상태별 모습
- **도장 안 고름**: `stamp-empty` 위에 숫자 Song Myung 22px 녹갈(`muted`보다 진하게, 바탕과 대비 4.5:1 이상).
- **도장 고름**: `stamp-inked`로 바뀌고 숫자는 `gold-ink`(진한 갈색). 120ms 눌림(scale 0.94→1) 한 번. 한 번에 하나만.
- **띠지 안 고름**: 한지 띠 + `ink` 글자 15px. **고름**: 남색 물들인 띠 + `sky-ink` 글자. 최대 개수에 닿으면 안 고른 띠지는 흐리게(opacity .45).
- **포커스**: 키보드 포커스는 금색 2px 외곽선(접근성 유지).
- **행복도 없이 저장**: 기존 안내 문구 그대로, 도장 줄 위에 `danger` 글자.
- **저장 중**: 버튼 글자만 "저장하는 중…". 저장 뒤 접히는 전환(v2) 유지.

## 대비 (사용자 지적: 색이 바탕과 겹쳐 안 보임)
- 카드 종이(`card-paper`)는 바탕 한지보다 확실히 밝게. 도장·띠지 테두리는 녹갈 진하게. 375px 스크린샷에서 **카드 경계, 빈 도장, 안 고른 띠지가 바탕과 구분되는지** 확인해 보고.

## 하지 않는 것
- 둥근 사각형 테두리 버튼(PPT 도형), 그라데이션, 그림자
- 이모지 기분 아이콘
- 손글씨체를 라벨·버튼에 쓰기

## 끝났을 때 확인
- `npx tsc --noEmit`, `npm test` 통과
- 로그인이 필요한 화면이라 개발 서버에서 직접 못 보면, 임시 미리보기 경로를 만들지 말고 **컴포넌트를 정적 HTML로 렌더한 스크린샷이나 스토리 없이 코드 대조**로 보고하고 "사용자 확인 필요"로 남긴다
- 375px 가로 스크롤 없음

## v3.1 — 저장 완료 "팡" (2026-10-05 저녁)

> 00-톤.md "v3.1 — 팡" 절이 명세다. 여기엔 파일만 적는다.

- 수정: `EntryForm.tsx` 저장 성공 분기(접힘 전환 → 보상 팝업), `globals.css`(팝업·흩날림 키프레임), 새 컴포넌트 `src/components/SaveBurst.tsx` 허용.
- 필요한 에셋: `public/cards/{간지}.webp` 60장(`에셋/바이럴/cards`에서 복사, 폭 768 이하로 줄여도 됨), `ui-kit/pop-paper-bits`·`ui-kit/pop-gold-dust` 2장 생성 → `public/ui/`.
- 확인: 저장 → 카드 팡 → 조각 흩날림 → 1.5초 뒤 오늘 화면. reduced-motion에서 흩날림 없음. 로그인이 필요하므로 실제 저장은 사용자 확인, 팝업 자체는 `/`에 임시 주입하지 말고 컴포넌트 단독 렌더로 확인.
- **구현 메모 (2026-10-05 구현 시)**: `saveEntryAction`(actions.ts, 기능 파일)이 성공하면 서버에서 바로 `redirect("/?saved=날짜")`를 하므로, `EntryForm`은 성공 신호를 받기 전에 언마운트된다. 그래서 `SaveBurst`는 **오늘 화면 `page.tsx`에서 `saved === today && entry`일 때** 마운트한다(저장 성공이 보장된 자리). 같은 저장을 두 번 터뜨리지 않도록 `sessionStorage`에 날짜+내용 열쇠를 남긴다. 5단계의 "1.5초 뒤 이동"은 "1.5초 뒤 오버레이가 걷히며 이미 와 있는 오늘 화면이 드러남"으로 읽는다. `EntryForm`의 접힘 전환은 제거했고, 과거 날짜 기록(`/write?date=…`) 저장에는 팡이 뜨지 않는다(오늘 화면이 그 날의 기록을 읽지 않음).
- 조각 시트의 좌표: `에셋/사주 일기/ui-kit/pop-pieces.json` (알파 후처리본 `*-clean.png`에서 측정). 카드 뒤에서 시작하면 가려지므로 조각은 카드 가장자리(거리의 50%)에서 나타나 200~290px까지 날아간다.

## v3.2 — 인주 도장 · 오늘의 작은 약속 · 팡 도장 (2026-10-06, 위보다 우선)

> 00-톤.md v3.2 "인주"·"팡 + 작은 약속" 절이 명세다.
- 행복도 도장 찍힌 상태 = `stamp-inked-red`(새 에셋), 숫자 한지색. `stamp-inked`(금)는 더 쓰지 않음.
- 쓰기 화면 맨 위 "오늘 약속" 금색 띠지 + 세그먼트 3칸 `name="promise"` value `kept|missed|na`(기능 쪽이 받는다 — `EntryForm`에 필드가 이미 있으면 그 이름을 따른다, 없으면 이 이름으로 추가하고 보고에 "기능 쪽 저장 필요"로 남긴다). 그날 운세의 do 문장을 props로 받음.
- `SaveBurst.tsx`: 카드 오른쪽 아래 행복도 도장 꽝(150ms 지연, scale 1.4→1, 120ms). 약속 지킨 날(`promise==="kept"`)이면 카드 테두리 금 2px.
- 에셋: `stamp-inked-red` 1장 생성.
- 확인: 도장 안 고름/고름 대비, 약속 띠지가 운세 없을 때(게스트 첫날 등) 생략되는지, reduced-motion.
