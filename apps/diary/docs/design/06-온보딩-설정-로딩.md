## 온보딩 = 호적 서류
00 v3.2 "생년월일 입력" 절 그대로. 제목 "태어난 날을 적어요"(Song Myung 26px). 양식지 위 칸: 연(4자리)·월·일 한 줄, 시·분 한 줄 + "시간을 몰라요" 띠지 토글. 성별·양음력(·윤달) 띠지. 도시. 금색 버튼 "오늘 운세 보기". 익명이라 이름 칸 없음(기능 쪽이 이름을 "손님"으로 보냄 — `name="name"` hidden 유지).

## 설정
한지 카드 한 장에 목록: Google 연결(상태 + 버튼 또는 이메일) / 알림(NotificationSettings) / 생년월일 고치기 → `/onboarding` / 앱으로 두기(InstallHint) / 맨 아래 흐린 글자 링크 "로그아웃" 또는 "이 기기의 기록 지우기". 금색 면 버튼은 Google 연결 하나만. 나머지는 글자 링크·테두리 버튼.

## 로딩
00 v3.2 "로딩" 절. `loading.tsx` 셋은 같은 뼈대 컴포넌트 `PageSkeleton`(제목 자리 + 빈 카드 n장)을 쓴다. `FortuneLoading`은 열린 운세 카드 틀(`card-gold card-paper`) 안에 붓선 + "오늘 글자를 읽고 있어요".

## 하지 않는 것
스피너·shimmer·회전, 기본 HTML select 모양 그대로 두기(한지색으로 덮기), 입력칸을 절대 위치로 양식지에 맞추기
