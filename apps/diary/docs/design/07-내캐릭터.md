## 화면별
- 오늘: 00 v3.3 표 + "60칸 띠 삭제" 절. `BandHint.tsx`는 지우지 말고 미사용으로 두되 import 제거.
- 운세 카드: 동물 삭제. 머리 오른쪽은 `+/×`만.
- 쓰기 팡(`SaveBurst`): 내 일주 카드, 인주 도장, 지난 도장 점(최근 7개, 카드 아래 가장자리 안쪽, 12px, 간격 6px), 글자 "기축 카드에 오늘 도장을 찍었어요". `kept`면 금테 2px(유지).
- 나: 제목 영역 = 내 카드(폭 56%, 가운데) + 아래 "{이름} · 기축일 · 소"(Song Myung 20px) + 오른쪽 위 "설정". 격자 칸 = 캐릭터만 + 금 테두리 농도 + 약속 두 겹.
- 온보딩: 양식지 제거, 입력칸·세그먼트 규칙(00 v3.3). 버튼 "내 카드 보기".
- welcome: 한지 바탕 가운데 내 카드 팡(SaveBurst의 팡 키프레임 재사용, 도장 없음) → 150ms 뒤 "당신의 카드는 기축 · 소예요"(Song Myung 24px) + 한 줄 "60갑자 중 당신의 날이에요. 매일 밤 한 줄이 이 카드에 쌓여요"(16px) + 금색 버튼 "오늘 운세 보기". 자동 이동 없음(버튼으로만).
- 로딩: `FortuneLoading`에 `character?: string` prop — 있으면 캐릭터 48px + 글자, 없으면 붓선. `PageSkeleton`은 그대로.
- 공유 카드: 카드 이미지를 내 일주 카드로(기능이 경로 넘김).
