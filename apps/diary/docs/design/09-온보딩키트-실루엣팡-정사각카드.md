## 1. 온보딩 입력칸 — 결정 A + C
- **A. 입력칸 하나하나**(연·월·일·시·분, 도시 select): 밋밋한 네모 → 오늘 화면 '신호 상자'(`.signal-box`)와 같은 재질. 한지색(paper-3) 바탕 + 녹갈 1px 선 + 모서리 살짝(4~6px) + 안쪽 아주 옅은 종이결(card-paper를 작게 타일링하거나 paper-3 단색이면 그대로). 숫자 Song Myung 22px 먹색. 상태 규칙(빈 칸 흐림 / 입력 중 금색 2px / 채움 먹색 / 오류 먹색 1.5px + danger 한 줄)은 v3.3 그대로. 높이 56px·44px 터치 유지. select도 같은 상자(네이티브 화살표 숨기고 ▾ 유지).
- **C. 세그먼트**(양력/음력, 남/여, 시간 알아요/몰라요): 쓰기 화면의 **띠지 `.tag`**(tag-strip-paper, 고른 쪽 `input:checked + .tag` 규칙)로 바꾼다. 도장(`.stamp`)은 행복도 전용이라 쓰지 않는다. 윤달 체크 한 줄은 띠지 하나(고르면 inked).
- **B(묶음마다 작은 틀)는 하지 않는다** — 틀 안의 틀 금지(설정 화면에서 뺀 이유와 같음). 바깥 `card-frame card-paper` 한 장은 그대로.
- 묶음 라벨(태어난 날 / 태어난 시간 / 태어난 곳 / 성별)은 14px 보조색 그대로. 지역 설명 13px 줄은 라벨 아래 그대로.
- 금색 버튼 "내 카드 보기"는 그대로.

## 2. welcome — 실루엣 → 팡 → 정사각 카드 (결정 A·A)
구조(`SaveBurst` reveal 가지): 상태 `"silhouette" → "open"`.
- **실루엣(0~1.2초)**: 정사각 틀(1:1, 폭 62vw·최대 320px — 지금 카드 자리와 같음) 안에 `characterSrc` 컷아웃을 **검게**(CSS `filter: brightness(0)`; 투명 배경이라 동물 형태만 검다) 가운데 배치, 틀 바탕은 paper-2. 틀은 `char-frame`을 1:1로 쓰거나 `card-frame`의 테두리를 1:1 상자에 입힌다. 아래 글자 "당신의 카드를 찾고 있어요"(16px 보조색). 숨 쉬는 모션·스피너 없음(00 "하지 않는 것"). 실루엣은 자리에 그냥 있다 — 정지가 긴장이다.
- **팡(1.2초 시점)**: 기존 팡 키프레임(조각 16개 흩날림 + 카드 scale 0.9→1) 그대로. 실루엣 틀이 **같은 자리·같은 크기의 정사각 카드**(`cardSrc`)로 바뀐다 — 크기가 튀면 안 된다. 실루엣 글자는 사라지고 150ms 뒤 "당신의 카드는 기축 · 소예요" + 설명 + 금색 버튼(지금 순서).
- **자동**: 탭 없이 1.2초 뒤 저절로. `prefers-reduced-motion`이면 실루엣 0.6초 뒤 조각 없이 교체.
- 이미지 미리 받기: 실루엣 동안 `cardSrc`를 `new Image()`로 받아 둔다(팡 때 빈 틀 금지 — B8과 같은 원칙). 1.2초가 지났는데 아직 안 받아졌으면 받아진 뒤 팡(최대 3초, 그 뒤엔 그냥 교체).
- 생년월일 **고치기**(설정 → 온보딩 편집)는 welcome을 거치지 않는다(기능 그대로). 실루엣 연출은 처음 한 번만.

## 3. 정사각 카드가 쓰이는 곳(결정 B)
- welcome(위), **나 화면 머리**(폭 56%였던 3:4 → 정사각은 폭 52~56% 유지하되 높이가 줄어드니 아래 "{이름} · 기축일 · 소" 간격 다시 맞춤), **공유 캔버스**(560×560, 아래 글 블록 여백 재계산 — 1080×1920 안에서 세로 균형).
- 쓰기 저장 팡(save 모드)은 v3.5 그대로(일진 캐릭터 + char-frame + 점수). 건드리지 않는다.

## 모션
팡 키프레임·조각은 기존 것. 새 keyframe은 실루엣→카드 교체(opacity 교차 120ms)만.
