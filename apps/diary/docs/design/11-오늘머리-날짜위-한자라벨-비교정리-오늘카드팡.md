# 11 — 오늘 머리(날짜 위·한자 라벨) · 비교 블록 정리 · 저장 팡 = 오늘 정사각 카드 · 나 머리 기록 줄 (v3.10)

> 먼저 `00-톤.md`(v3.9 절까지). `frontend-design` 스킬로 작업. 2026-10-08 사용자 결정(grill 5문답: 날짜 위 한 줄 / 라벨 한자만 / 비교 제목 삭제 + 작은 한 줄 / 판정 기준 밴드 폭 / 저장 팡 = 오늘 정사각 카드). 기능 쪽은 끝나 있다. 디자이너는 모양만.

## 기능이 넣어 둔 것
- `page.tsx` 머리: `<h1 class="today-date">`("10월 8일 목요일", 16px muted) → `.medal-pair`. 라벨 구조 `.medal-pair__label` > `.medal-pair__who`("나"/"오늘") + `.medal-pair__hanja`("己丑"/"乙卯", lang=zh-Hant). 순번·기록 일수 줄은 삭제됨.
- `FortuneCard.tsx` `.compare`: 제목 없음. 순서 `.compare__bars` → `.compare__verdict` 띠지 → `.compare__sub`("경진일에 3번 기록 · 평균 6.2") → `.compare__note`. 기록 없으면 `.compare__empty`만. 점수 환산 버그(11.4) 고침, 판정 기준 2.0/1.0.
- `SaveBurst.tsx` save 모드: `cardSrc`가 있으면 `.burst-card.today-card` > `<img>`(오늘 일진 정사각 카드 1080×1080) + `.burst-stamp`(행복도). 기존 `.char-card` 가지는 폴백으로 남아 있음. `data-kept`는 그대로 그 div에.
- `me/page.tsx` 머리: h1 아래 `.me-progress`("기록 12일째 · 60칸 중 9칸", 14px muted).

## 수정 가능 파일
`src/app/page.tsx`(className·구조), `src/components/SaveBurst.tsx`(className·구조만, 상태·타이머·props 유지), `src/components/FortuneCard.tsx`(className만), `src/app/me/page.tsx`(className만), `src/app/globals.css`, `docs/design/00-톤.md`(v3.10 절). 건드리지 않는 것: `src/lib/**`, actions, 데이터·조건식, 폼 name/value.

## 필요한 에셋
없음(키트 재사용: stamp-inked-red, tag-strip-paper, gold-wash).

## 1. 오늘 머리
- 위 한 줄 `.today-date`: Pretendard 16px muted, 가운데. 아래 캐릭터 쌍과 간격 14px.
- 캐릭터 100px 틀 그대로. 라벨: `.medal-pair__who` 13px muted → 바로 아래 `.medal-pair__hanja` **Song Myung 22px 먹색**(간지색 text-ganji 써도 됨 — 둘 다 같은 색), 한글 없음. 두 줄 간격 2px. 라벨 폭은 틀 폭(100px) 안에서 가운데.
- × 는 그대로(송명 20px muted).
- 운세 카드와 간격 20px.

## 2. 비교 블록(`.compare`)
- 제목이 없어졌으니 상자 위 여백 14px. 막대 두 줄 → 띠지 판정(가운데 또는 왼쪽, 지금 규칙) → `.compare__sub` 13px muted 한 줄 → `.compare__note`(맞춤도) 13px muted. 두 작은 줄 사이 2px.
- `.compare__empty` 16px ink 그대로.

## 3. 저장 팡 = 오늘 정사각 카드 (`.today-card`)
- 카드 이미지 전체 폭(62vw·최대 320px, 1:1). 카드 자체가 테두리를 가지므로 틀 없음.
- `.burst-stamp`(행복도 숫자, 인주 도장 키트)는 **오른쪽 아래 모서리 안쪽**(right 10px · bottom 10px), 지름 64px, 살짝 기울기(−8°), 카드 팡 150ms 뒤 꽝(기존 키프레임). 숫자 한지색 Song Myung 28px.
- `data-kept`(포인트 해봤어요)면 금테 2px — 기존 규칙을 `.today-card`에도.
- 지난 도장 점(`.burst-past`)·글자·확인 버튼은 그대로. 글자는 "{ganjiKo}일 카드에 오늘 도장을 찍었어요" 유지.
- `.char-card` 규칙은 지우지 말 것(폴백).

## 4. 나 머리
- `.me-progress` 14px muted, h1 아래 4px. 익명 안내 줄이 있으면 그 위.
