> 먼저 `00-톤.md`(v3.10 절까지). `frontend-design` 스킬로 작업. 2026-10-09 사용자 결정(grill 7문답). 기능 쪽은 끝나 있다. 디자이너는 모양만.

## 기능이 넣어 둔 것
- 정사각 카드 60장 가장자리 검은 띠(0~7px) 잘라 재저장, 주소에 `?v=2`(캐시 무효화). 화면 쪽 할 일 없음 — 카드에 검은 테두리·그림자·outline을 CSS로 더하지 말 것.
- `me/page.tsx` 기둥 라벨: "시"·"일"·"월"·"년"만(일주 이름 삭제).
- `FortuneCard.tsx` `.score-brush[data-band="좋음"|"무난"|"주의"]`.
- `GanjiGrid.tsx` 칸 상세: `.grid-card` 정사각 카드(폭 56%·최대 220px). 기록 없는 칸은 `[data-unmet]` + "아직 못 만난 카드예요".
- `StatsSummary.tsx` 새 구조: 맞춤도 카드 안 `.meter > .meter__fill`(width %) / `.metrics > .metric`×3(`__label`, `__value`(+`small` 단위), `__sub`; 기분 칸은 `.metric--moods` > `.metric__chips > .metric__chip`(+`small` 횟수)) / 그래프 카드(`HappinessChart`) / 사실 줄 / "글자별 내 행복도" 카드 안 `.bars[data-kind]` > `.bars__title` + `.bars__row`(grid, 열 수 인라인) > `.bars__col[data-empty][data-el=목|화|토|금|수]` > `.bars__value`, `.bars__track > .bars__fill`(height %), `.bars__label`, `.bars__n`.
- `HappinessChart.tsx`(SVG 320×150): `.hchart__grid`(가로 눈금 0·5·10), `.hchart__axis`(글자), `.hchart__fortune`(운세 점수 꺾은선, 빈 날 끊김), `.hchart__avg`(7일 평균), `.hchart__dot`(행복도 점), `.hchart__legend > .hchart__key--dot|--avg|--fortune`, 빈 상태 `.hchart__empty`.

## 수정 가능 파일
`src/app/globals.css`(위 클래스 전부), `src/components/{StatsSummary,HappinessChart,GanjiGrid}.tsx`(className·마크업 배치만; 계산식·데이터·링크 유지), `src/app/me/page.tsx`(className만), `src/components/FortuneCard.tsx`(className만), `docs/design/00-톤.md`(v3.11 절). 건드리지 않는 것: `src/lib/**`, actions, `public/cards-square/**`, 계산식.

## 필요한 에셋
없음(키트 재사용: gold-wash, card-paper, tag-strip-paper).

## 1. 운세 단계별 붓 색 (Q1 = A)
- 카드 바탕은 그대로. `.score-brush` 뒤 붓 자국만 단계별: **좋음 = 금빛**(지금 gold-wash), **무난 = 연한 녹갈**(frame 색 25~30% 농도의 붓 자국 — gold-wash를 hue-rotate/색 덮어 만들거나 mask로 같은 붓 모양에 색만 바꾼다), **주의 = 옅은 먹빛**(ink 15~20%). 빨강·파랑 금지. 숫자 색은 셋 다 그대로.

## 2. 격자 칸 카드 (Q5 = A)
- `.grid-card`: 테두리 없이 카드 그대로(카드가 테두리를 가짐). 살짝 그림자 없음.
- `[data-unmet]`: `filter: grayscale(1) opacity(.35)` 정도로 흐리게 — "아직 못 만난 카드". 글자 한 줄 아래.

## 3. 지표 세 칸 `.metrics`
- 3열 그리드(375px에서 각 ~105px), 칸마다 paper-3 면(틀 안의 틀 금지 — 면만, 모서리 4px). `__label` 13px muted, `__value` Song Myung 30px 먹색(+`small` 14px muted), `__sub` 12px muted 1~2줄.
- 기분 칸: 칩 세로 3개(13px, 칩 = tag-strip-paper 작은 띠지 또는 1px 녹갈 테두리 pill, 횟수 `small` muted). 3열이 좁으면 기분 칸만 아래 줄 전체 폭.

## 4. 맞춤도 게이지 `.meter`
- 기존 붓선(rule) 자리. 높이 6px, paper-3 트랙, fill 금빛(gold-wash). 모서리 3px.

## 5. 30일 그래프 `.hchart`
- 눈금선 녹갈 0.5px 25%, 축 글자 10px muted.
- `.hchart__dot` 먹색 r3, `.hchart__avg` 금색 2.5px round, `.hchart__fortune` muted 1.5px 점선(4 3). 빈 날은 비어 있다(이어 그리기 없음 — 기능이 path를 끊어 둠).
- 범례: 각 key 앞에 작은 표식(점 / 굵은 금선 / 점선) — `::before`로.

## 6. 글자별 내 행복도 `.bars`
- 한 카드 안에 천간 10열 / 지지 12열 / 오행 5열 세 줄. 각 줄: 제목 14px 굵게 → 막대 줄.
- `.bars__track` 높이 64px(오행 줄은 80px), 바탕 paper-3, 아래 정렬. `.bars__fill` 금빛(오행 줄은 `data-el`별 오행 색 el-*). `.bars__value` 11px 막대 위, `.bars__label` Song Myung 15px 한글(천간·지지) / 16px(오행), `.bars__n` 10px muted.
- `[data-empty]` 칸: 트랙만 점선 테두리, 라벨 muted.
- 375px에서 지지 12열이 가로 스크롤 없이 들어가야 함(열 ~24px).

## 모션
fill은 처음 그릴 때만 300ms(기존 `bar-in` 재사용), reduced-motion 끔. 그 밖에 없음.

## 하지 않는 것
카드에 테두리·그림자 추가, 빨강/파랑으로 길흉, 틀 안의 틀, 차트 라이브러리, 새 그림.
