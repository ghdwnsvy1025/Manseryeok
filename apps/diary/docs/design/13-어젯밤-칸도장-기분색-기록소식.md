# 13 — 어젯밤 안내 · 칸 상세 도장 · 기분 색 · 오늘의 기록 소식 줄 (v3.12)

> 먼저 `00-톤.md`(v3.11 절까지). `frontend-design` 스킬로 작업. 2026-10-09 사용자 결정(grill 4문답). 기능 쪽은 끝나 있다. 디자이너는 모양만.

## 기능이 넣어 둔 것
- 새벽 4시 전, 날짜 없이 쓰기를 열고 어제 기록이 없으면 어제 날짜로 열림. 쓰기 머리에 `.night-carry`("어젯밤(10월 9일) 기록으로 남겨요 · 오늘로 바꾸기" 링크), 제목 "…, 어젯밤 하루". 오늘 화면 기록 카드도 "어젯밤 하루, 어땠어요?" / 버튼 "어젯밤 기록하기".
- `GanjiGrid` 칸 상세: 동물 이름 삭제. 간지 이름(송명 20px) → `.cell-stat` > `.cell-stamp`(평균 숫자, 인라인 `--h` 0~1 = 평균 농도) + "3번 기록"(15px muted) → 날짜 목록은 `<details>` "날짜 보기"로 접힘.
- 기분 `data-tone="pos"|"neutral"|"neg"`: 쓰기 기분 띠지(`.tag[data-tone]`), 오늘의 기록 기분 띠지(`.tag.tag--on[data-tone]`), 나 화면 `.metric__chip[data-tone]`.
- `TodayEntryCard` 맨 아래(내일 간지 삭제): `.entry-news` > `.entry-news__card[data-first]`("을묘 카드를 처음 만났어요 · 60장 중 9장" / "을묘 카드에 두 번째 도장 · 60장 중 9장") + `.entry-news__metric`("연속 3일째 · 포인트 해본 비율 67%").
- 그래프는 첫 기록 날부터 오늘까지만(최대 30일) — 기능 쪽 끝. 제목 "내 행복도".

## 1. 어젯밤 안내 `.night-carry`
- 제목 위 한 줄, 작은 한지 띠(paper-3 면, 모서리 4px, 좌우 10px · 상하 6px) 안 14px 먹색. 링크는 밑줄. 경고색 없음 — 차분하게.

## 2. 칸 상세 도장 `.cell-stamp`
- 저장 팡의 도장과 같은 인주 도장 키트, 지름 56px, 살짝 −6° 기울기. 숫자 Song Myung 22px 한지색.
- 농도: `opacity: calc(.45 + var(--h) * .55)` 정도 — 평균이 낮을수록 옅은 인주. 빨강 대비가 약한 쪽으로(인주 자체 색은 키트 그대로).
- 옆 "3번 기록" 15px muted. 도장·글자 한 줄 가운데 정렬.
- "날짜 보기" 접힘: summary 14px muted 밑줄, 열리면 지금 목록.

## 3. 기분 색 `[data-tone]`
- **pos(긍정)**: 안 고른 띠지 = 금빛 0.5px 테두리/글자 gold-ink, 고른 띠지(`tag--on`) = 금빛 면(gold-wash 또는 tag-strip을 금빛으로) + 먹색 글자.
- **neutral(무덤덤)**: 지금 띠지 그대로(종이색 / 고르면 기존 남색 띠지).
- **neg(부정)**: 안 고른 띠지 = 남색(sky/ganji 톤) 글자, 고른 띠지 = 기존 남색 띠지(tag-strip-navy) + 한지색 글자.
- 즉 지금 "고르면 남색"인 규칙에서 긍정만 금빛으로 갈라지는 것. 빨강·초록 없음. 쓰기·오늘의 기록·나 칩 세 곳 같은 규칙.

## 4. 오늘의 기록 소식 `.entry-news`
- 얇은 붓선(rule--light) 위에 두 줄, 가운데 정렬. `__card` 15px 먹색(처음 만났으면 `[data-first]` 앞에 작은 금빛 점 또는 "NEW" 대신 금색 글자 한 단어 강조 — 글자 추가 없이 색·굵기만), `__metric` 13px muted. 두 줄 간격 4px.
