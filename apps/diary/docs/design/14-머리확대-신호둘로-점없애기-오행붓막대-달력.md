# 14 — 오늘 머리 확대 · 신호 상자 둘로 · 점 대신 줄맞춤 · 오행 붓 막대 · 달력 보기 (v3.13)

> 먼저 `00-톤.md`(v3.12 절까지). `frontend-design` 스킬로 작업. 2026-10-10 사용자 결정(grill 6문답). 기능 쪽은 끝나 있다. 디자이너는 모양만.

## 원칙(새로 톤에 넣을 것): 글자 사이 가운뎃점(·) 금지
나열은 간격·칩으로, 짝 정보는 **이름–값 줄맞춤(`.kv`)** 으로. 기능 쪽이 문구에서 점을 다 뺐다. CSS로 `::before { content: "·" }` 같은 걸 되살리지 말 것.

## 기능이 넣어 둔 것
- **오늘 머리**: `.today-date`(날짜·요일), `.medal-pair__who`("나/오늘"), `.medal-pair__hanja` 안에 글자별 `<span class="text-el-*">`(천간·지지 각자 오행 색).
- **신호 상자 둘**: `.signal-box.signal-box--good`(↑ 줄 → 하면 좋아요 → → 줄) / `.signal-box.signal-box--care`(↓ 줄 → 피해요). 줄은 `.signal-box__row[data-signal="↑|→|↓"]`. 띠지 안 기간·영역 사이 점 삭제(간격만).
- **`.kv` 이름–값 줄**(공통): `<dl class="kv">` > `.kv__row` > `<dt>`(왼쪽 이름) + `<dd>`(오른쪽 값). 값 안에 `.kv__bar > span`(width %, 작은 진행 막대), `.kv__num`(평균 숫자), `.kv__n`(횟수) 이 올 수 있음. `.kv--facts`(나 화면 "가장 행복한 날/가장 힘든 날").
  - 쓰이는 곳: 나 머리(기록 n일 / 모은 카드 n / 60장 + 막대), 맞춤도 카드(기록 / 평균 행복도 / 아직 안 겪은 간지), 사실 줄 카드, 오늘의 기록 소식(오늘 포인트 / 모은 카드 + 막대), 달력 머리(이 달 기록 / 평균 행복도).
- **오늘의 기록 소식**: `.entry-news` > `.entry-news__card[data-first]`(문장 하나) > `dl.kv` > `ul.entry-news__chips > li.chip`("연속 3일", "포인트 100%").
- **쓰기 쪽지**: `.note-slip__label` 안 `.note-slip__sub`(운세의 "하면 좋아요" — 라벨 아래 줄 또는 옆 작은 글자).
- **나 화면**: "이 기기에만 저장돼요" 삭제, 제목 "{이름}의 경진일"(동물 삭제), "자세히"(오행 분포 글자 삭제), 섹션 제목 "내 행복도" + `.view-switch`(`.view-switch__item[aria-current=page]` "60갑자" / "달력").
- **달력** `MonthCalendar`: `.cal` > `.cal__head`(‹ 제목 ›) > `dl.kv` > `.cal__dow`(일~토) > `ol.cal__grid` > `.cal__cell`(링크; `[data-has]` 기록 있음 + 인라인 `--h` 0~1, `[data-today]`, `[data-future]` 누를 수 없음, `.cal__cell--blank`) > `.cal__day`(날짜 숫자) + `.cal__stamp`(행복도 숫자).
- 오행 분포 마크업(`.elements*`)은 그대로 — CSS만 바꾼다.

## 필요한 에셋
새 그림 없음. **붓 가로획 마스크**를 사주 코어 키트에서 복사해 쓴다(`--k-brush-stroke`가 가리키는 파일 — `사주 코어/content/src/` CSS에서 경로 확인, 원본은 `에셋/사주 코어/ui-kit/`). 복사 위치 `public/ui/brush-stroke.*`. 없으면 일기 키트 `divider-clean`을 마스크로.

## 1. 오늘 머리 (Q1 = A, Q2 = A)
- `.today-date`: Song Myung 24px 먹색(muted 아님), 가운데.
- 캐릭터 틀 100 → 108px. `.medal-pair__who` 16px muted, `.medal-pair__hanja` 30px(글자별 오행 색 — 기능이 span에 text-el-* 붙임; 기존 먹색 지정이 덮지 않게).
- 375px 한 줄 유지(× 포함).

## 2. 신호 상자 둘 (Q4 = A)
- `--good`: 따뜻한 금빛 면(gold-wash를 아주 옅게 또는 paper-3 + gold 10% 곱) + 금빛 1px 안쪽 선. ↑ 화살표 금색 굵게 20px. `[data-signal="→"]` 줄은 이 상자 맨 아래, 글자 ink/70로 옅게.
- `--care`: 서늘한 먹빛 면(ink 6~8% 곱) + 먹 1px 안쪽 선. ↓ 화살표 먹색 굵게 20px.
- 두 상자 사이 12px. 빨강·파랑 금지. 상자 안 줄 간격은 지금 규칙.
- 범례(`SignalLegend`): 세 항목 간격 16px(점 없음), 지금 크기.

## 3. `.kv` 이름–값 줄 (Q5 = A)
- 한 줄 = 왼쪽 dt 14px muted, 오른쪽 dd 15px 먹색 Song Myung 숫자(tabular), 양끝 정렬. 줄 사이 6px, 줄 아래 0.5px 점선 괘선(녹갈 25%) 또는 없음 — 둘 중 깔끔한 쪽.
- `.kv__bar`: dd 안 숫자 오른쪽 또는 아래 폭 72px·높이 5px 트랙(paper-3) + 금빛 fill.
- `.kv--facts`: dd 안 간지(text-ganji) → `.kv__num` 인주 작은 원(지름 26px, 숫자 13px 한지색 — 칸 상세 도장 축소판) → `.kv__n` 13px muted.
- 나 머리의 `.kv`는 가운데 정렬 블록(최대 260px).

## 4. 오늘의 기록 소식
- `.entry-news__card` 15px 먹색 가운데(첫 만남이면 금빛 점, 지금 규칙). 아래 `.kv`(카드 폭). 맨 아래 `.chip` 두 개 가운데: 1px 녹갈 테두리 pill, 13px, 높이 28px, 간격 8px.

## 5. 쓰기 쪽지 `.note-slip__sub`
- 라벨 오른쪽에 12px muted(한 줄에 안 들어가면 아래 줄).

## 6. 오행 분포 — 붓 막대 (사주 코어처럼, 옛 느낌)
- 줄: 한자/오행 글자 17px Song Myung 오행 색 → 막대 트랙 높이 10px(바탕 없음 또는 paper-3 아주 옅게) → fill = 오행 색 + **붓 가로획 마스크**(`mask: url(brush-stroke) no-repeat center / 100% 100%`)로 끝이 갈라진 붓 자국 → % 13px muted tabular.
- 들어올 때 왼쪽에서 차오름(scaleX 0→1, 0.9초, 줄마다 70ms, 한 번). reduced-motion이면 바로.
- 가장 큰 값 % 굵게(기존 규칙 유지).

## 7. 달력 (Q6 = B)
- `.view-switch`: 두 칸 세그먼트(쓰기 띠지 `.tag` 재질 또는 밑줄 탭), 현재 쪽 강조. 44px.
- `.cal__head`: ‹ › 44px 터치, 제목 Song Myung 20px.
- `.cal__grid` 7열, 칸 정사각(375px에서 ~44px), 모서리 18%.
  - 기록 없는 날: `board-cell` 재질(빈 도장 자리) + `.cal__day` 12px muted 가운데.
  - `[data-has]`: 인주 도장 키트(stamp-inked-red) 칸 안 꽉, 농도 `opacity: calc(.45 + var(--h)*.55)`; `.cal__stamp` Song Myung 16px 한지색 가운데, `.cal__day`는 왼쪽 위 9px 한지색 70%.
  - `[data-today]`: 남색 2px outline(격자 오늘 칸과 같은 규칙).
  - `[data-future]`: opacity .35, 커서 기본.
- 격자 칸과 같은 크기 체계라 두 보기를 오가도 덜컹거리지 않게.
