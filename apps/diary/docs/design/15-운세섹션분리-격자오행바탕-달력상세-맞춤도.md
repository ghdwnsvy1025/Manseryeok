# 15 — 운세 카드 섹션 분리 · 격자 칸 오행 바탕 · 달력 날짜 상세 · 맞춤도 숫자 세 칸 (v3.14)

> 먼저 `00-톤.md`(v3.13 절까지, 가운뎃점 금지). `frontend-design` 스킬로 작업. 2026-10-10 사용자 결정(grill 7문답). 기능 쪽은 끝나 있다. 디자이너는 모양만.

## 기능이 넣어 둔 것
- **운세 카드**(`FortuneCard`): 신호 상자 둘(`.signal-box--good/--care`)을 없애고
  - `section.traits` > `h3.traits__title`("오늘의 특징") > `SignalLegend`(처음 한 번) > `ul.traits__list` > `li.trait[data-signal="↑|→|↓"]`(↑ → ↓ 순) > `span.trait__tag`(`.trait__period` 오늘/이달/올해 · `.trait__area` 사람/돈… · `.trait__arrow`) + `span.trait__text`(문장). 영역이 없으면 섹션 없음.
  - 붓선(`rule--light`) 하나.
  - `section.actions` > `h3.actions__title`("오늘 해 볼 것") > `div.action.action--do`(띠지 `.sig--gold` "하면 좋아요" + `p.action__text`) + `div.action.action--dont`(띠지 `.sig--ink` "피해요" + `p.action__text`).
  - 투표는 `VoteButtons`(클라이언트, 누르는 즉시 바뀜, 카드 안 접힘). 마크업·클래스(`.vote`, `.vote__btn[aria-pressed]`)는 그대로.
- **격자 칸**(`GanjiGrid`): 테두리는 선택 칸(`outline-ink`)만. 오늘 칸은 `[data-today]`(테두리 없음). 모든 칸에 `[data-el="wood|fire|earth|metal|water"]`(그 간지 천간의 오행).
- **나 화면 보기 전환**: 기본 **달력**. `.view-switch__item[data-icon="calendar"|"grid"]` 순서 달력 → 60갑자.
- **달력**: 날짜 칸 링크가 `?d=`로 상세를 연다. 고른 칸 `[data-selected]`. 아래 `CalendarDayDetail`: `section.day-detail` > `p.day-detail__date` > `div.day-detail__card[data-empty]`(정사각 카드 `<img>` + `span.day-detail__stamp`(행복도, 인라인 `--h`)) > `ul.day-detail__moods`(기분 띠지 `[data-tone]`) > `p.day-detail__note.ruled`(손글씨) > "고치기" 링크. 기록 없으면 흐린 카드 + "이 날은 아직 기록이 없어요." + 금색 면 버튼 "이 날 기록하기".
- **맞춤도 카드**(`StatsSummary`): "기록이 쌓일수록 올라요" 문장·kv 삭제. 제목은 `details.fit-help` > `summary`("맞춤도" + `.fit-help__q` "?") > `p.fit-help__text`. 게이지 아래 `ul.stat3` > `li.stat3__item` ×3 > `.stat3__value`(+`small` 단위) + `.stat3__label`(기록 / 평균 행복도 / 안 겪은 간지).
- **지표 칸**: "포인트 해봄" → `.metric__label` "해 본 비율" + `.metric__hint`(운세의 "하면 좋아요").
- **그래프**: `.hchart__avg` 삭제 → `.hchart__line`(내 행복도 꺾은선, 빈 날 끊김) + 점 `.hchart__dot` + 운세 점선 `.hchart__fortune`. 범례 "7일 평균" 삭제.
- "기록이 3일 쌓이면…" 안내 카드 삭제(3일 전엔 글자별 막대 섹션 자체가 없음).

## 필요한 에셋
없음. 키트 재사용(tag-strip, stamp-inked-red, divider, card-paper, gold-wash). 아이콘(달력·격자)은 CSS나 인라인 SVG 선 2~3개로 — 그림 생성 금지.

## 1. 운세 카드 두 섹션 (Q1 = A)
- `.traits__title`·`.actions__title`: Song Myung 18px 먹색, 아래 10px.
- `.trait`: 줄마다 위 띠지(`.trait__tag` — 기존 `.sig--line` 재질: 먹 테두리 띠지, 14px, 기간 muted · 영역 먹색 굵게 · 화살표 20px 굵게(↑ 금, ↓ 먹, → muted)) + 아래 문장 16px. 줄 사이 14px. 상자 면 없음(한지 위에 바로) — 틀 안의 틀 금지.
- `.action`: 띠지 + 문장 16px. `--do`는 문장 앞 얇은 금빛 왼줄(2px), `--dont`는 먹빛 왼줄. 두 행동 사이 12px.
- 빨강·파랑 금지. 가운뎃점 금지.

## 2. 격자 칸 (Q2 = A)
- `.album-cell[data-el]`·`.board-cell[data-el]` 바탕: 그 오행 색 8%를 paper-2에 섞음(`color-mix`). 기록 없는 칸(빈 도장 자리)은 빈 도장 그림 위에 오행 6%.
- `[data-today]`: 칸 오른쪽 위 지름 6px 남색(ganji) 점. 테두리 없음.
- 포커스: 탭으로 누른 뒤 남는 테두리 없게 `:focus:not(:focus-visible) { outline: none }`(키보드 포커스는 유지). 선택 칸의 먹색 outline만 보인다.

## 3. 보기 전환 (Q6 = A)
- 섹션 제목 아래 폭 전체 두 칸, 높이 48px, 띠지 재질(`tag-strip-paper`, 고른 쪽 `tag-strip-navy` + 한지색 글자). 글자 앞 아이콘 16px(달력 = 네모+윗줄, 격자 = 3×3 점) — `::before`로 CSS/SVG.

## 4. 달력 상세 (Q7 = A)
- `.cal__cell[data-selected]`: 먹색 2px outline(격자 선택과 같은 규칙).
- `.day-detail`: 달력 아래 16px. `__date` Song Myung 18px 가운데. `__card` 폭 60%·최대 240px 가운데, 카드 그대로(테두리·그림자 없음). `__stamp`: 카드 오른쪽 아래 안쪽 10px, 지름 56px 인주 도장(키트), −8°, 농도 `.6 + --h*.4`, 숫자 Song Myung 22px 한지색. `[data-empty]` 카드: `grayscale(1) opacity(.35)`.
- 기분 띠지 가운데, 메모 손글씨 괘선(오늘의 기록과 같은 규칙), "고치기" 14px 밑줄.

## 5. 맞춤도 (Q3 = A)
- `.fit-help summary`: "맞춤도" 15px 굵게 + `?` 18px 원(1px 녹갈 테두리, 12px muted). 열리면 `.fit-help__text` 13px muted 한 줄.
- `.stat3`: 3열, 칸 사이 세로 0.5px 녹갈 괘선(면 없음), 가운데 정렬. `__value` Song Myung 26px 먹색(+`small` 13px muted), `__label` 12px muted.
- `.metric__hint`: 라벨 아래 11px muted 한 줄.

## 6. 그래프 (Q5 = A)
- `.hchart__line`: 먹색 2px, round join. `.hchart__dot`: 먹색 r3 + 한지색 1.5px 테두리(선 위에 또렷이). `.hchart__fortune`: 금색 1.5px 점선(4 3), 옅게(.7). 범례는 둘(점+선 / 점선).
