## 1. 달력 단계 색 (Q2 = A) — 빨강 없음
- 칸 모양은 지금 도장 자리 그대로. `[data-has]` 칸의 도장 면 색만 단계별로:
  - `high`: 금빛(gold-wash 질감, 숫자 먹색 굵게)
  - `mid`: 옅은 녹갈(frame 25~30%를 paper-2에 섞음, 숫자 먹색)
  - `low`: 차분한 남색(sky 70~80%, 숫자 한지색)
  - 도장 모양(가장자리 번짐)은 `stamp-inked-red`를 **mask**로 써서 모양만 빌리고 색은 위 단계 색으로(빨강이 보이면 안 됨). `--h` 농도는 쓰지 않아도 된다(단계가 대신).
- `button.cal__cell` 기본 버튼 모양 제거(배경·테두리·글꼴 상속, 높이·정사각 유지, 44px 터치).
- `[data-selected]` 먹색 2px outline(지금 규칙 유지), `[data-today]` 점(지금 규칙 유지).
- `[data-stamp-in]`: 도장이 위에서 눌리듯 scale 1.25→0.95→1 + opacity 0→1, 420ms, 한 번. reduced-motion이면 없음.
- 같은 단계 색을 날짜 상세 `.day-detail__stamp`에도 적용해도 된다(지금 인주 → 단계 색). 상세 도장엔 `--h`만 있으니 단계는 CSS로 못 정한다 — 상세 도장은 금빛 하나로 통일.
