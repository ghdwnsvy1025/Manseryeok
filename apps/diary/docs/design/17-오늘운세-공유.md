# 17 오늘 운세 공유 (v3.16, 2026-10-10)

기능 쪽이 운세 카드 헤드라인 줄 오른쪽에 `FortuneShareButton`을 넣었다(나 화면 "내 카드 공유" 섹션은 없앰). 이 문서는 모양과 공유 이미지 확인 기록.

## 버튼 `.share-btn` (globals.css)

- 녹갈 1px pill, 보이는 높이 32px, 13px 먹색, 앞에 14px 공유 아이콘(위 화살표 + 열린 상자 선, `::before` 인라인 SVG mask, 글자색).
- 손가락 자리 44px는 `::after`(위아래 7px)로 늘린다. `.tap`의 min-height·음수 여백은 이 버튼에서 끈다.
- 금색 면 금지(화면당 금 면 하나). disabled = opacity .5.
- `.share-btn-wrap`은 flex-shrink 0, 헤드라인 첫 줄과 높이 맞춤(위 2px). 375px에서 헤드라인과 겹치지 않음(헤드라인이 줄바꿈된다).
- `.share-btn__note`: 버튼 아래 6px, 오른쪽 정렬 절대 위치 12px muted 한 줄. 레이아웃을 밀지 않는다.

## 공유 이미지 (fortuneShareCanvas.ts, 1080×1350)

- 담는 것 그대로: "오늘의 운세" / 날짜 + 간지일(송명) / 오늘 간지 정사각 카드 560px / 단계(송명 96) + 점수(송명 76) / 헤드라인 최대 2줄(송명 50) / 바닥 안내 + 주소.
- 색 상수만 토큰에 맞춤: paper-2 `#f8ecd1`, frame `#767b3c`. 점수 금빛은 gold 그대로면 대비 2.2:1이라 진한 금 `#8a6420`(4.6:1).
- 확인: 송명 적용됨, 카드 가운데, 1줄 헤드라인 기준 바닥 주소까지 잘림 없음(2줄이어도 헤드라인 끝 ≈ y1100, 바닥 안내 y1180).
