# 19 메모 글씨 교체와 운세 카드 영역 띠지 (v3.18, 2026-10-11)

## 1. 메모 글씨 = 고운바탕
- 나눔펜 손글씨가 어색하다는 피드백으로 사용자 메모를 고운바탕(단정한 명조)으로 바꾼다.
- 방법: `--font-hand` 토큰을 `var(--font-gowun), "AppleMyungjo", "Batang", serif`로. className `font-hand`는 그대로(뜻 = "사용자가 쓴 글").
- 쓰는 곳 셋(쓰기 입력 textarea, 오늘의 기록 카드, 달력 날짜 상세): 17px, `break-keep`(낱말 중간 줄바꿈 없음).
- 편지지 괘선 `.ruled`: `--lh` 36px에서 30px, 배경 위치 0.45lh. 타일 선이 1/4, 3/4 지점이라 선은 각 줄 0.95lh(28.5px)에 놓이고, 17px 명조의 받침 아래끝(약 25px) 바로 아래라 글자를 가로지르지 않는다.
- 쓰기 입력칸은 글에 맞춰 2줄에서 6줄까지 자란다(`field-sizing: content`). 못 자라는 브라우저나 6줄을 넘겨 스크롤할 때도 괘선이 글과 함께 움직인다(`background-attachment: local`).
- 나눔펜을 쓰는 곳이 없어 `layout.tsx`에서 Nanum_Pen_Script 불러오기를 지웠다(다운로드 절약).

## 2. 운세 카드 점수 아래 영역 띠지
- 마크업(기능 쪽): summary 안 `.score-brush` 아래 `span.area-chips` > `span.area-chip[data-signal]` + `span.area-chip__arrow`(색은 TSX: ↑ 금, → muted, ↓ 먹) + sr-only. 보기 전용.
- 모양: 점수 아래 8px, 가운데 정렬 한 줄(넘치면 줄바꿈), 칩 사이 8px.
- 칩 = `.sig--line` 재질 축소판: 찢긴 한지 띠(tag-strip-paper mask) + 먹 70% 1px 가장자리, 높이 26px, 좌우 12px, 13px 먹색 보통 굵기. 화살표 15px 굵게.
- 빨강, 파랑, 가운뎃점, 틀 안의 틀 없음. 새 그림, 새 모션 없음.
