# 20 — 오늘의 개운 (2026-10-12, 톤 v3.19)

자리: 운세 카드(`src/components/FortuneCard.tsx`) "오늘 해 볼 것" 섹션, 피해요 아래. 마크업은 기능 쪽이 확정(`.gaewoon*`), 디자인은 `globals.css`만.

- 위 행동과 사이 16px, 구분선 없음(같은 섹션).
- `__title` 15px 굵게 먹색(섹션 제목 18px 송명보다 한 단계 아래), `__reason` 14px 먹색.
- `__grid` 2열 같은 폭, `grid-auto-rows: 1fr`로 칸 높이 같게, 사이 8px. 375px에서 칸 폭 141px.
- `__item` paper-3 70%를 paper-2에 섞은 옅은 면, 틀 없음, 모서리 4px, 안쪽 10/12px.
- `__label` 12px muted, 앞 `::before` 14px 인라인 SVG mask(`--gw-icon`을 `data-kind`마다): 색 동그라미, 음식 그릇, 시간 시계, 활동 발자국 둘.
- `__value` 15px 먹색, keep-all, 최대 2줄(line-clamp). 색 칸은 점 + 이름 한 줄 정렬.
- `__swatch` 14px 원, 먹 20% 0.5px 테두리(흰색도 보이게). 실제 색은 정보라 빨강·파랑도 예외로 허용.
- `__note` 12px muted, `__empty` 14px muted(위 16px).
- 금지: 길흉 색, 가운뎃점, 칸 안 틀, 새 그림, 새 모션.
