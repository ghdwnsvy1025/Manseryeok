# 21 — 손맛 효과 · 탭 아이콘 · 카드 무게 · 빈 화면 (v3.20)

> 먼저 `00-톤.md`(v3.19까지, 가운뎃점 금지). `frontend-design` 스킬로 작업. 2026-10-12 사용자 결정(Q1 = A 인주 도장 "꾹", Q2 = A 보상 순간 금빛 가루, Q3 = A+B+C). 기능 쪽은 끝나 있다. 디자이너는 모양·움직임만.

## 기능이 넣어 둔 것
- `src/lib/fx.ts`: 화면 위 고정 레이어 `#fx-layer.fx-layer`(body 끝, aria-hidden)에 잠깐 그렸다 지운다.
  - `span.ink-bloom`: 누른 자리(인라인 left/top = 손가락 좌표, 기준점은 가운데로 잡아야 함)에 0.5초. `TouchFx`가 button·a·띠지 label·달력/격자 칸·summary를 누를 때마다 만든다.
  - `span.gold-dust` ×10: 요소 가운데(left/top)에서 인라인 변수 `--dx`·`--dy`(튈 방향·거리 px)·`--s`(지름 5~9px)로 0.8초. 보상 순간에만: 투표 "맞아요", 쓰기 "해봤어요" 도장, 저장 직후 카드 첫 만남, 연속 7·30·100일(`.chip[data-milestone]`), 나 탭 달력 오늘 칸 도장 꽝.
  - 움직임 줄이기 설정이면 JS가 아예 그리지 않는다.
- `BottomNav`: 링크 안 글자 위 `span.nav-icon[data-icon="sun|brush|seal"]`(오늘 해, 쓰기 붓, 나 도장). 고른 탭 링크는 `aria-current="page"`. 옛 점(`h-1 w-1 rounded-full`)은 그대로 있다 — 아이콘으로 대체할 거면 그 점 className을 지워도 된다.
- 그래프 빈 화면: `div.empty-art` > `img.empty-art__img`(내 캐릭터, 96px) + 안내 글.

## 수정 가능 파일
`src/app/globals.css`, className만: `src/components/BottomNav.tsx`, `src/components/HappinessChart.tsx`, 카드 무게 조정에 필요한 화면 파일(`src/app/page.tsx`, `src/app/me/page.tsx`, `src/components/{TodayEntryCard,StatsSummary}.tsx`)의 className. `docs/design/00-톤.md` v3.20 절. 금지: `src/lib/**`, 로직, 문구.

## 필요한 에셋
새 그림 없음. 아이콘은 CSS/인라인 SVG 선(2~3획)으로. 금빛 가루는 `pop-gold-dust-clean`(키트) 질감을 써도 되고 단색 금빛 점이어도 된다.

## 1. 기본 터치감 — 인주 도장 "꾹" (Q1 = A)
- 눌림: `button, a.tap, .tag, .cal__cell, .album-cell, .vote__btn, .gold-plate, .share-btn` 등 누를 수 있는 것에 `:active { transform: scale(.96) }`, 돌아올 때 120ms ease-out. 크게 보이는 금색 면 버튼(.gold-plate)은 .97.
- `.ink-bloom`: 지름 0 → 56px 원, 색은 먹(ink) 12% 또는 인주(seal) 10% 정도의 옅은 번짐(가장자리 흐림 radial-gradient), opacity .5 → 0, 450ms. `position: fixed; transform: translate(-50%,-50%); pointer-events: none`.
- `.fx-layer`: fixed inset 0, pointer-events none, z-index 화면 맨 위(팡 오버레이보다 위).
- 과하지 않게: 눌림 0.2초 안에 끝.

## 2. 보상 순간 — 금빛 가루 (Q2 = A)
- `.gold-dust`: 지름 `var(--s)` 금빛 점(가장자리 살짝 빛남). 0 → `translate(var(--dx), var(--dy))`로 튀며 scale 1 → .4, opacity 1 → 0, 700ms cubic-bezier(.2,.7,.3,1). 시작 위치 기준점 가운데.
- `.chip[data-milestone]`: 금빛 테두리 1px + 굵게.

## 3. 탭 아이콘 (Q3 = A)
- `.nav-icon`: 22px, `currentColor` mask(해 = 원 + 짧은 빛살, 붓 = 비스듬한 붓대 + 붓끝, 도장 = 둥근 손잡이 + 네모 인면). 고른 탭(`[aria-current=page]`) 금빛(lamp/gold) + 아이콘 아래 점 대신. 안 고른 탭 muted. 탭 높이 64px 유지, 아이콘–글자 간격 3px.

## 4. 카드 무게 (Q3 = B)
- 주인공 = 운세 카드(지금 `card-gold`). 그대로 또는 조금 더 무겁게(금빛 테두리 유지).
- 보조 카드(오늘의 기록, 나 화면의 그래프·맞춤도·내 사주 카드 등 `card-frame card-paper`)는 한 단계 가볍게: 이중선 → 한 줄 녹갈 선(또는 이중선 농도↓), 바깥 장식 모서리 축소. 한지 질감은 유지. 화면 전체에 높낮이가 생기게.
- 틀 안의 틀 금지 원칙 유지.

## 5. 빈 화면 (Q3 = C)
- `.empty-art`: 가운데 정렬, 캐릭터 96px opacity .35 + grayscale .3, 아래 글 15px muted, 위아래 여백 16px.

## 모션 요약
눌림 120ms, 번짐 450ms, 금빛 가루 700ms(보상 순간만). 모두 움직임 줄이기면 없음(:active 축소도 끔).

## 하지 않는 것
게임 같은 번쩍임·흔들림·소리, 빨강·파랑 길흉, 가운뎃점, 새 그림, 로직·문구 변경.
