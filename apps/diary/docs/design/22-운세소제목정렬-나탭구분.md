## 기능이 넣어 둔 것
- 운세 카드: `h3.traits__title`("오늘의 특징"), `h3.actions__title`("오늘 해 볼 것"), `p.gaewoon__title`("오늘 챙기면 좋은 것" — 이름 바뀜), 개운 라벨 "행운 색 / 추천 음식 / 힘이 나는 시간 / 추천 활동", 안내 "전통 오행 대응표를 참고했어요."
- 나 탭 머리: h1 "나의 카드, 경진"(이름이 있으면 "{이름}의 카드, 경진") + `p.me-card-hint`("태어난 날의 간지(일주)로 정해진 내 카드예요").
- 자세한 통계 맨 위 `div.habit.card-frame.card-light.card-paper`("기록 습관" + kv 4줄: 지금 연속 / 가장 길게 이어 쓴 날 / 이번 달 기록 / 최근 30일 중 기록한 날 + 막대).
- 쓰기 기분 띠지 13개 → 18개(감사함·신남·피곤함·외로움·긴장됨 추가). "안 써도 돼요" 줄 삭제.

## 1. 운세 소제목 정렬
- 세 소제목을 **같은 체계**로: 같은 글꼴(Song Myung)·같은 크기(18px)·같은 왼쪽 시작선·같은 위 여백(섹션 사이 24px)·같은 아래 여백(10px). 지금 `gaewoon__title`만 15px 굵은 고딕이라 어긋난다 — 셋 다 섹션 제목급으로 맞추고, 소제목 앞에 작은 표식(붓 점 또는 짧은 금빛 세로선 3px×16px) 하나로 "여기서 새 섹션"이 보이게.
- 소제목 아래 내용(띠지·행동·네 칸)도 같은 왼쪽 시작선.

## 2. 나 탭 구분 (컨셉에 맞게)
- 섹션마다 **한지 띠지 머리표**(tag-strip-paper, 13px 먹색 굵게)로 이름을 단다: "내 카드" / "내 행복도" / "지표" / "자세한 통계" / "내 사주" — 실제 섹션 제목 요소가 있으면 그 모양을 바꾸고, 없으면 기존 h2/summary에 클래스만(문구 추가는 금지 — 이미 있는 제목 글자만 쓴다. 제목이 없는 섹션은 붓선 구분만).
- 섹션 사이: 붓선(divider-clean) 하나 + 위아래 24px. 카드끼리 붙어 보이지 않게.
- 머리(내 카드) 영역: 카드 + h1 + `me-card-hint`(13px muted) + 기록 kv. 힌트는 h1 바로 아래 4px.

## 3. 기록 습관 `.habit`
- 다른 보조 카드와 같은 card-light. kv 줄 그대로, "최근 30일" 막대는 금빛.
