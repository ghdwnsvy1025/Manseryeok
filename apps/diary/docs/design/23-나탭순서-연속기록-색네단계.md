# 23. 나 탭 순서 · 연속기록 · 행복도 색 네 단계 (v3.22, 2026-10-13)

사용자 결정 (grilling, 추천안 그대로):

1. **잔 설명 삭제**: 카드 아래 "태어난 날의 간지…", 달력 위 머리표 "내 행복도", 달력/격자 아래 설명 문장 — 마크업에서 이미 지웠다. `.me-card-hint` CSS가 남아 있으면 지운다. 그래프 카드 안의 "내 행복도" 제목도 없앴다.
2. **순서**: 보기 전환(달력|60갑자) → 달력 → 그래프(`.hchart-wrap`) → 기록 습관(`.habit`) → 지표 두 칸(`.metrics.metrics--two`) → 자세한 통계(접힘) → 내 사주(접힘).
   - 달력과 그래프는 한 덩어리로 보이게 간격을 좁게(달력 바로 밑). 그래프 위 붓선 구분(me-sep) 없음.
   - 기록 습관과 지표 두 칸 사이, 자세한 통계 앞에는 기존 me-sep 리듬 유지.
3. **행복도 색 네 단계** (`data-tier`): `top` 8~10 초록 — 톤의 녹갈(`--color-frame` 계열)을 진하게 올린 초록, 금색보다 눈에 덜 튀되 분명히 "좋은 날". `high` 6~7 금(기존 high 그대로). `mid` 4~5 종이(기존 mid). `low` 0~3 남색(기존 low).
   - 달력 도장 `.cal__cell[data-tier="top"]` 추가 (숫자 색은 종이색, 굵게).
   - 그래프 점 `.hchart__dot[data-tier]` 같은 네 색. 선 색은 그대로.
   - 빨강 금지 (00-톤 규칙).
4. **기록 습관 `.habit`** (새 마크업, StatsSummary.tsx):
   - `.habit__head`: 왼쪽 `.habit__label` "연속 기록"(작게), 가운데/큰 `.habit__value` 숫자(송명 큰 숫자, `small` "일째"), 오른쪽 `.habit__best` "최고 N일"(muted).
   - `.habit__dots` (ol, li 30개, 오래된 날→오늘): 작은 도장 점. `data-on` = 기록한 날(금 도장), 빈 날 = 연한 빈 원. `data-today` = 마지막 점, 테두리로 표시. 375px에서 한 줄 30개가 빠듯하면 15×2줄.
   - `.habit__kv`: 이번 달 기록 / 최근 30일 기록률 (기존 kv 줄맞춤).
5. **지표 두 칸 `.metrics--two`**: 연속 기록 칸이 빠져 두 칸(하면 좋아요, 자주 고른 기분). 2열 그리드로 폭을 반씩.
6. **기분 20개**: 홀가분함·든든함 추가(긍정, 금빛). 4개×5줄 정렬 확인만.

## v3.23 추가 (2026-10-13)

1. **자세한 통계 + 내 사주 한 묶음**: 둘 다 가끔 여는 접힌 칸. 붓선(me-sep)은 묶음 위에 한 번만, 두 칸 사이엔 선 없이 같은 모양의 접힌 줄(서랍 두 개)로 위아래 붙인다(간격 8px 안팎). 자세한 통계 summary와 내 사주 summary의 높이·글꼴·화살표를 맞춘다. 내 사주의 여덟 글자 미리보기는 유지.
   - 마크업: 자세한 통계는 StatsSummary 안 `details.more-stats.me-sep`, 내 사주는 page.tsx `details.saju-fold.me-sep.me-sep--wide`. 필요하면 내 사주 쪽 me-sep 클래스를 빼거나 묶음 클래스를 더해도 된다(className만).
2. **연속 기록 점의 뜻**: 점 줄 아래 `.habit__ends`(span 두 개, "30일 전" 왼쪽 / "오늘" 오른쪽, 12px muted). 빈 날 점은 더 흐린 점선 원으로 — 금빛 도장이 이어진 구간이 연속 기록으로 바로 읽히게.
3. 오늘 챙기면 좋은 것 아래 "전통 오행 대응표를 참고했어요." 삭제됨 — `.gaewoon__note` CSS가 다른 데서 안 쓰이면 정리.
