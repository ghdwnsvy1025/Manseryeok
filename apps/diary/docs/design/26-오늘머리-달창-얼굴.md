# 26 — 오늘 머리: 두 얼굴을 달창(만월창)에

> 먼저 `00-톤.md`를 읽는다. `frontend-design` 스킬로 작업. 출처: 사용자 요청 2026-10-15 "나와 오늘 캐릭터의 얼굴 크기가 비슷했으면(무자·임술이 다름), 원보다 컨셉에 맞는 더 세련된 틀" → 제안 1안 "달창" 선택.

## 왜
- 지금 `.medal`은 전신 그림 `characters/*.webp`의 위 55%를 잘라(`height: 182%`, `object-position: 50% 12%`) 보여 준다. 동물마다 머리 크기·위치가 달라 무자는 얼굴이 꽉 차 잘리고, 임술은 작은 얼굴에 들고 있는 지도까지 들어온다.
- 얼굴만 그린 그림 `public/faces/<간지>.webp`(512² 투명, 가장자리 7% 여백으로 60장 맞춤, v3.25 격자·달력에서 이미 씀)를 쓰면 두 얼굴이 같은 크기가 된다. `characterOf(...).faceSrc`가 이미 있다.
- 1px 동그라미는 이 앱만의 물건으로 읽히지 않는다. 한옥의 둥근 창(만월창) — 나무 창틀에 한지를 바른 둥근 창 — 은 "한지 위의 밤"과 겹치고, 두 얼굴이 창 너머로 서로를 보는 그림이 된다.

## 수정 가능 파일
`src/app/page.tsx`(머리 메달 마크업: img src를 `faceSrc`로, 틀 그림 자리 span 추가만 — 문구·aria·로직 그대로), `src/app/globals.css`(`.medal*` 규칙과 간지별 보정 표 주석), `src/components/BurstPreload.tsx`는 건드리지 않는다. `docs/design/00-톤.md` "오늘 머리" 절에 v3.27 한 단락. 금지: `src/lib/**`, `src/app/actions.ts`, 다른 화면.

## 화면 구조
```
        10월 15일 목요일
   ( 달창[금] )   ×   ( 달창[녹갈] )
     얼굴(나)            얼굴(오늘)
       나                  오늘
      戊子                 壬戌
```
- 틀 바깥 지름 108px 그대로(375px 한 줄 유지). 안쪽 창(한지 `card-paper` 바탕 + 얼굴)은 창틀 안지름에 맞춘 원, 그 위에 창틀 그림을 겹친다(`.medal::after` 또는 형제 span, pointer-events 없음).
- 얼굴 `faces/*.webp`는 창 안에서 `object-fit: contain`, 위아래 가운데. 두 얼굴은 같은 크기 — 간지별 보정 표는 비운다(필요 없어짐).
- 내 쪽 금빛 창틀, 오늘 쪽 녹갈 창틀 — 색은 "나"를 가리킬 뿐 길흉이 아니다(기존 규칙 유지). 1px CSS 테두리는 지운다.
- 라벨·`×`·간격은 그대로.

## 상태별 모습
- 얼굴 그림을 못 받으면 한지 창만(alt 글자는 기존대로). 창틀 그림을 못 받으면 예전 1px 테두리가 보이게 폴백(`border`를 창틀 로드 전 기본값으로 두거나 배경색 대비로).

## 모션
없음. 반복 애니메이션 금지 규칙 그대로.

## 하지 않는 것
전신 캐릭터 교체, 문구 변경, 크기 변경, 운세 카드 안 그림 추가, 창살로 얼굴 가리기, 달·별 장식 추가.

## 끝났을 때 확인
- `npx tsc --noEmit`, `npm test` 통과.
- 375px 스크린샷: 무자 × 임술, 기축 × 갑인 두 쌍을 정적 하네스(실제 CSS·에셋 사용)로 찍어 얼굴 크기가 같아 보이는지, 창틀이 얼굴을 가리지 않는지, 한 줄에 들어가는지 대조. 로그인 뒤 화면 라이브는 운영 DB에 행이 생기므로 하네스로 대신해도 된다.
- 에셋 용량: 창틀 webp 각 60KB 이하.
