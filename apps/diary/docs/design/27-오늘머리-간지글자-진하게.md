# 27 — 오늘 머리: 간지 한자 진하게·34px

> 먼저 `00-톤.md`(v3.27 절까지)를 읽는다. `frontend-design` 스킬로 작업. 출처: 사용자 결정 2026-10-15 — 시안(`shots/27-시안-오행창틀-글자.png`) 중 C안. 창틀(달창 금빛·녹갈)은 그대로, 오행 그라데이션 창틀(A·B안)은 하지 않는다.

## 왜
- 머리 간지 한자(`.medal-pair__hanja`)는 글자마다 오행 색(`text-el-*`)인데, 한지 `paper #f1debb` 위 대비가 토 `#a67c2e` **2.87:1**(큰 글자 기준 3:1 미달), 금 `#6f6f6a` 3.83:1이라 戊·戌·庚申이 흐리다.

## 수정 가능 파일
`src/app/globals.css`만: `@theme`에 글자용 진한 오행 토큰 추가, `.medal-pair__hanja` 크기, `.medal-pair__hanja` 안의 `text-el-*` 색 덮어쓰기. `docs/design/00-톤.md` v3.27 절 아래 한 단락. 금지: `--color-el-*` 원래 값 변경(격자·막대·나무패 등 다른 곳이 씀), `page.tsx` 마크업, 다른 화면.

## 필요한 에셋
없음.

## 바뀌는 것
- 새 토큰(글자 전용, 한지 위 대비): `--color-el-earth-ink #7d5a1c`(4.75:1), `--color-el-metal-ink #5a5a55`(5.25:1), `--color-el-fire-ink #a52419`(5.55:1). 목 `#2f6b4f`(4.77:1)·수 `#1c2b52`(10.5:1)는 그대로.
- `.medal-pair__hanja .text-el-earth { color: var(--color-el-earth-ink) }`, metal·fire도 같은 방식. 범위는 오늘 머리 한자만.
- `.medal-pair__hanja` font-size 30px → **34px**. line-height·간격은 375px 한 줄과 라벨 폭(108px) 안에 들어가게 필요하면만 조정.

## 하지 않는 것
창틀 변경, 오행 색 원래 값 변경, 다른 화면 한자, 문구.

## 끝났을 때 확인
- `npx tsc --noEmit`, `npm test` 통과.
- 375px 정적 하네스(명세 26과 같은 방식, 운영 DB 쓰기 없음): 무자×임술, 경신×갑인, 병오(화)×기축 세 쌍. 한자가 라벨 폭 안·한 줄, 가로 스크롤 없음, 세 색 대비 수치 보고.
