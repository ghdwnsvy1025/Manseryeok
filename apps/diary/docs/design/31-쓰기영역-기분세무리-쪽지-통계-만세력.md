## 1. 쓰기 화면 (`/write`)
- **행복도 = 영역 여섯 줄** (`.entry-areas`, `.entry-area`, `.entry-area__label`, `.entry-area__stamps`): 줄마다 왼쪽 영역 이름(일·공부/돈/건강/가족/연애/대인관계), 오른쪽 5단계 도장 다섯(1~5). 지금은 한 줄 위·아래로 쌓여 있다 — **이름과 도장이 한 줄**(이름 폭 고정 약 72px, 도장 다섯이 남은 폭)로. 도장은 지금 1~10 도장과 같은 재료, 크기는 375px에서 한 줄에 들어가는 만큼(약 40px). 고른 도장 = `stamp--on`. 단계 색: 1~2 남색 · 3 종이 · 4~5 금빛(달력 네 단계 색과 같은 계열, 빨강 없음) — `data-level`이 필요하면 JSX에 붙여도 된다(값은 1~5).
  - 아래 양 끝 작은 글 "아주 힘듦 / 아주 좋음"은 도장 열 아래에 맞춘다(이름 열은 비움).
  - 위 한 줄(`aria-live`) "7점, 괜찮았어요 · 3개 영역 평균"은 그대로, 점수 숫자만 송명으로 조금 크게 해도 좋다.
- **기분 세 무리** (`.entry-moods__group[data-tone]`, `.entry-moods__head`): "좋았어요 / 그저 그래요 / 아쉬웠어요" 머리 아래 띠지들. 무리 사이가 분명히 갈리게(머리 앞 작은 색점이나 녹갈 0.5px 괘선 중 톤에 맞는 하나). 띠지 색은 기존 `data-tone` 그대로. 44개라 길다 — 띠지 높이 40→36px, 간격 6px까지 줄여도 된다.
- **내일의 나에게** (`.entry-tomorrow`, 쪽지 안 textarea): 쓰기 카드 맨 아래 쪽지 한 장. 손글씨 입력이 쪽지 위에 바로 쓰이는 느낌으로(괘선 한두 줄). 지금 쪽지 CSS가 문장 표시용이라 textarea가 어색할 수 있다 — 높이·여백·placeholder 정렬을 맞춘다.
- 지운 것: "오늘의 포인트" 블록(.promise-stamp*, 쪽지 문장) — 쓰지 않는 CSS는 지운다(`.promise-stamp*`, `.metric--points`, `.metric__dot`, `.burst-card[data-kept]`, `.album-cell[data-kept]` 등 검색해서 사용처 0이면).

## 3. 나 탭 통계 (`/me`)
- **그래프 칩** (`.hchart__chips`, `.hchart__chip[data-on]`): 전체 · 일·공부 · … 작은 띠지 칩(높이 28px, 13px). 켜진 칩 = 남색 띠. 그래프 위 한 줄, 넘치면 가로 스크롤 없이 줄바꿈.
- **빈 날 건너는 선** (`.hchart__line--gap`, `.hchart__fortune--gap`): 같은 색·같은 굵기, 불투명도 약 35%. 범례 `.hchart__key--gap`(옅은 선 = 기록 없는 날을 건넘)은 짧은 옅은 선 견본 + 글.
- **영역별 막대** (`.area-bars*`): 이름(72px) · 가로 막대(트랙 옅은 녹갈, 채움은 `data-tier` 네 단계 색) · 평균 숫자 · 매긴 날 수. 매긴 날 없는 영역(`data-empty`)은 흐리게.
- **가장 행복한 날·힘든 날** (`.day-pick*`): 머리 줄 오른쪽에 "10월 / 전체" 작은 전환(칩). 아래 두 칸 카드(기존 `.metrics--two`). 카드 = 그날 간지 얼굴 48px 원(달력 상세 얼굴과 같은 처리) + 간지 이름 + 날짜 + 행복도 큰 숫자(`data-tier` 색) + 기분 띠지 최대 3개. 행복한 날 카드에는 금빛 얇은 테, 힘든 날은 남색 얇은 테(빨강 없음). 비었을 때(`data-empty`) 흐린 글 한 줄.
- **자주 고른 기분** (`.metric--moods`): 지금 카드 한 장으로 따로 섰다 — 한 줄 칩으로 가볍게.
- 순서(기능이 정함): 달력 → 그래프 → 기록 습관 → 영역별 막대 → 가장 행복한 날·힘든 날 → 자주 고른 기분 → 자세한 통계.
- 달력 날짜 상세(`CalendarDayDetail`): 영역 줄(`.day-detail__areas`, kv)과 "내일의 나에게" 쪽지(`.day-detail__tomorrow`)가 새로 들어갔다 — 기존 상세 간격에 맞춘다.

## 4. 나 탭 내 사주 요약 (`.saju-summary`) → 만세력 화면 (`/me/saju`)
- **요약 카드**(나 탭, 내 카드 아래): 머리표 "내 사주" + 오른쪽 여덟 글자(오행 색, 기존 `.saju-fold__preview`와 같은 글자) / kv 두 줄(중심 기운, 용신) / 오른쪽 아래 "만세력 보기 ›". 카드 전체가 링크 — 누를 수 있어 보이게(꺾쇠, 눌림 상태).
- **만세력 화면**: 사용자 말 "디자인이 너무 허접해, 보고 싶지 않아"가 출발점. 한지 위의 제대로 된 만세력 한 판처럼.
  - 표(`.saju-table*`): 4열(시·일·월·연) × 7줄(십신/천간/지지/십신/지장간/십이운성/12신살). **천간·지지 줄은 나무패**(기존 `wood-tablet` 재료, 송명 30px 내외, 오행 색) — 위아래 두 칸이 한 기둥으로 이어진 패처럼. 일주 열(`data-day`)은 금빛 얇은 테로 "나". 나머지 줄은 13px, 녹갈 0.5px 괘선으로 줄을 나눈다. 시간 모름 열(`data-unknown`)은 "?" 흐린 빈 패.
  - 카드 순서: 표 → 오행 분포 → 중심 기운 → 용신 → 신살 → 십이운성 → 대운 → 사주카우에서 더 보기 → 전체 풀이.
  - 중심 기운 카드: 큰 글자(송명 22px) "식상 · 기운이 여린 편" 같은 한 줄이 주인공.
  - 용신 카드: 세 줄 각각 오행 한 글자를 오행 색 원형 도장(지름 32px, 옅은 오행 색 면 + 진한 글자)으로 — 용신이 가장 진하게, 희신·기신은 한 단계 옅게. 기신 도장에 빨강 금지.
  - 신살: 이름 띠지 + 한 줄 뜻. 맨 아래 "신살은 옛 표식일 뿐…" 12px.
  - 대운: kv 두 줄 그대로, 간지에 그 간지 얼굴(`faces/`) 28px를 붙여도 좋다(그림 추가 아님 — 있는 얼굴).
  - **사주카우에서 더 보기**: 테두리 버튼 "내 조선시대 직업 카드 보기 · 갑자" + 글자 링크 "친구와 궁합 보기". 카드 버튼 왼쪽에 내 얼굴 28px.
  - **전체 풀이** (`.saju-paid`): 화면 끝의 금색 면 하나(이 화면의 유일한 금색 면 버튼). 카드는 다른 카드보다 한 단계 힘 있게(금테 `card-gold`). 결제가 닫혀 있으면 "열리면 알림 받기"가 금색 면, "초대 코드가 있어요"는 글자 링크.
- 금색 면 버튼은 화면에 하나 — 만세력 화면에선 전체 풀이 버튼.

### 6. 쓰기 — 행복도가 실시간으로 "팡"
- `.entry-areas__score[data-pop]`: 도장을 누를 때마다 key가 바뀌어 다시 그려진다. 숫자가 **한 번 팡**(0.9 → 1.15 → 1, 약 260ms, 반복 없음). 숫자는 송명 28~32px로 키워 이 카드의 주인공이 되게. 색은 숫자의 단계(`happinessTier`) 면색이 아니라 먹 — 금색 글자 금지(v3.26). 필요하면 숫자 뒤 작은 도장 면(달력 단계 색)을 둬도 된다.
- `.entry-areas__calc`: 숫자 옆(또는 아래 한 줄)에 계산 과정 "(4 + 2 + 3) ÷ 3 = 3.0, × 2" — 13px muted, 고정폭 숫자(tabular-nums). 숫자와 같은 줄에 들어가지 않으면 아래 줄로.
- reduced-motion: 팡 없이 숫자만 바뀐다.

### 7. 나 탭 — 다음 달 예상
- `.day-pick__next`, `.day-pick__card--forecast[data-kind=best|worst]`, `.day-pick__reason`: "가장 행복한 날과 힘든 날" 카드 아래 "12월 예상" 두 칸. 지난 날 카드와 같은 틀이되 **아직 오지 않은 날**이라 한 단계 가볍게(테 점선 1px 또는 종이 면 옅게). 좋은 날 = 금빛 쪽, 조심할 날 = 남색 쪽(빨강 없음). 이유 한 줄 13px.
- 달력: 다음 달까지 넘겨 볼 수 있다. 미래 칸 `[data-forecast=best|worst]`에 작은 표식 `.cal__forecast`(지금 글자 ☀/☂ — 톤에 맞는 작은 도장 점이나 별 모양으로 바꿔도 된다, 그림 새로 만들지 않음).
