# 33 — 운세 카드 "오늘의 특징": 오늘 영역은 짧은 상태말, 이달·올해는 화살표 칩

> 먼저 `00-톤.md`(v3.36까지)를 읽는다. `frontend-design` 스킬로 작업. 출처: 2026-10-31 운세 v4.20(ChatGPT 2차 검토 14항, 사용자 결정 Q1 "(나) 추천대로"). 기능 쪽(데이터)은 끝났다.

## 왜
- v4.19까지 AI가 영역마다 행동 한 문장을 썼다("오늘은 먼저 연락하거나 만나자고 해도 반응이 좋아요"). 한 편에 줄이 3~5개, 본문·하면 좋아요와 같은 조언이 되풀이되고, 이달 줄은 한 달 내내 같은 신호인데 매일 새 문장으로 써져 겹쳤다. "→ 돈 일은 평소와 비슷해요" 같은 군더더기 줄도 자리를 차지했다.
- 이제 행동은 "오늘 해 볼 것"(하면 좋아요·피해요)이 맡고, "오늘의 특징"은 **어느 쪽이 잘 되고 어느 쪽을 조심할지 한눈에**만 보여 준다.

## 데이터 (기능 쪽이 이미 바꿈 — `src/lib/fortune/visible.ts` composeAreas)
- `fortune.areas`(화면은 지금처럼 `areas` 배열을 읽는다)의 각 줄 `{ period, area, signal, line }`:
  - **→ 신호 줄은 더 이상 오지 않는다**(오늘·이달·올해 모두). 닫힌 카드 머리 칩에도 →가 없다.
  - **오늘** 줄: `line` = 코드가 정한 짧은 상태말 7~14자, 예 "말이 엇갈리기 쉬운 쪽", "돈 일이 계획대로 가는 쪽", "몸이 가벼운 쪽". 문장이 아니라 명사구(마침표 없음).
  - **이달·올해** 줄: `line` = `""`(빈 문자열).
  - 옛 캐시(v4.18 이전, `areas`가 저장된 운세)는 `line`에 예전 문장이 들어 있을 수 있다 — `line`이 있으면 줄, 없으면 칩으로 그리면 둘 다 맞는다.
- 오늘 줄 최대 2, 이달 1, 올해 1(그 운 문장이 있는 날만). ↑ 먼저.

## 화면 구조 (펼친 카드 "오늘의 특징")
```
오늘의 특징
오늘 힘이 되는 것  [칩] [칩]          ← 그대로 (v3.36)
(범례 — 처음 한 번, 그대로)
[오늘 · 사람 ↓]  말이 엇갈리기 쉬운 쪽   ← 오늘 줄: 띠지 + 상태말. 짧으니 띠지 오른쪽 같은 줄(좁으면 줄바꿈 허용)
[오늘 · 돈 ↑]    돈 일이 계획대로 가는 쪽
[이달 사람 ↓] [올해 돈 ↑]             ← 이달·올해: 문장 없이 화살표 띠지 칩만 한 줄(가로 줄바꿈)
```
- 오늘 줄의 띠지는 지금 `.trait__tag`(`.sig--line` 재질) 그대로, 상태말은 15~16px 먹색 90%. 줄 사이는 지금(14px)보다 좁혀도 된다(문장이 한 줄이 됐으므로).
- 이달·올해 칩은 오늘 띠지와 같은 재료로 한 단계 작게(기간 글자 muted가 칩 안에 있어 "이달"인지 보인다). 칩 줄은 오늘 줄들 아래 10~12px.
- 영역이 하나도 없으면 지금처럼 섹션째(힘이 되는 것도 없으면) 없음.
- 닫힌 카드 머리의 오늘 영역 칩 `.area-chips`는 그대로(→가 안 올 뿐).

## 상태
- 오늘 0·1·2줄 × 이달 0·1 × 올해 0·1. 오늘 0줄 + 이달 1칩만 있는 날.
- 옛 캐시: `line`에 긴 문장이 있는 줄(이달 포함)도 깨지지 않게 — `line`이 있으면 줄로.
- 375px에서 가장 긴 상태말("손에 든 일에 힘이 실리는 쪽")이 띠지 옆에 들어가는지, 안 들어가면 자연스럽게 아래로.
