# 34 — 쓰기: 행복도는 도장 하나(필수), 영역은 선택

> 먼저 `00-톤.md`를 읽는다(v3.32 쓰기 영역 도장, v3.34 분홍 막대, v3.15·v3.22 네 단계 색). `frontend-design` 스킬로 작업한다. 출처: 2026-11-01 사용자 결정 "일기 기록할 때 6개 영역을 꼭 고르지 않고 행복도만 고를 수 있게". 기능 쪽은 끝났다.

## 왜
- 31번에서 행복도를 "영역 여섯 줄의 평균 × 2"로 바꿨다. 실제로는 영역 하나만 골라도 저장됐지만, 여섯 줄이 행복도 자리를 차지하고 있어 **다 채워야 하는 것처럼** 보였다. 평균 점수가 내 느낌과 어긋나는 날도 있었다(다섯 영역은 보통이고 하나가 아주 나빴던 날).
- 이제 **행복도 = 1~10 도장 하나(필수)**, **영역 = 그 아래 선택 칸**(행복도를 바꾸지 않고 나 탭 영역 통계에만 쓰인다).

## 기능 쪽이 이미 바꾼 것 (`src/app/write/EntryForm.tsx` 로직, `src/lib/entry.ts`)
- 새 fieldset `.entry-happy` (맨 위, `ref`·`name="happiness"` 라디오 1~10): `legend` "행복도" → 점수 줄 `.entry-areas__total`(고르면 `.entry-areas__sum` 안 `.entry-areas__score` 숫자 + `.entry-areas__hint` "점, 괜찮았어요", 안 고르면 "1부터 10까지, 도장 하나", 행복도 없이 저장 누르면 빨간 굵은 글 "행복도를 먼저 골라 주세요") → 분홍 막대 `.happy-bar`(그대로) → 도장 열 `.entry-happy__stamps`(지금은 5열 grid 두 줄) 안의 `.stamp.entry-happy__stamp[data-level=1~10]`.
- 그 아래 fieldset `.entry-areas`: `legend` "영역" + 안내 `.entry-areas__note` "오늘 있었던 것만, 안 골라도 돼요 (N)" → 여섯 줄 `.entry-area`(그대로) → 양 끝 글 `.entry-areas__ends`(그대로).
- 평균 계산 줄 `.entry-areas__calc`는 없어졌다(CSS 지워도 된다). 영역 도장을 눌러도 행복도 숫자는 바뀌지 않는다.

## 수정 가능 파일
- `src/app/write/EntryForm.tsx` — className·JSX 구조·시각 상태만. `name=`·`value`·`onChange`/`onClick`·`onSubmit`·`ref`·`track` 로직은 그대로
- `src/app/globals.css`
- `docs/design/00-톤.md` — "v3.38" 한 단락
- 금지: `src/lib/**`, `src/app/actions.ts`, 다른 화면

## 필요한 에셋
없음. 도장은 지금 `.stamp`·`.entry-stamp` 재료(stamp-empty / 네 단계 면을 stamp-inked-red 알파로 오린 자국).

## 화면 구조 (카드 종이 한 장 안, 위에서 아래)
```
행복도                                  ← legend 17px 굵게 (그대로)
7 점, 괜찮았어요                         ← 숫자 송명(지금 크기) + 말, 팡 그대로
[분홍 막대]                              ← 그대로
(1)(2)(3)(4)(5)                          ← 도장 10개. 375px에서 5 × 2줄 또는 10개 한 줄 중 손가락 자리(≥ 40px)를 지키는 쪽
(6)(7)(8)(9)(10)
────────────── (조용한 구분: 녹갈 0.5px 괘선이나 간격 — 틀 안의 틀은 만들지 않는다)
영역   오늘 있었던 것만, 안 골라도 돼요   ← legend + 안내 13~14px muted. 행복도보다 한 단계 가볍게
일·공부 (1)(2)(3)(4)(5)                  ← 여섯 줄 그대로 (v3.32)
…
아주 힘듦                     아주 좋음
```
- 행복도 도장 10개도 영역 도장과 같은 재료의 **네 단계 면**으로 찍힌다: `data-level` 1~3 남색(low) · 4~5 종이(mid, 옅은 녹갈) · 6~7 금빛(high) · 8~10 moss(top, 숫자 종이색 굵게) — 달력·그래프·날짜 상세의 `data-tier`(v3.22)와 같은 기준. 같은 숫자는 앱 어디서나 같은 색이어야 한다(처음 썼던 v3.15 세 단계는 실수, 2026-11-01 고침). 영역 도장(1~5단계)의 매핑은 v3.32 그대로. 고르지 않은 도장은 stamp-empty + 숫자 muted.
- 영역 칸은 "선택"이 눈에 보이게 행복도보다 가볍게(글 크기·여백·흐린 안내). 다만 흐리게 죽이지는 않는다 — 누르고 싶게.

## 상태
- 처음(아무것도 안 고름) / 행복도만 고름 / 행복도 + 영역 두세 개 / 행복도 없이 저장 누름(점수 줄 빨간 글 + 그 자리로 스크롤) / 예전 기록 고치기(행복도는 이미 찍혀 있고 영역 없음).

## 모션
행복도 숫자 팡(`.entry-areas__score[data-pop]`)과 분홍 막대 폭 200ms는 그대로. 새 모션 없음.

## 하지 않는 것
새 색·새 에셋, 영역 평균 표시, 행복도와 영역을 한 틀에 묶는 상자, 빨강(오류 글 말고).
