# 35 — 운세 카드: "오늘 흐름" 숫자 + 오늘의 영역 6칸 도장 (운세 개편 Phase 2)

> ⚠️ **v2 (2026-11-01 사용자: "디자인이 좀 별로야. 오행 막대처럼 눈에 보이기 쉽게 세련된 막대 디자인으로")** — 아래 "v2 붓 막대" 절이 도장 5칸·2열 × 3행 부분보다 우선한다. 범례·개운 접힘·오늘 흐름 숫자 등 나머지는 v1 그대로.

## v2 붓 막대 (이 절이 우선)
- 기능 쪽이 마크업을 바꿨다(`src/components/AreaSignalGrid.tsx`): `ul.area-grid > li.area-grid__item[data-active][data-dir=up|down|none][data-mixed]`, 줄 = `summary|div.area-grid__row > span.area-grid__label + span.area-grid__bar[data-dir] > span.area-grid__axis + span.area-grid__fill(style --len 0.5 | 1)`. 도장 5칸(`.area-grid__stamp*`)은 없어졌다 — 그 CSS는 지운다.
- **한 영역 = 한 줄**(6줄 세로). 2열 × 3행은 버린다 — 막대는 길어야 읽히고, 이유가 그 줄 아래 **전체 폭**으로 펼쳐져 옆 칸이 비어 보이던 문제도 없어진다.
- 줄 = 이름(왼쪽, 고정 폭 — 오행 막대의 글자 열처럼) + **가운데에서 갈라지는 막대 트랙**(남은 폭 전부).
  - 트랙 가운데에 세로 눈금 `.area-grid__axis` 하나(녹갈 옅게) = "평소/특별한 신호 없음" 기준선.
  - `data-dir="up"` → 막대가 축에서 **오른쪽으로**, 금빛(쓰기 도장 4~5와 같은 단계 면). `data-dir="down"` → 축에서 **왼쪽으로**, 남색(1~2와 같은 면). 길이 = 반쪽 트랙 × `--len`(0.5 한 단계, 1 뚜렷함).
  - 재료는 **오행 분포 붓 막대와 같은 붓 가로획**(`globals.css` 1833~ `.elements__fill`: `brush-stroke.webp` 마스크, 붓 끝이 바깥쪽으로 갈라지게 — 왼쪽 막대는 마스크를 좌우 뒤집어 끝이 왼쪽). 그려질 때 `brush-in`처럼 축에서 바깥으로 한 번 퍼지고, 줄마다 70ms씩 늦게(오행 막대와 같은 리듬). reduced-motion이면 없음.
  - `data-dir="none"`(신호 없음, 섞임 포함): 막대 없이 축 눈금만, 이름 muted. **"보통일 것"처럼 보이는 가운데 막대·점을 만들지 않는다.**
- 신호 있는 줄: 이름 먹 굵게 + 작은 꺾쇠(›, 펼치면 ⌄). 줄 높이(손가락 자리) 44px 이상. 누르면 그 줄 아래 전체 폭에 이유 한 줄(14~15px 먹 80%), 짧은 높이 전환(reduced-motion이면 없음).
- 범례(`SignalLegend kind="stamps"`, 마크업 바뀜): `.area-legend > .area-legend__item[data-kind=down|up|quiet] > span.area-legend__sample[data-tone=down|up|quiet]` + 글 "조심할 쪽" · "좋은 쪽" · "가운데 = 특별한 신호 없음". 견본은 짧은 붓 막대 조각(남색 왼쪽 / 금빛 오른쪽)과 축 눈금 하나.
- 숫자·눈금 수치·게이지 글자는 넣지 않는다(정밀해 보이지 않게). 빨강 금지.
- 375px 스크린샷 이름을 `35v2-*.jpg`로: 신호 2개 + 범례 / 신호 6개 / 이유 펼침 / 섞임 / 옛 캐시 / 닫힘 머리.

## 왜
- 운세가 거의 글로만 설명돼 오늘 어디가 움직이는지 한눈에 안 보였다. 기록 화면과 같은 6개 영역을 같은 "도장" 재료로 보여 줘, 운세와 내 기록이 같은 말을 쓰게 한다.
- 영역 도장은 **예측 점수가 아니다.** 진한 도장 = 오늘 계산에서 그 영역을 위나 아래로 움직이는 신호, 흐린 가운데 도장 = 특별한 신호 없음("보통일 것"이 아니다).
- 숫자는 "운세 점수"가 아니라 **"오늘 흐름 N / 10"**. 단계 말(조심할 편 등)과 숫자가 어긋나지 않게 기능 쪽이 맞췄다(주의 ≤ 4, 보통 5~6, 수월 ≥ 7).

## 기능 쪽이 이미 한 것
- `src/components/FortuneCard.tsx`: 머리 점수 자리가 `오늘 흐름 {flow} / 10`(`.score-brush__score`). 새 운세(오늘 7영역 원자료가 있는 것)는 "오늘의 특징" 안에서 예전 영역 줄·이달·올해 칩 대신 `<SignalLegend kind="stamps" />` + `<AreaSignalGrid areas={six} />`. 옛 캐시는 예전 줄·칩 그대로(두 경우 다 깨지지 않게).
- `src/components/AreaSignalGrid.tsx`(새, 클라이언트): `ul.area-grid > li.area-grid__item[data-active][data-mixed]`.
  - 신호 있는 영역: `details.area-grid__details > summary.area-grid__row(span.area-grid__label + span.area-grid__stamps) + p.area-grid__reason` — 누르면 이유 한 줄(예 "눈에 띄는 것마다 손이 가기 쉬운 쪽이에요."), 다시 누르면 닫힘. 펼칠 때 통계 이벤트(로직은 그대로 둔다).
  - 신호 없는 영역: `div.area-grid__row`(누를 것 없음).
  - 도장 5칸 `span.area-grid__stamp[data-level=1~5]`, 오늘 위치에만 `data-on="active"`(진함) 또는 `data-on="quiet"`(흐린 가운데, 늘 3번 칸).
  - 순서는 기록 화면과 같다: 일·공부 / 돈 / 건강 / 가족 / 연애 / 대인관계.
- `src/components/SignalLegend.tsx`: `kind="stamps"`면 `.area-legend > .area-legend__item[data-kind=active|quiet]` 두 개("진한 도장 = 오늘 신호", "흐린 가운데 도장 = 특별한 신호 없음"), 처음 한 번만(× 로 닫음).

## 화면 구조 (펼친 카드, "오늘의 특징" 섹션)
```
오늘의 특징
오늘 힘이 되는 것 [칩][칩]                 ← 그대로
(범례 · 처음 한 번)  진한 도장 = 오늘 신호   흐린 가운데 = 특별한 신호 없음  ×
┌ 일·공부 ○○◌○○ ┐┌ 돈     ○●○○○ ┐       ← 읽기용 compact: 375px에서 2열 × 3행
│ 건강   ○○◌○○ ││ 가족   ○○◌○○ │          (쓰기 화면처럼 6줄 × 큰 도장 아님)
│ 연애   ○○◌○○ ││ 대인관계 ○●○○○│
└──────────────┘└──────────────┘
  ▸ 누른 영역 아래(그 칸 또는 그 행 전체 폭)에 이유 한 줄
```
- 진한 도장 색은 쓰기 화면 영역 도장과 같은 단계 면: 1~2 남색, 4~5 금빛(3은 active일 수 없다). 흐린 가운데 도장은 녹갈 20~30% 정도로 "자리 표시"처럼 — 진한 도장과 한눈에 갈려야 한다.
- 신호 있는 칸은 이름도 먹색 진하게, 없는 칸은 muted. 누를 수 있다는 단서(작은 ▸ 또는 밑선)는 신호 있는 칸에만. 손가락 자리 40px 이상(칸 전체가 눌림).
- 이유 펼침은 `.fortune-body` 전환과 어울리는 짧은 높이 전환(reduced-motion이면 없음). 이유 글 14~15px 먹색 80%.
- 이달·올해 칩은 새 운세에서 보이지 않는다(기능 쪽이 이미 뺐다). 옛 캐시 화면은 그대로.

## 같이 손볼 것
- **오늘의 개운(`.gaewoon`)은 기본 접힘**: "오늘 챙기면 좋은 것 ›" 한 줄 details로 감싸고 누르면 지금 네 칸이 펼쳐진다(내용·계산 그대로).
- 머리 `오늘 흐름 N / 10`은 지금 점수 자리 그대로(15px muted, 단계 붓 자국 옆). 크게 키우지 않는다(정밀해 보이지 않게).
- 닫힌 카드의 오늘 영역 띠지(`.area-chips`)는 그대로.

## 상태
- 신호 있는 영역 0 · 2 · 3 · 5~6개(5~6개인 날이 열흘에 두 번쯤 있다), 일·공부가 섞임(`data-mixed`, 흐린 가운데), 이유 펼침, 옛 캐시(도장 없음 — 예전 줄·칩), 범례 닫은 뒤.

## 모션
이유 펼침 높이 전환 하나(짧게). 그 밖에 새 모션 없음.
