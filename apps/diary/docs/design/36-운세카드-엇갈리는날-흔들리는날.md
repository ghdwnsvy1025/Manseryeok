# 36 — 운세 카드: "엇갈리는 날", "흔들리기 쉬운 날" 표시

> 먼저 `00-톤.md`(v3.26 금색 규칙, v3.36 핵심 문장이 주인공, v3.39 오늘 흐름)와 명세 `35`를 읽는다. `frontend-design` 스킬을 불러서 작업한다. 출처: 2026-11-04 앱 주인 결정 "추천대로 진행".

## 왜
- 가상 200명 1년치 측정에서 "주의"인데 좋은 영역 막대가 있는 날이 29%, 두 글자 방향이 반대인 날이 48%였다. 숫자 하나로는 "조심하라면서 왜 돈은 좋아요?"가 생긴다.
- 일진과 대운·세운·월운의 충은 2026-11-04부터 점수에 넣지 않는다. 대신 "오늘 평소보다 들쭉날쭉할 수 있다"는 뜻을 카드에 남긴다.
- 카드의 주인공은 계속 제목(핵심 문장)이다. 이 표시는 그 아래에서 어긋남을 풀어 주는 조용한 주석이다.

## 필요한 에셋
없음. 새 그림을 만들지 않는다. 기존 띠지 재료(`.area-chip`)와 토큰만 쓴다.

## 기능 쪽이 이미 한 것 (고치지 않는다)
`src/lib/fortune/areaProfile.ts`의 `dayShapeView(fortune)`:
```ts
{ crossed: boolean; shaky: boolean; line: string } | null
```
- `null`이면 아무것도 그리지 않는다(옛 캐시 포함).
- `crossed` = 엇갈리는 날, `shaky` = 흔들리기 쉬운 날. 둘 다 true일 수 있다.
- `line`은 코드가 정한 한 줄이다. 그대로 보여 주고 문구를 바꾸지 않는다.

## 화면 구조
닫힌 카드(`summary`) 안, 오늘 영역 띠지(`.area-chips`) 바로 아래, `summary`가 끝나기 전:
```
좋음/무난/주의 + 오늘 흐름 N / 10
제목(핵심 문장)
사람 ↓  돈 ↑            ← 기존 띠지
[엇갈리는 날]           ← 새 표시. 둘 다면 [엇갈리는 날] [흔들리기 쉬운 날]
전체로는 조심할 편이지만 돈 쪽은 괜찮아요.   ← 새 한 줄
```
- 마크업: `.day-shape > .day-shape__tags > .day-shape__tag[data-kind=crossed|shaky]` + `.day-shape__line`. 태그 글은 정확히 "엇갈리는 날", "흔들리기 쉬운 날".
- 표시 글 13~14px, 한 줄 글 15px 안팎(본문보다 크지 않게), 먹색 또는 muted. `break-keep`.
- 기존 띠지와 같은 집안으로 보이되 구별되게 한다(예: 면 없는 얇은 녹갈 선). 도장이나 경고처럼 보이지 않게 한다.
- 손가락으로 누를 것이 아니다. 누를 수 있어 보이는 단서를 넣지 않는다(카드 전체를 여는 `summary` 동작 그대로).
- 스크린 리더가 표시와 한 줄을 그대로 읽게 한다.

## 상태별 모습
| 상태 | 모습 |
|---|---|
| `dayShapeView` null | 없음. 지금 카드와 똑같다 |
| crossed만 | 표시 하나 + 한 줄 |
| shaky만 | 표시 하나 + 한 줄 |
| 둘 다 | 표시 둘(한 줄 안, 좁으면 줄바꿈) + 한 줄 |
| 카드 펼침 | 머리에 그대로 남는다. 펼친 본문에 되풀이하지 않는다 |

쓸 수 있는 값 예:
- 엇갈림: "전체로는 조심할 편이지만 돈 쪽은 괜찮아요." / "전체로는 수월한 편이지만 건강 쪽은 조심해요." / "일·공부와 돈 쪽은 괜찮고 건강 쪽은 조심해요."
- 흔들림: "큰 흐름과 오늘이 어긋나 평소보다 들쭉날쭉하게 느껴질 수 있어요."
