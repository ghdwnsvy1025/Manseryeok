## 할 일

1. **옥색:** 크림 카드 종이(#f8ecd1)와 바탕 한지(#f1debb) 위에서 글자 대비가 4.5:1 이상인 깊은 옥색을 고른다(예: #2e6b62 언저리).
   - 오행 나무색 `el-wood`(#2f6b4f)와는 눈으로 갈려야 한다. 나무 기운으로 읽히지 않게 푸른 쪽으로 기울인다.
   - `.fc--blend` 안 지역 변수로 둔다.
2. **인장:**
   - 유리한 점은 옥색 테 + 옥색 글자 + 옥색 줄 이름.
   - 조심할 점은 주홍 테(`el-fire-ink`) + 같은 색 글자 + 같은 색 줄 이름.
3. **게이지:** 높음은 옥색, 낮음은 주홍, 신호 없음은 지금처럼 흐린 남색 또는 흐린 먹(뜻 없는 색). 디자이너가 고르고 보고한다.
4. **술:** 지금 주홍 술은 이제 "조심할 점" 색과 겹친다. 술 색을 **금**(매듭과 같은 색)으로 바꿀지, 주홍으로 둘지 정한다. 기본 권장은 금이다(장식이 뜻을 갖지 않게).
   - 카드와 로딩·실패 카드의 술을 같이 맞춘다.
   - 바꾸면 섞은 톤에서 주홍은 "조심할 점" 하나만 뜻하게 된다.
5. **펼친 안의 나머지:**
   - "하면 좋아요 / 피해요" 라벨에 색이 있으면 같은 짝(옥색 / 주홍)으로 맞추거나 먹으로 둔다. 디자이너 판단이다.
   - "내 기록으로 본 오늘" 비교 막대는 뜻 없는 색 그대로 둔다(금 선 빈 막대 · 먹).
6. **옛 운세의 화살표:** ↑ 주홍(v3.48)은 이제 조심 색이라 뜻이 거꾸로 읽힌다. ↑는 옥색, ↓는 주홍으로 맞춘다.
