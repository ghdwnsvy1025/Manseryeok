# 48 — 만세력: 접힌 줄은 특징 셋, 낱장은 일반 만세력 표 + 다섯 힘 + 힘의 균형

> 명세 47(나 탭 개편) 위에 얹는다. 47이 만든 낱장 틀(`Sheet.tsx`), 권유 칸(`PaidInvite.tsx`)은 그대로 쓴다.

## 왜

앱 주인(2026-11-17): "사주 만세력이 그냥 좀 일반적인 만세력이었으면 좋겠어. 아니면 접혀 있을 때에는 만세력 말고 특징들만 적어 놓고, 펼치면 사주 코어에 있는 그래프처럼 표현하고 싶어."

둘을 다 한다. 접힌 줄은 여덟 글자 대신 **특징 셋**, 낱장을 열면 맨 위에 **흔히 보는 만세력 표**, 그 아래 **사주 코어 진단 낱장 같은 그림 둘**(다섯 힘 막대, 힘의 균형 반원).

참고 그림(사주 코어 유료 풀이, 모양만 참고 — 톤은 일기 것): `사주 앱/사주 코어/docs/design/shots/26-수빈-390x844-1명식낱장.png`(정사각 글자 칸 여덟, 일주 칸 강조, 오행 세로 막대), `18-힘의균형.png`(반원 게이지 + 인장).

## 쓸 값 (`chart` = `sajuChart(...)`, 이미 page.tsx에 있다)

| 값 | 뜻 |
|---|---|
| `chart.columns` | 시·일·월·연 기둥: `stem`·`branch`(한자), `stemElement`·`branchElement`, `stemGod`·`branchGod`(십신, 일간은 "나"), `hidden`(지장간), `unseong`(12운성), `sal12`(12신살), `unknown`(시간 모름) |
| `chart.power` | **새 값.** 오행 순(목화토금수) 다섯 줄: `ko`, `el`, `pct`(정수 %, 합 100 안팎), `group`(비겁…), `plain`(쉬운 말), `role`(용·희·기·구·한 또는 null). 유료 풀이 진단 낱장과 같은 판정용 세력 |
| `chart.center` | `strength`(신강·중화·신약), `strengthPlain`("기운이 센 편"…), `inbi`(비겁+인성 %), `centerGroup`, `centerPlain`, `gyeok` |
| `chart.yongsin` | `use`·`hee`(오행), `useGroup`·`heeGroup`, `unstable`. 못 정했으면 null |
| `chart.elements` | 엔진 분포율(지금 오행 방울이 쓰는 값). **이 낱장에서는 더 쓰지 않는다** — `power`와 계산이 달라 숫자가 다르다. 한 화면에 두 가지 %를 내지 않는다 |

## 필요한 에셋

없음. 지금 만세력 표의 나무 패 그림은 이 화면에서 더 쓰지 않는다(파일은 지우지 않는다).

## 화면 구조

### 본문의 접힌 줄 (나 탭, 내 카드 아래)

여덟 글자를 빼고 특징 셋을 적는다. 줄 전체가 버튼, 오른쪽 `만세력 ›`.

- 왼쪽 위 작은 머리말 `내 사주`
- 세 줄(이름–값, 톤 문서의 kv 줄):
  - `중심` — `chart.center.centerPlain`의 앞 구절(대시 앞까지. 예: "현실을 다루고 거두는 기운")
  - `힘` — `chart.center.strengthPlain`(예: "기운이 고른 편")
  - `필요한 기운` — 용신 오행 한 글자를 오행 색 동그라미로 + 한글(예: 목). `chart.yongsin`이 null이면 이 줄을 뺀다
- 한자 여덟 글자는 여기 없다. 사주 용어(재성·용신·신강)도 이 줄에는 쓰지 않는다 — 쉬운 말만.

### 낱장 안 (위에서 아래로)

1. **명식 — 일반 만세력 표.** 4열(시주·일주·월주·연주) × 아래 행:
   - 십신(천간) — 일주는 `나`
   - **천간** 정사각 칸: 한자 크게(명조), 아래 한글 작게. 칸 바탕은 그 글자 오행의 옅은 색, 글자는 오행 진한 색
   - **지지** 정사각 칸: 같은 꼴
   - 십신(지지)
   - 지장간(한자 나열, 작게)
   - 12운성
   - 12신살
   - 일주 열은 가는 테로 강조. 시간 모름이면 시주 열은 빈 칸에 `?`와 `시간 모름`.
   - 왼쪽에 행 이름(십신·천간·지지·지장간·12운성·12신살)을 작은 글씨로. 360px에서 넘치지 않게 행 이름 열은 좁게.
   - 표 아래 한 줄: 생년월일(지금 있는 줄) + `고치기` 링크.
2. **다섯 힘.** 머리말 `다섯 힘`. `chart.power` 다섯을 세로 막대로(높이 = pct, 가장 큰 값이 그림 높이의 9할). 막대 색은 오행 색. 막대 위에 `NN%`, 아래에 오행 한 글자(오행 색, 명조)와 그 아래 갈래 쉬운 말의 짧은 꼴(두 줄까지). 0%인 오행은 바닥선 위 납작한 옅은 획.
   - `role`이 `용`인 막대 위에 작은 인장 `필요`, `희`면 `도움`. 다른 역할은 표시하지 않는다. `chart.yongsin`이 null이면 인장 없음.
   - 그림 아래 한 문장: `{가장 큰 오행의 plain}이 가장 커요`.
3. **힘의 균형.** 머리말 `힘의 균형`. 반원 게이지: 왼쪽 끝 `여린 쪽`, 가운데 `고른 쪽`, 오른쪽 끝 `센 쪽`. 바늘(동그란 표식) 자리 = `chart.center.inbi`%. 가운데 큰 숫자 `NN%`, 아래 `나를 돕는 기운`. 그 아래 `chart.center.strengthPlain`을 인장 하나로.
   - 작은 글씨 한 줄: `높고 낮음은 좋고 나쁨이 아니에요. 기운을 쓰는 방향이에요`.
4. **풀이 낱말 줄**(이름–값): 중심 기운(`centerGroup` + `centerPlain`), 격(`gyeok`, 있으면), 용신·희신(오행 동그라미 + 갈래) — 여기서는 사주 용어를 쓴다. 용신이 불안정(`unstable`)이면 지금 있는 안내 그대로.
5. 대운, 신살 칩, 사주카우 링크 — 지금 있는 것 그대로.
6. 유료 풀이 권유(`PaidInvite`) — 그대로, 맨 끝 한 곳.

낱장에서 빠지는 것: 맨 위 여덟 글자 한 줄과 오행 방울 줄(엔진 %), 나무 패 표.

## 색

- 오행 색은 일기 앱의 오행 토큰(지금 `ELEMENT_TEXT`가 쓰는 것)을 쓴다. 사주 코어의 색값을 가져오지 않는다. 칸 바탕의 옅은 색은 같은 토큰을 옅게 섞어 만든다(대비: 칸 위 글자 4.5:1 이상).
- 게이지·테는 녹갈·먹. 분홍(코어 도화 톤)은 쓰지 않는다. 금색은 글자·포커스에 쓰지 않는다.
- 옥색·주홍은 "좋을·조심할" 뜻 전용이라 여기서는 쓰지 않는다. `필요`·`도움` 인장은 인주색 도장(톤 문서의 인장 규칙)으로.

## 상태별 모습

| 상태 | 모습 |
|---|---|
| 태어난 시간 앎 | 위 그대로 |
| 시간 모름 | 표의 시주 열 `?`. 다섯 힘·힘의 균형은 세 기둥으로 계산된 값 그대로 + 작은 글씨 `태어난 시간을 넣으면 더 정확해져요`. 용신 null이면 인장·필요한 기운 줄 없음 |
| 한 오행이 0% | 납작한 옅은 획 + `0%` |
| 한 오행이 60% 넘음 | 막대가 그림 높이 9할, 나머지는 비례 |

## 모션

- 낱장이 열릴 때 막대가 바닥에서 자라고(300ms, 한 번) 게이지 표식이 왼쪽 끝에서 제자리로(400ms, 한 번). `prefers-reduced-motion`이면 없음. 그 밖의 새 모션 없음.

## 하지 않는 것

- 사주 코어의 낱장 틀(금테 뇌문 테두리, 도화 가지, 소나무, 구름) 가져오기 — 낱장 머리의 뇌문 띠·매듭(47)만
- 해설 글 쓰기(유료 풀이의 몫). 그림 아래 한 문장씩만
- "다섯 영역 유형", 대운 곡선 등 유료 풀이의 다른 그림
- 새 계산, 새 그림 생성, lib 수정

## 더하기 (2026-11-17 저녁, 앱 주인 "추천대로") — 누르고 싶은 접힌 줄, 권유 자리 올리기

앱 주인: "접혔을 때 만세력을 더 누르고 싶게 하고 싶어. 거기서 유료 풀이를 유도하잖아?" 위 본문과 어긋나는 곳은 이 절이 우선한다.

1. **접힌 줄 = 두 줄 + 그림 맛보기.** 왼쪽에 `중심`·`힘` 두 줄(쉬운 말, 그대로). `필요한 기운` 줄은 접힌 줄에서 뺀다(낱장 안에서 본다). 오른쪽에 **다섯 힘 막대를 아주 작게**(폭 72~84px, 높이 44px쯤): `chart.power` 다섯 막대를 오행 색으로, 숫자·글자·도장 없이 바닥선만. 0%는 납작한 획. 꾸밈 그림이라 `aria-hidden`.
2. **버튼 글귀:** `만세력 ›` → `내 사주 그림 보기 ›`. 낱장 제목은 `만세력` 그대로.
3. **처음 한 번 붉은 점.** 이 기기에서 만세력 낱장을 한 번도 안 열었으면 버튼 글귀 옆에 인주색 작은 점(6px). 열면 사라지고 다시 안 나온다. 기억은 기기에만(`localStorage`, try/catch — 못 읽으면 점을 안 보인다). 서버 렌더와 어긋나지 않게 마운트 뒤에 붙인다. 점은 꾸밈이라 읽어 주는 글은 `새로 생겼어요`(sr-only).
4. **권유 자리:** ~~`PaidInvite`를 "힘의 균형" 바로 아래로 올린다~~ → **"사주카우에서 더 보기" 칸 안으로**(2026-11-18, 앱 주인 "유료풀이광고는 사주카우와 같이 놓아줘"). 그 칸의 순서: 머리말 → 유료 풀이 권유(글귀 · 금색 버튼 · `다음에` · `초대 코드가 있어요` 그대로) → 내 조선시대 직업 카드 보기 → 친구와 궁합 보기. 같은 서비스의 세 가지가 한 묶음으로 읽히게 칸 안은 점선 한 줄로만 가른다. 권유는 여전히 한 곳, 금색 면도 하나. `다음에`로 닫은 30일 동안은 머리말과 카드 보기 · 궁합 보기만 남는다. 낱장 순서: 명식 → 다섯 힘 → 힘의 균형 → 풀이 낱말 → 신살 → 12운성 → 대운 → 사주카우에서 더 보기(권유 포함).
5. **짧은 꼴은 lib 것을 쓴다.** 막대 아래 말은 `chart.power[].short`(기능 쪽이 넣음, `GROUP_SHORT`). 네가 component에 적어 둔 짧은 말 표는 지운다. "~이 가장 커요" 문장도 `short`가 아니라 지금처럼 `plain`의 대시 앞 구절을 쓴다(그대로).
6. **어색한 안내 문장 고치기:** `SajuChartPanel`의 `{GROUP_PLAIN[...]}이 나를 편하게 해요.` → `GROUP_SHORT[...]`로(예: "나와 같은 기운이 나를 편하게 해요.").
7. **기신 줄 되살리기:** 풀이 낱말에 용신·희신 아래 기신 한 줄(전에 있던 꼴 그대로).

끝났을 때 확인(더하기): 375·360·430에서 접힌 줄(점 있음/없음), 낱장의 힘의 균형 아래 권유(보임/닫은 뒤), 풀이 낱말(기신 포함) 스크린샷 `48-6-*`. 접힌 줄이 360px에서 두 줄 글과 작은 막대가 겹치지 않는가 / 붉은 점이 낱장을 한 번 열고 닫으면 사라지는가 / 권유가 한 곳뿐인가.
