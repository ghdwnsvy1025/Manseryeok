- **B-H2 재현 확인**: `/\evil.com`은 `startsWith("/") && !startsWith("//")` 검사를 통과하고, Node 24와 Chrome 모두 `https://evil.com/`으로 해석한다. `/auth/callback`, GoogleButton, LinkGoogleButton, onboarding 네 곳이 같은 검사를 쓴다.
- **C-A1 실측**: 전역 포커스 링이 금색 `#d8a332`이고 한지 `rgb(241,222,187)` 위 대비 1.73:1. 키보드 사용자는 포커스를 거의 볼 수 없다.

## 지금 당장 고칠 것 (순서대로)

1. **나 화면 날짜 범위** — `db.ts:211`의 `-31`을 다음 달 1일 미만(`.lt`)으로. 한 줄. 테스트에 9월·2월 추가. (A-1)
2. **오픈 리다이렉트** — `new URL(raw, origin).origin === origin` 검사로 공통 `safeNext()`를 만들고 네 곳에서 쓴다. (B-H2)
3. **운세 LLM 비용 상한** — SDK `timeout`·`maxRetries: 0`, `page.tsx`에 `maxDuration`, `max_tokens` 4096 이상 + `stop_reason` 확인, API 오류 결과는 그 날 캐시에 쓰지 않기, 프로필 변경 하루 N회 제한, `tokens_in/out` 저장. (A-2·A-3·A-5, B-H1)
4. **금색 포커스 링·활성 탭 라벨** — 포커스 링은 먹색/이끼색으로, 활성 탭은 진한 금색 글자 + 금색 밑줄. 톤 문서에 "금색은 글자·포커스에 쓰지 않는다" 한 줄. (C-A1) → `/design` 경로
5. **"기록 모두 지우기"가 계정까지 삭제** — 라벨과 설명에 범위(기록 N건 + 생년월일)를 적는다. (D-H2)
6. **"기존 Google 계정으로 로그인"이 익명 기록을 즉시 버림** — OAuth 전 `signOut()` 제거(성공 시에만 세션이 교체됨) + 기록이 있으면 두 번 누르기 확인. (B-M2, D-H-1b)
7. **돌아온 Google 사용자의 진입로** — 온보딩과 설정에 `/login` 링크. (D-H-1)
8. **쓰기 화면 PNG 3.3MB 프리로드** — 팡 조각 두 장과 쪽지를 webp 512px로 재납품하고 저장 버튼 누를 때만 로드. (C-P1) → saju-assets
9. **보안 헤더** — `frame-ancestors 'none'`/XFO, Referrer-Policy, nosniff. CSP는 Report-Only부터. (B-M1)
10. **무인증 서버 액션·푸시 endpoint** — `recordShareAction`은 삭제(죽은 코드), 푸시 endpoint는 https + 알려진 푸시 호스트만. (A-9, B-M3·M4)
