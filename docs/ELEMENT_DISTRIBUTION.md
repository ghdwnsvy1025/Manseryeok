## 1. 이 앱 안에서 쓰기

### 1-1. 부르는 방법 세 가지

**① 글자 두 줄로 (가장 간단)**

```ts
calculateElementDistribution("신기병을", "미축술해");
```

**② 옵션 객체로 (운을 섞을 때)**

```ts
calculateElementDistribution({
  stems: "신기병을",
  branches: "미축술해",
  daewoon: { stem: "신", branch: "오" },   // 대운 (선택)
  yearly:  { stem: "갑", branch: "진" },   // 세운 (선택)
  monthly: null,                            // 월운 (선택)
  daily:   null,                            // 일운 (선택)
  calculationMode: "native_with_luck",      // 또는 "luck_only"
});
```

**③ 만세력 결과(`SajuResult.pillars`)를 그대로**

```ts
import { calculateElementDistributionFromPillars } from "@/lib/saju/elementDistribution";

calculateElementDistributionFromPillars(sajuResult.pillars, daewoonInput, yearlyInput);
// 시주가 없으면(출생 시각 모름) 알아서 빼고 일·월·년 3기둥으로 계산
```

> 사주 프로필(`SajuProfilePillars`)을 갖고 있다면 `stemKo`/`branchKo`를 시→일→월→년 순으로 이어 붙여 ①로 부르면 됩니다.
> 예시: [`src/lib/saju/yongsin.ts`](../src/lib/saju/yongsin.ts)의 `layout()`.

### 1-2. 입력 규칙

| 규칙 | 설명 |
|---|---|
| **순서는 시 → 일 → 월 → 년** | 달력 순서(년월일시)가 **아닙니다.** 아래 "순서를 틀리면" 참고 |
| 한글·한자 둘 다 됨 | `"辛己丙乙"` / `"未丑戌亥"`도 같은 결과 (확인함) |
| 천간·지지 글자 수가 같아야 함 | 다르면 `"천간과 지지 길이가 일치해야 합니다."` 에러 |
| 모르는 글자는 에러 | `"Unknown stem: X"` — 화면에서 부를 땐 `try/catch`로 감싸세요 |
| 3기둥도 됨 | 시주 없이 `"기병을"` / `"축술해"` → `{목 16.92, 화 14.81, 토 35.58, 금 13.33, 수 19.36}` |

**순서를 틀리면 — 실제로 돌려 본 결과**

| 넣은 순서 | 원국만 | 대운 섞으면 |
|---|---|---|
| 시일월년 (정상) | 토 36.01 | 토 31.85 |
| 년월일시 (통째로 뒤집음) | 토 36.01 — **같음** | 토 31.89 — **조금 틀림** |
| 일시월년 (섞임) | 토 33.75 — **크게 틀림** | – |

원국 계산은 "왼쪽 옆·오른쪽 옆"을 똑같이 보기 때문에 **통째로 뒤집으면 우연히 같은 값**이 나옵니다. 그래서 테스트를 원국만으로 하면 **순서 실수를 못 잡습니다.** 운을 섞으면 기둥마다 무게(일주 0.35가 가장 큼)가 달라서 그때 틀어집니다. 순서는 반드시 시→일→월→년으로 맞추세요.

### 1-3. 돌려주는 값

```ts
{
  originalPercentage,  // 원국만의 분포 %  ← 대부분 이걸 씁니다
  originalRaw,         // 원국만의 원점수 (합계가 100이 아님)
  percentage,          // 운까지 섞은 최종 %  (운을 안 넣으면 originalPercentage 와 같음)
  raw,                 // 운까지 섞은 원점수
  detail: {            // 계산 과정 전부 — 디버깅·"왜 이렇게 나왔나" 설명용
    branchBase,        // 지지별 기본 분포 (2-1단계)
    banghap, samhap,   // 방합·삼합 성립 여부와 배수
    branchWeighted,    // 지지 위치별 가중합 (2-5단계)
    stemScores,        // 천간별 점수와 곱해진 배수 전부 (2-6단계)
    fireWaterExtreme,  // 화수 보정
    finalMix,          // 원국/대운/세운 섞은 비율
    ...
  }
}
```

**`percentage`는 소수 둘째 자리로 반올림된 값**입니다. 합이 99.99나 100.01이 될 수 있어요.

## 2. 계산 원리 — 원국

원리를 한 문장으로:

> **지지는 "한 오행"이 아니라 속에 숨은 글자(지장간)의 섞임으로 보고, 천간은 자기 아래·옆 지지에서 얼마나 힘을 받는지로 점수를 매긴 뒤, 둘을 더해서 %로 바꾼다.**

아래 7단계를 순서대로 합니다. 괄호 안 §는 명세 절 번호입니다.

### 2-1. 지지 기본 분포 (§3·§4)

지지 하나를 **합계 1짜리 오행 벡터**로 바꿉니다.

**일반 지지** — 지장간 세 글자에 무게를 주고 오행별로 더합니다.

| 자리 | 무게 |
|---|---|
| 여기 | 0.2 |
| 중기 | 0.3 |
| 정기 | 0.5 |

각 지장간 무게에 **양음 배수**(양간 ×1.04 / 음간 ×0.96)를 곱한 뒤, 합이 1이 되게 나눕니다.

```
해(亥) = 무(여기) · 갑(중기) · 임(정기) — 셋 다 양간
  토 0.2×1.04 = 0.208
  목 0.3×1.04 = 0.312
  수 0.5×1.04 = 0.520      합 1.04 → 나누면  토 0.2 · 목 0.3 · 수 0.5
```

**토 지지(축·진·미·술)** — 지장간 대신 **고정 분포표**를 쓰고, 오행마다 대표 지장간의 양음 배수를 곱해 다시 나눕니다.

| 토 지지 | 목 | 화 | 토 | 금 | 수 | 대표 지장간 |
|---|---|---|---|---|---|---|
| 축 | – | – | 0.40 | 0.25 | 0.35 | 기·신·계 |
| 진 | 0.35 | – | 0.40 | – | 0.25 | 을·무·계 |
| 미 | 0.25 | 0.35 | 0.40 | – | – | 을·정·기 |
| 술 | – | 0.35 | 0.40 | 0.25 | – | 정·무·신 |

### 2-2. 방합 (§6) — 지지 **전체**를 키운다

같은 계절 지지가 모이면 그 지지들의 **모든 오행**에 배수를 곱합니다.

| 그룹 | 오행 | 2개 모임 | 3개 모임 |
|---|---|---|---|
| 해자축 | 수 | ×1.2 | ×1.4 |
| 인묘진 | 목 | ×1.2 | ×1.4 |
| 사오미 | 화 | ×1.2 | ×1.4 |
| 신유술 | 금 | ×1.2 | ×1.4 |

성립 여부는 **글자**로 보고, 곱하는 건 **지장간 분포**에 합니다.

### 2-3. 삼합·반합 (§7) — 결과 **오행만** 키운다

| 그룹 | 결과 오행 | 가운데 글자 |
|---|---|---|
| 해묘미 | 목 | 묘 |
| 신자진 | 수 | 자 |
| 인오술 | 화 | 오 |
| 사유축 | 금 | 유 |

| 모인 모양 | 기본 배수 |
|---|---|
| 셋 다 | 1.35 |
| 둘 + 가운데 글자 포함 | 1.18 |
| 둘 + 양끝만 | 1.08 |

**떨어져 있으면 약해집니다.** 모인 글자들의 위치 차이(span)에 따라:

| span | 거리 계수 |
|---|---|
| 1 (붙어 있음) | 1.00 |
| 2 | 0.75 |
| 3 (양끝) | 0.55 |

```
실제 배수 = 1 + (기본 배수 − 1) × 거리 계수

예) 해(년)·미(시) — 해묘미 양끝, span 3
    1 + (1.08 − 1) × 0.55 = 1.044
```

같은 글자가 여러 번 있으면 **span이 가장 작은 조합**을 고릅니다.

### 2-4. 같은 층끼리 생극 (§9)

**천간끼리**, **지지끼리**만 서로 영향을 줍니다 (천간↔지지 사이는 여기서 안 봄).

| 관계 | 효과 |
|---|---|
| 옆 글자가 나를 생함 | +0.08 |
| 옆 글자가 나를 극함 | −0.10 |

| 거리 | 계수 | | 같은 오행 연속 개수 | 계수 |
|---|---|---|---|---|
| 1 | 1.00 | | 1 | 1.00 |
| 2 | 0.35 | | 2 | 1.35 |
| 3 | 0.15 | | 3 | 1.60 |
| | | | 4 | 1.80 |

```
배수 = 1 + Σ(효과 × 거리 계수 × 연속 계수)   → 0.72 ~ 1.22 로 자름
```

지지는 한 오행이 아니므로, **지장간 분포의 오행 성분마다** 따로 계산해 곱합니다 (성분 크기도 곱함).

### 2-5. 화수(火水) 보정 (§10)

불과 물이 **둘 다 0.15 이상** 있고 한쪽이 확실히 셀 때만(차이 0.1 이상) 적용합니다. 대표오행이 아니라 **지장간의 화·수 성분**으로 봅니다.

| 우세 | 화 성분 감소 | 수 성분 감소 |
|---|---|---|
| 수가 셈 | 0.40 × 접촉 | 0.15 × 접촉 |
| 화가 셈 | 0.15 × 접촉 | 0.40 × 접촉 |

- 접촉 = 가까운 지지의 반대 성분 × 거리 계수(1 / 0.35 / 0.15) 중 최댓값
- 같은 성분이 연달아 있으면 그룹 안에서 접촉값을 공유
- 연달아 있으면 우세 판정에 `+0.2 × (연속 수 − 1)` 보너스
- 결과 배수는 0.7 ~ 1.0

**같은 기둥 안(천간↔지지)**도 따로 봅니다.

| 조합 | 천간 배수 | 지지 해당 성분 배수 |
|---|---|---|
| 화 천간 + 지지에 수 성분 | 0.92 | 수 ×0.97 |
| 수 천간 + 지지에 화 성분 | 0.97 | 화 ×0.92 |

### 2-6. 지지 위치별 가중합 (§5)

각 지지 자리마다 **자기 × 1 + 왼쪽 × 0.2 + 오른쪽 × 0.2**를 더합니다.

```
기여 = 기본분포[오행] × 자리무게(1 또는 0.2)
     × 방합배수 × 삼합배수[오행] × 지지양음(양 1.03 / 음 0.97)
     × 생극배수[오행] × 화수배수[오행] × 간지화수배수[오행]
```

> ⚠️ **1.4로 나누지 않습니다.** 명세가 두 번 강조하는 부분입니다. 평균이 아니라 합입니다.

### 2-7. 천간 점수 (§8)

천간은 **자기가 선 지지와 양옆 지지에서 얼마나 힘을 받는지**로 점수를 매깁니다.

```
도움값(천간, 지지분포) = 지지분포[천간의 오행] × 1
                       + 지지분포[천간을 생하는 오행] × 0.5

raw = 도움값(자기 아래 지지) × 1
    + 도움값(왼쪽 지지) × 0.2
    + 도움값(오른쪽 지지) × 0.2

점수 = max(raw, 0.4)                     ← 최소 0.4 보장
     × 인접 동일 천간(같은 글자가 붙어 있으면 1.25)
     × 양음(양간 1.04 / 음간 0.96)
     × 천간끼리 생극 배수(2-4)
     × 간지 화수 배수(2-5)
```

생하는 오행: 목←수 · 화←목 · 토←화 · 금←토 · 수←금

### 2-8. 합산 → %

```
원점수[오행] = Σ 지지 가중합[오행] + Σ 천간 점수(그 천간의 오행에만)
분포율[오행] = 원점수[오행] / 원점수 합계 × 100   (소수 둘째 자리 반올림)
```

## 5. 운 섞기 — 명세와 얼마나 같은가

운(대운·세운·월운·일운)은 **원국 원점수를 건드리지 않고, % 단계에서 섞습니다.**

### 5-1. 섞는 비율

| 넣은 운 | 원국 | 대운 | 세운 | 명세와 |
|---|---|---|---|---|
| 없음 | 100% | – | – | ✅ 같음 |
| 대운 | 50% | 50% | – | ✅ 같음 |
| 세운 | 75% | – | 25% | ✅ 같음 |
| 대운 + 세운 | 40% | 40% | 20% | ✅ 같음 |

각 운의 % 자체도 섞어서 만듭니다.

| 운 | 구성 | 명세와 |
|---|---|---|
| 대운 | 대운 자체 40% + 원국 기둥에 미친 영향 60% | ✅ 같음 |
| 세운 (대운 없을 때) | 자체 40% + 원국 영향 60% | ✅ 같음 |
| 세운 (대운 있을 때) | 자체 30% + 원국 영향 45% + 대운 영향 25% | ✅ 같음 |

원국 기둥별 영향 무게 (시·일·월·년): **0.25 · 0.35 · 0.25 · 0.15** — 일주가 가장 큽니다.

### 5-2. ⚠️ 코드가 근사하는 부분

| 모드 | 명세 (§13·§14) | 지금 코드 |
|---|---|---|
| **월운·일운 포함** (`native_with_luck`) | 원국 40% · 대운 32.26% · 세운 16.13% · 월운 7.74% · 일운 3.87% | 원국+대운+세운 결과와 "선택한 운만으로 계산한 값"을 **50:50** |
| **간단 모드** (`luck_only`) | 대운 53.76% · 세운 26.88% · 월운 12.90% · 일운 6.45%, 운끼리 12쌍 상호작용, 자체 55% + 상호작용 45% | 운 기둥들을 **원국 계산식에 그대로 넣어 근사** |

코드 주석에도 `APPROXIMATE (자료 B §13 대비)`라고 적혀 있습니다. **이 두 모드의 %를 정확한 값처럼 쓰지 마세요.**

명세대로의 비율 **숫자 자체**는 [`luckRates.ts`](../src/lib/astrology/luckRates.ts)에 따로 구현돼 있습니다 (`LUCK_BASE_WEIGHTS` 대운 50 · 세운 25 · 월운 12 · 일운 6, 합계 상한 60).

> 원국만·대운·세운을 쓰는 경우라면 걱정 없습니다. 지금 앱의 사주 원국 화면·용신·운세 LLM 입력은 모두 이쪽입니다.

## 7. 자주 틀리는 것

| 함정 | 올바른 방법 |
|---|---|
| 입력을 년→월→일→시로 넣음 | **시→일→월→년**. 원국만 테스트하면 뒤집어도 같은 값이 나와서 실수가 숨습니다 — **운을 섞은 경우로도 꼭 확인** |
| 지지를 대표오행 하나로 계산 (술 = 토) | 반드시 **지장간 분포 벡터** (술 = 화 0.34 · 토 0.42 · 금 0.24) |
| 자기 1 + 옆 0.2 + 옆 0.2를 1.4로 나눔 | **나누지 않음** |
| 방합을 결과 오행에만 곱함 | 방합은 **지지 전체**, 삼합은 **결과 오행만** |
| 천간↔지지 사이에도 생극 보정 | 생극 보정은 **천간끼리·지지끼리만** (단, 같은 기둥의 화수는 따로) |
| 운을 원점수에 더함 | 운은 **% 단계에서** 섞음 |
| 옛날 숫자를 씀 | 아래 표 참고 |
| 중간값을 반올림 | **최종 %만** 반올림 |
| `辛`과 `申`을 둘 다 "신"으로 처리 | 천간 자리면 辛(금 천간), 지지 자리면 申(금 지지) — 자리로 구분됨. 한자로 넣으면 안전 |

### 명세 §18 — 이제 쓰면 안 되는 옛날 값

| 항목 | 옛날 | **지금** |
|---|---|---|
| 천간 최소값 | 0.5 | **0.4** |
| 인접 동일 천간 | 1.5 | **1.25** |
| 원국 방합 | 1.5 | **2개 1.2 / 3개 1.4** |
| 운 간지 생 받는 쪽 | 1.5 | **1.25** |
| 운 간지 극 당하는 쪽 | 0.5 | **0.75** |
| 대운 같은 천간·지지 | 1.5 | **1.2** |
| 외부 방합 | 1.5 | **2개 1.15 / 3개 1.3** |
| 대운 영향률 | 25%·30% 고정 | **LUCK_BASE_WEIGHTS + 상한 60** |
| 대운 기둥 비중 | 0.25 · 0.25 · 0.25 · 0.25 | **0.25 · 0.35 · 0.25 · 0.15** |

인터넷이나 예전 파일에서 가져온 코드가 있다면 이 값부터 확인하세요.

## 8. 해석할 때 (명세 자료 A 원칙)

- 분포율은 **해석을 돕는 보조 지표**입니다. "토 36%라서 이런 사람이다"라고 단정하지 않습니다.
- 원국 분포 = 타고난 재료 / 운을 섞은 분포 = 특정 시기의 체감 흐름 / `luck_only` = 원국과 무관한 운 자체의 분위기.
- 최종 해석은 일간·월지·일지·T존·십신·자리·합충과 함께 봅니다.
