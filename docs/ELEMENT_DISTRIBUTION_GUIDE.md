# 오행 분포율 계산 정리

> 사주 8글자(+ 선택한 운)에서 **목·화·토·금·수 비율(%)** 을 구하는 과정을 코드 기준으로 정리한 문서.
> 기준 코드: `src/lib/saju/elementDistribution.ts` (약 3,250줄, 2026-09-25 시점)
> 만세력(기둥 계산)은 `MANSERYEOK_CALCULATION_GUIDE.md` 참고.

---

## 1. 핵심 개념

단순히 "글자 8개 중 목이 몇 개"를 세지 않는다. 각 글자에 **점수**를 매기고 여러 보정을 곱한다.

- **지지**는 한 오행이 아니라 **지장간 비율로 쪼갠 벡터**로 본다. 예) 午 = 화 70% + 토 30%.
- **천간**은 뿌리(주변 지지가 같은 오행이거나 생해주는 오행인지)에 따라 점수가 달라진다.
- **거리**를 반영한다. 붙어 있는 글자끼리는 영향이 크고, 멀수록 작다.
- **생극, 방합·삼합, 화수 충돌, 음양**을 배수로 반영한다.
- 마지막에 모두 더해 100%로 정규화하고, 소수 둘째 자리에서 반올림한다.

> 앱 원칙(`.cursor/rules/00-saju-core.mdc`): **오행 %는 보조 지표**다. 길흉 판정이나 절대 점수에 쓰지 않는다.

## 2. 입력과 출력

```ts
// 원국만 (만세력 계산 시 자동 호출)
calculateElementDistributionFromPillars(pillars)            // 기둥 객체 → 시·일·월·년 순으로 문자열화

// 직접 호출
calculateElementDistribution({
  stems:    "계경신경",   // 천간: 시 → 일 → 월 → 년 순서 (한글/한자 모두 가능)
  branches: "미진사오",   // 지지: 같은 순서
  daewoon:  { stem: "임", branch: "오" },  // 선택
  yearly:   { stem: "병", branch: "오" },  // 선택
  monthly, daily,                          // 선택 (근사 계산)
  viewMode: "diary_detail" | "simple",     // simple이면 운만 보는 luck_only 모드
});
```

- **순서가 중요하다**: 위치 index 0 = 시주, 1 = 일주, 2 = 월주, 3 = 년주. 이웃 판정은 이 순서를 기준으로 한다.
- 시간을 모르면 3글자(일·월·년)로 계산한다.
- 출력:
  - `originalRaw`, `originalPercentage`: 원국만의 점수와 %
  - `raw`, `percentage`: 운을 섞은 최종 점수와 % (운이 없으면 원국과 같다)
  - `detail`: 모든 중간값(디버그와 설명용)

## 4. 원국 계산 순서 (`computeOriginalDistribution`)

### ① 지지 기본 분포 — `getBranchBaseDistribution`
- 일반 지지: 지장간 3개에 `0.2 / 0.3 / 0.5 × 해당 천간의 음양계수(1.04 또는 0.96)`를 곱해 오행별로 더한 뒤 합이 1이 되도록 정규화한다.
- 토 지지: 3-3 표의 값에 오행별 대표 지장간의 음양계수를 곱한 뒤 정규화한다.
- 예) 午 = 병(0.2×1.04) + 기(0.3×0.96) + 정(0.5×0.96) → **화 0.705, 토 0.295**

### ② 지지끼리 생극 — `getBranchPeerElementMultipliers`
대상 지지의 **오행 성분마다** 다른 지지들이 주는 영향을 합한다.
```
delta = Σ(다른 지지 j, j의 오행 성분 e)
          ± 계수 × j의 e 비율 × 거리계수 × 연속계수
   e가 대상 오행을 생하면 +0.08, 극하면 −0.10
배수 = clamp(1 + delta, 0.72, 1.22)
```
- 거리계수: 바로 옆 1.0, 두 칸 0.35, 세 칸 0.15
- 연속계수: 같은 오행 성분이 1개면 1.0, 2개 연속이면 1.35, 3개면 1.6, 4개면 1.8 (뭉쳐 있으면 힘이 세진다)

### ③ 지지 화수(火水) 충돌 보정 — `getBranchFireWaterElementMultipliers`
- 조건: 지지들의 화 합계와 수 합계가 **둘 다 0.15 이상**이고 한쪽이 우세할 때만 적용한다.
- 우세 판정: `점수 = 합계 + 0.2 × (연속 구간 길이 − 1)`. 두 점수 차가 0.1 미만이면 균형으로 보고 보정하지 않는다.
- 접촉계수: 반대 오행이 주변에 얼마나 가까이 있는지(`반대 성분 × 거리계수`의 최댓값). 연속 그룹은 같은 값을 공유한다.

| 우세 | 화 배수 | 수 배수 |
|---|---|---|
| 수 우세 | 1 − 0.40 × 수접촉 | 1 − 0.15 × 화접촉 |
| 화 우세 | 1 − 0.15 × 수접촉 | 1 − 0.40 × 화접촉 |

배수 범위는 0.7 ~ 1.0이다. **약한 쪽이 더 크게 깎인다.**

### ④ 같은 기둥의 천간–지지 화수 보정 — `getGanjiFireWaterMultipliers`
| 조합 | 천간 배수 | 지지의 해당 성분 배수 |
|---|---|---|
| 화 천간 + 지지에 수 성분 있음 | ×0.92 | 수 ×0.97 |
| 수 천간 + 지지에 화 성분 있음 | ×0.97 | 화 ×0.92 |

### ⑤ 천간끼리 생극 — `getPeerInteractionMultipliers`
②와 같은 공식을 천간의 대표 오행 하나로 적용한다. 생 +0.08, 극 −0.10, 거리·연속 계수는 같고, 범위는 0.72 ~ 1.22다.

### ⑥ 방합 — `computeOriginalBanghap`
| 방합 | 해자축(수) | 인묘진(목) | 사오미(화) | 신유술(금) |
|---|---|---|---|---|
| 2글자 | ×1.2 | | | |
| 3글자 | ×1.4 | | | |

해당 지지의 **분포 전체**에 곱한다(방합 오행 성분만이 아니다). 거리 보정은 없다.

### ⑦ 삼합·반합 — `getSamhapMatches`
| 삼합 | 해묘미(목) | 신자진(수) | 인오술(화) | 사유축(금) |
|---|---|---|---|---|
| 중심 글자 | 묘 | 자 | 오 | 유 |

| 유형 | 기본 배수 |
|---|---|
| 3글자 완성 | 1.35 |
| 2글자, 중심 포함 | 1.18 |
| 2글자, 가장자리만 | 1.08 |

- 거리 보정: `실제 배수 = 1 + (기본 − 1) × 거리계수`. 거리계수는 글자 간 간격(span) 1이면 1.0, 2면 0.75, 3이면 0.55.
- 삼합에 참여한 지지의 **삼합 오행 성분에만** 곱한다.

### ⑧ 지지 위치별 점수 — `computeBranchWeightedPosition`
각 자리의 점수 = **자기 지지 × 1.0 + 양옆 지지 × 0.2**
```
기여분[오행] = 기본분포[오행] × 위치가중(1.0 또는 0.2)
             × 방합배수 × 삼합배수[오행] × 지지음양계수
             × 생극배수[오행] × 화수배수[오행] × 간지화수배수[오행]
```
→ 가운데 지지(일지·월지)는 1.0 + 0.2 + 0.2 = **1.4배**, 끝 지지(시지·년지)는 **1.2배**로 반영된다.

### ⑨ 천간 점수 — `computeStemScoreDetails`
천간은 **자기 오행 하나에만** 점수를 준다.
```
도움값(지지) = 지지 분포[같은 오행] × 1.0 + 지지 분포[나를 생하는 오행] × 0.5
원점수 = 도움값(자기 지지) × 1.0 + 도움값(양옆 지지) × 0.2
최종 = max(원점수, 0.4)                  ← 뿌리가 없어도 최소 0.4
       × 1.25 (바로 옆 천간이 같은 글자면)
       × 천간음양계수 × 천간생극배수 × 간지화수배수
```

### ⑩ 합산과 백분율
```
원국 점수 = Σ 지지 위치 점수 + Σ 천간 점수
원국 %    = 오행 점수 / 전체 합 × 100   (소수 둘째 자리 반올림)
```

## 5. 운(대운·년운·월운·일운)을 섞을 때

원국 %와 운 %를 **가중 평균**한다.

| 선택한 운 | 원국 | 대운 | 년운 |
|---|---|---|---|
| 없음 | 100% | – | – |
| 대운만 | 50% | 50% | – |
| 년운만 | 75% | – | 25% |
| 대운 + 년운 | 40% | 40% | 20% |

- **대운 %** = 대운 자체 40% + 대운이 원국 기둥에 미치는 작용 60%
  - 대운 자체: 천간 0.5 + 지지 0.5. 간지 내부 생극, 원국과 같은 글자(×1.2), 방합(2자 ×1.15, 3자 ×1.3), 삼합(거리 0.85 고정), 화수, 음양을 반영한다.
  - 원국에 미치는 작용: 기둥 가중치 **시 0.25 · 일 0.35 · 월 0.25 · 년 0.15**. 원국 각 기둥의 천간·지지 점수에 생극 배수(0.88 ~ 1.12)를 곱한다.
- **년운 %** = 자체 30% + 원국 작용 45% + 대운 작용 25% (대운이 없으면 자체 40% + 원국 60%)
- **월운·일운**이 들어가면: 위 결과 50% + (일·월·년·대운을 원국처럼 한 줄로 놓고 계산한 값) 50%
  → 코드와 `docs/SAJU_CALCULATION_SPEC.md`에 **근사(approximate)** 로 표시돼 있다. 개인화 학습에서는 제외된다(`eligibleForTraining: false`).
- **luck_only 모드**(`viewMode: "simple"`): 원국을 빼고 운 기둥만 같은 엔진으로 계산한다. 이것도 근사다.

## 6. 실제 계산 예시 (코드를 직접 실행한 결과)

사주: **계미시 · 경진일 · 신사월 · 경오년** (양력 1990-05-15 14:30 남자)
→ `stems = "계경신경"`, `branches = "미진사오"`

**지지 기본 분포**
| 자리 | 지지 | 목 | 화 | 토 | 금 | 수 |
|---|---|---|---|---|---|---|
| 시 | 미 | 0.25 | 0.35 | 0.40 | – | – |
| 일 | 진 | 0.34 | – | 0.42 | – | 0.24 |
| 월 | 사 | – | 0.50 | 0.20 | 0.30 | – |
| 년 | 오 | – | 0.70 | 0.30 | – | – |

**적용된 보정**
- 방합 **사오미(화) 3글자 → ×1.4** (미·사·오 전체)
- 삼합 없음
- 화수 보정 적용: **화 우세**
- 천간 원점수: 계 0.05, 경(일) 0.33, 신 0.47, 경(년) 0.23 → 신을 뺀 셋은 뿌리가 약해 **최소 0.4**로 올라간다.
  - 확인용 계산) 신(금) = 사[금 0.3 + 토 0.2×0.5] × 1.0 + 진[토 0.42×0.5] × 0.2 + 오[토 0.30×0.5] × 0.2 ≈ **0.471**

**결과**
| 목 | 화 | 토 | 금 | 수 |
|---|---|---|---|---|
| **10.67%** | **31.77%** | **26.69%** | **22.49%** | **8.38%** |

글자 수로만 세면 금이 3개(경·신·경)로 가장 많다. 하지만 천간의 뿌리가 약하고 지지에 사오미 화 방합이 있어서 **화가 1위**로 나온다.
