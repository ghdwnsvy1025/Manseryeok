# 오늘의 운세 — 계산 로직과 사용 이론 (2026-11-02 코드 기준)

운영 판본: 글 v4.21b + 개편 Phase 2(오늘 흐름, 영역 막대). 작업 트리의 한마디(v4.24)는 미배포.
코드: 판정 규칙 `packages/saju-core-rules/src/`(사주 코어에서 복사, 여기서 고치지 않음) → 하루 조립 `apps/diary/src/lib/fortune/core.ts` → 기록 보정 `personal.ts` → 글 계획 `plan.ts` → 글 `llm.ts`.
규칙의 근거 표기: `Y-05`·`C-08`·`E-11` 등은 사주 코어 규칙 문서 번호, `카드 012` 등은 앱 주인이 확답한 판정 카드, `[가설]`은 코드에 가설로 적힌 값.

## 0. 한눈에

```
생년월일시 → 원국 네 기둥
  → 세력(오행 %) → 신강/중화/신약 → 중심기운 → 용신 → 용·희·한·구·기 역할
오늘 일진 두 글자 → 글자마다 십신과 역할 → 점수: 천간 ×1.5, 지지 ×1  = raw
일진 지지 ↔ 원국 지지 충 → rel
대운·세운(판정) → ctx
점수 = toScore01(raw × w + rel + ctx) + 내 기록 보정 → 10점 환산 → 단계(좋음·무난·주의) → "오늘 흐름"
일진 글자의 십신 → 영역 신호(막대)
코드가 고른 계획 → AI가 글로 씀
```
숫자와 판정은 전부 코드가 계산한다. AI는 글만 쓴다.

## 2. 원국 분석 (`yongsin.ts`)

**세력(Y-02)**: 기본 방식 `정기연속80엔진20`(카드 016·033). 유료 풀이·만세력과 같은 값.
- 글자 가중치: 일간 1, 연간 1, 월간·시간 1.5, 연·월·시지 1.5, 일지 2.25.
- 같은 오행 글자가 바로 옆에 붙어 있으면 그 글자 ×1.2 `[가설]`(카드 033).
- 최종 % = 이 값 × 0.8 + 엔진 오행 분포 공식 × 0.2(카드 016).

**신강약(Y-03)**: 인비(비겁 % + 인성 %) ≥ 55 신강, ≤ 45 신약, 그 사이 중화.

**중심기운(Y-04)**: %가 가장 큰 그룹. 1·2위 차이가 3 미만이면 혼합.

**용신(Y-05, 현묘표)**
- 신강 → 재성
- 신약 → 중심이 식상·재성·관성이면 현묘표(식상→인성, 재성→비겁, 관성→비겁). 중심이 비겁·인성이면(모순) 식상 ≥ 재·관일 때 인성, 아니면 비겁. "판정 불안정" 표시
- 중화 → 현묘표(비겁→재성, 인성→재성, 식상→인성, 재성→비겁, 관성→비겁)

**역할(Y-06)**: 용신 기준 상생 고리에서
- 용신을 생하는 그룹 = 희(도움), 용신이 생하는 그룹 = 한(무난)
- 용신을 극하는 그룹 = 기(가장 나쁨), 용신이 극하는 그룹 = 구(나쁨)
- 보충(카드 012): 신약에 인성 용신이면 희 = 비겁, 한 = 관성

**시간 모름(Y-10, v4.12)**: 12개 시주를 모두 넣어 가장 많이 나온 용신 오행을 쓴다. 일치율 w = 표 ÷ 12. w만큼 유불리 폭을 줄인다. 시간을 알면 w = 1.

**조후(J-04·05, 온도)**: 월지 ±3·±1, 시지 ±1, 나머지 화 글자 +1·수 글자 −1로 온도 점수. |점수| ≥ 6 `[가설]`이면 극단으로 보고 운 판정에 글자 온도를 더한다.

## 3. 일진 판정 (`luck`, Y-09)

글자마다 **역할 → 점수**, 천간은 ×1.5, 지지는 ×1. `합계 = 천간 + 지지` = raw.

| 역할 | 용 | 희 | 한 | 구 | 기 |
|---|---|---|---|---|---|
| 천간 | +3 | +1.5 | +0.75 | −1.5 | −3 |
| 지지 | +2 | +1 | +0.5 | −1 | −2 |

판정: ≥ 3 매우 유리, > 0 유리, 0 보통, ≤ −3 어려움, 그 밖 주의. 천간·지지가 모두 한신이면 "보통"(v4.1).

**점수를 바꾸는 특수 규칙** (대부분 앱 주인 확답 카드, 값은 `[가설]`)
| 규칙 | 조건 | 처리 |
|---|---|---|
| Y-12 | 비겁 중심 신강의 관성 운 | 한신이지만 희신급으로(인비 혼합이면 비겁 비율만큼) |
| Y-12 신약 | 신약 + 인성 용신의 비겁 운 | 희신급 |
| 카드 014·019·031·021 | 신약의 관성 운 | 원국에 관성 없음 → 희신급 / 양간+편관 기신급, 양간+정관 −0.5, 음간+편관 −1, 음간+정관 −0.5 / 관성 중심의 정관 → 기신급 / 식상 중심의 지지 관성 → 0 |
| Y-13 | 극단 비겁(원국에 식·재·관 없음) | 식상 +2, 비겁·인성 −1, 재·관 −2 |
| Y-14 | 비겁 중심 신강 | 그 층에 식·재·관이 없으면 비겁 운 −1. 비겁 ≥ 70%면 재·관 운 절반 |
| Y-15 | 비겁 중심 신강 + 원국 지지 비겁 3개 이상 | 지지 재성 −2(군겁쟁재), 지지 관성 절반 |
| 카드 013 | 운 천간이 원국 비겁 천간과 천간합 | 천간 점수 절반 |
| J-05 | 조후 극단 | 글자 온도(화 +1, 수 −1, 未戌 +0.5, 丑辰 −0.5)를 맞추는 쪽으로 가감 |

**플래그(점수 없음, 글 재료)**: 용신 손상(운 글자가 원국 용신 글자를 극·합), 운 내부 상충(절각·개두), 중화 사주, 신강 관성 반동(카드 021·025) 등.

## 4. 일진 ↔ 원국 관계 (`luckRelations`, `core.ts`)
| 이론 | 점수 | 내용 |
|---|---|---|
| **충**(C-08) | **있음** | 일진 지지가 원국 지지와 충. 강도 = 자리(연 1, 월 3, 일 3, 시 2). 丑未충은 −1 |
| 충의 방향 | | 寅申→寅, 巳亥→巳, 子午→午, 卯酉→卯가 위축. 위축 글자 오행이 용·희면 불리, 기·구면 유리, 그 밖·辰戌丑未는 중립 |
| 합(삼합·반합·육합) | **없음**(v4.2) | 표시만 |
| 복음(같은 지지) | **없음** | 글 재료 "비슷한 일이 되풀이되기 쉬워요" |

`rel` = 충마다 불리 −0.5 × 강도, 유리 +0.5 × 강도, 중립 0. 합계는 ±1.5 안. 시간 모름은 `w × 방향값 + (1 − w) × (−0.25 × 강도)`.
자리의 생활 영역(v4.5): 연 = 오래된 인연, 월 = 집안이나 일터, 일 = 나와 가까운 사람, 시 = 앞으로의 계획.

## 5. 맥락: 대운·세운·월운 (`core.ts`)
- 세운은 **입춘** 기준(입춘 전이면 전년). 월운은 절기 기준 월 간지. 대운은 출생 정보로 계산.
- `ctx` = 대운 합계 × 0.2 × w + 세운 합계 × 0.15 × w(월운 판정은 0)
일진과 대운·세운·월운의 충은 2026-11-04부터 점수에 넣지 않는다(코어 답_Q72-Q75, 미배포). 글의 맥락 문장과 카드 "흔들리기 쉬운 날" 표시에만 남는다.

## 6. 점수 → 단계 → 오늘 흐름
```
합 = raw × w + rel + ctx
score01 = 0.5 + 합/12            (합 ≥ 0, 상한 0.92)
        = 0.5 + 0.38·tanh((합/12)/0.38)  (합 < 0, 바닥 0.12에 다가감)
최종 = score01 + 내 기록 보정 (7절), 10점 환산 = ×10 (소수 한 자리)
단계: ≥ 6.8 좋음(수월한 편) / ≥ 4.8 무난(보통) / 그 아래 주의(조심할 편)
오늘 흐름 N: 반올림을 단계 범위 안으로(주의 ≤ 4, 무난 5~6, 좋음 ≥ 7)
```
가상 200명 × 360일 단계 분포(충 변경 전): 주의 42%, 무난 30%, 좋음 28%. 사람마다 주의 비율이 크게 달라 10명 중 8명이 약 23~60%이고 최대 75%다. 전에 적은 "주의 49%"는 6명 표본의 값이었다.

## 7. 내 기록 보정 (`personal.ts`, v4.19)
오늘 일진과 천간이나 지지가 같은 날의 기록 n개를 찾아
`shift = (n/(n+5)) × (그 날들 평균 행복도 − 전체 평균 행복도) / 9`, ±0.08(10점 눈금 ±0.8)로 자른다.
전체 기록 10개 미만이거나 n < 3이면 0. 사주 이론이 아니라 개인 통계다. 영역 점수는 아직 쓰지 않는다.

## 8. 영역 신호 = 막대 (`luckAreas` E-11, `areaProfile.ts`)
일진 글자의 **십신 그룹 → 건드리는 영역**:
| 그룹 | 영역 |
|---|---|
| 비겁 | 대인, 재물 |
| 식상 | 직업, 학업 |
| 재성 | 재물, 대인, 연애(남성만, 전통 배우자성) |
| 관성 | 직업, 연애(여성만, 전통 배우자성) |
| 인성 | 학업, 가족, 건강 |

- 영역 세기 = 그 영역을 건드린 글자 점수의 합(3절 점수, 한신은 0). |합| ≥ 1이면 신호.
- 그래서 하루 세기가 "천간 값, 지지 값, 둘의 합" 안에 묶여 같은 날 막대 길이가 많아야 두 가지다.
- 화면 6개 영역: 일·공부 = 직업·학업(한쪽만이면 그쪽, 같은 방향이면 센 쪽, 반대면 신호 없음). 길이 = |세기| ÷ 3(최대 1).
- 이유 문구: 같은 방향의 가장 센 글자의 그룹 × 영역 × 방향 고정표 70줄(`areaReasons.ts`).
- 코어는 일운 영역의 확신도를 "낮음"으로 둔다. 충·맥락은 막대에 들어가지 않는다.

## 9. 그 밖의 표
- **오늘 힘이 되는 것**: 코어 키워드표(`규칙/키워드.json`). 역할이 용·희면 십신 "운_긍정" 낱말, 기·구면 "운_부정".
- **오늘의 개운**(`gaewoon.ts`): 오행 대응표(색·맛·시간대·활동). 오늘 글자가 용·희면 그 오행, 아니면 내 용신 오행. 시간 모름으로 근거가 약하면(10/12 미만) 보여 주지 않는다.

## 10. 글로 옮기는 계획 (`plan.ts`, 계산이 아니라 선택)
- **핵심**: 천간·지지 가운데 |점수|가 큰 쪽(같으면 천간)의 십신. 읽기: 용·희 = 도움, 한 = 평소대로, 구·기 = 지나치기 쉬움, 용신 없음 = 보류.
- **보조**: 일·월 자리 충 > 다른 쪽 글자(|점수| ≥ 1, 다른 십신) > 복음·먼 자리 충 > 없음.
- **맥락**: 운이 바뀌는 날(절기, 입춘, 대운 교체), 운과 일진이 충인 날, 또는 ctx를 빼면 단계가 달라지는 날만.
- **표현 후보**: 십신별 생활 표현(`expressions.ts`)을 날짜로 돌려 4개. 최근 7일 문장과 겹치는 것은 뺀다.
- **영역**: 오늘 신호를 코어 순서대로 먼저, 맥락을 쓰는 날은 이달·올해를 그다음에, 합쳐 최대 2개.

## 11. 계산 예시 (가상 사주, 1995-02-16 08:20 남, 2026-12-08 丙辰일)
1. 원국 乙亥 戊寅 戊寅 丙辰. 세력: 관성 41.8, 비겁 34, 인성 12.9, 재성 11.3, 식상 0.
2. 인비 46.9 → 중화, 중심 관성 → 용신 비겁(토). 역할: 비겁 용, 인성 희, 식상 한, 재성 구, 관성 기.
3. 일진 천간 丙 = 편인, 희 → +1.5. 지지 辰 = 비견, 용 → +2. raw = 3.5, 매우 유리.
4. 충 없음(시지 辰과 복음) → rel 0.
5. 대운 乙亥 합계 −4, 세운 丙午 합계 +2.5 → ctx = −0.8 + 0.375 = −0.43.
6. score01 = 0.5 + (3.5 − 0.43)/12 = 0.76 → **7.6, 좋음, 오늘 흐름 8**.
7. 영역: 인성(+1.5) → 일·공부·가족·건강, 비겁(+2) → 대인관계·돈. 신호 5개, 길이 두 가지(1/2, 2/3).

## 12. 쓰지 않는 이론
- **전왕표·균형붕괴(Y-08)**: 2026-10-07 결정으로 뺌.
- **신살**(도화, 역마, 화개, 천을귀인, 백호, 괴강, 12신살), **공망**, **원진·귀문·해·파·형**: 코어에 태그는 있지만 오늘의 운세 계산에는 쓰지 않는다.
- **합의 점수**: 합은 점수에 넣지 않는다.
- **지장간 여기·중기**: 운 판정에 안 쓴다(세력의 엔진 분포 20% 안에만 간접 반영).
- **격국**: 일진 점수에 쓰지 않는다.

## 13. 알아 둘 한계
1. **가중치는 대부분 가설이다.** `core.ts`의 계수(÷12, 충 0.5, 대운 0.2, 세운 0.15 등)는 코드에 "가설, 백테스트로 조정"이라고 적혀 있다. 코어 점수의 근거는 강사 라벨 일치 측정과 앱 주인 확답 카드이고, 행복도 예측력을 검증한 것이 아니다.
2. **사람마다 단계 비율이 크게 다르다.** 평균은 주의 42%지만 사람에 따라 약 23~60%이고 최대 75%다. 좋음은 합이 약 +2.2 이상이어야 하고 주의는 합이 약 −0.3 아래면 나온다.
3. **영역 막대는 거친 신호다.** 코어 스스로 일운 확신도 "낮음". 건강은 인성 글자가 올 때만 움직이고, 연애는 성별에 따라 재성·관성으로 갈린다(전통 배우자성).
4. **시간 모름**: 점수는 일치율 w만큼 줄지만 영역 세기는 줄이지 않는다.
5. **중화 사주**: 코어 플래그는 "운의 유불리보다 T존 십신 위주로 볼 것"이라고 하지만 점수는 같은 방식으로 낸다.

## 14. 어떻게 설명하는가 (계산 → 글)
"어떤 사주일 때 이렇게 설명한다"는 규칙 층은 **아직 없다.** 지금 글 재료를 정하는 기준은 **십신 10개 × 읽기 3가지**뿐이다.
| 재료 | 기준 | 작가에게 가나 |
|---|---|---|
| 십신 뜻 이름(`TEN_GOD_THEME`), 생활 표현(`expressions.ts`, 십신마다 경향 6 · 과할때 2 · 활용 2) | 십신 + 읽기(용·희 = 활용, 한 = 평소, 구·기 = 과함) | 감 |
| 충·복음 생활 문장(자리별) | 관계 + 자리 | 감(보조일 때) |
| 코어 플래그의 해석 문장(카드 014·019·021·025·020 등, 예: "삶이 바빠지거나 번아웃이 오거나", "나를 깎아 결과물을 내놓는 때") | 신강약 · 중심기운 · 일간 음양 · 원국 구성 | **안 감** |
| 코어 사실 문장(`facts`: "내게 모자란 ○○를 채워요", 용신 손상 등) | 역할 · 용신 그룹 | **안 감**(v4.19에서 판정 말투가 샌다고 뺐다) |
| 코어 키워드표(`키워드.json`) | 십신 + 역할 | 화면 칩만 |
| 신강약 · 중심기운 · 용신 그룹 · 일간 · 오행 | | **안 감** |

그래서 신강인 사람과 신약인 사람이 같은 편관·과함을 받으면 재료가 같다. 5명 × 2026년 1,825일 중 1,101일(60%)에 사주 유형별 해석 문장이 코어에 있지만 글에 쓰이지 않는다.
