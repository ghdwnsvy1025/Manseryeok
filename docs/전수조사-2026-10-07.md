## C. 화면별 "중·하" (요약)

**온보딩**: 버튼 "내 카드 보기" vs 제목 "운세 보여요" 불일치 / 2월 30일 → 엔진 문구 그대로 / "대운 방향" 용어 / 성별 라디오 접근 이름 영어 / 도시 8개뿐(그 외·모름 없음) / 윤달 설명 없음 / 편집 모드인데 버튼이 "내 카드 보기", 취소·경고 없음.
**welcome**: 카드 설명 글씨 너무 작음 / "기축"이 뭔지 설명 없음.
**오늘**: 제목 2줄 접힘 / 캐시 히트에도 운세 fallback 깜빡임 / 카드가 두 화면 길이 / 화살표 범례 없음 / "왜 이런 운세" 한자·십신 그대로 / 투표 36px·취소 불가·피드백 없음 / 밤엔 저장 직후에도 운세가 접힘 / 저장 복귀 시 스크롤 위치 이어받음 / `?saved` 반복 / 오늘의 기록 카드에 약속 결과 없음 / 기록 삭제 없음 / 오류 카드에 다시 시도 없음.
**쓰기**: 도장 47px·띠지 40px(<44) / 키트 이미지 늦게 떠 '민짜' 1~2 s / 글자 수·자동 높이 없음 / 과거 날짜에도 "오늘" placeholder / 고치기 모드에 취소·삭제 없음 / 미래 날짜 조용히 오늘로.
**팡**: 고치기만 해도 팡 다시 터짐 / 금테 이유 설명 없음.
**나**: 나무패 십신·오행 설명 없음 / 격자 32px·빈 칸 글자 대비 2.5:1 / 오늘 칸 남색 테두리 안 보임(클래스 추정) / "신호 약함" 용어 / 칸 상세에 카드 전체(작은 글씨) / 맞춤도 설명 없음 / 통계 3개가 1건에도 전부 펼쳐져 2,890px / 공유 버튼이 60일 뒤에야 활성 / 공유 캔버스가 옛 색·폰트 / 목록 30건 제한 / ShareCard·알림·설치 상자가 둥근 PPT 상자(테두리 체계 3종).
**설정**: 알림 제목 중첩 / 시각 선택 없음·안내 없음 / iOS 문구가 안드로이드에도 / 생년월일 고치기 경고·취소 없음 / 이름·앱 정보 없음 / 오류 문구에 링크 없음 / "나로" / 로그아웃 확인 없음.
**공통**: manifest theme_color 남색·어미 "~됩니다" / `faint` 대비 2.5:1 / 알림 링크 `/write`로 오면 약속 블록 없음 / 익명 기기 종속 상시 안내 없음 / `lamp/night/surface` 별칭 잔존 / 템플릿 운세일 때 표시 없음.
